# 参考資料に含めたデータの出典とライセンス

この参考資料に含めた分野辞書は、いずれも本家 `dictionaries/` のファイルから、テストで使う語だけを抜いたものです。全文とライセンス全文は本家の `dictionaries/` および `THIRD-PARTY-NOTICES.md` を参照してください。

| `domain-laws.txt` | [e-Gov 法令検索](https://laws.e-gov.go.jp/) 法令 API (デジタル庁) | [公共データ利用規約 (第1.0版)](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0) (CC BY 4.0 と互換) |
