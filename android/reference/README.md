# Android 版 C# 実装の参考資料

このディレクトリは、別途開発している Android 版 Meltype の実装から、本家 Android 版の再構築に再利用できる部分だけを抜き出した**参考資料**です。ビルドには含まれません。

本家の Android 版（`android-v0.1.0-preview.1`）は Kotlin + Gradle + JNI + Mozc で実装されており、開発途中のため基本的な操作に課題があります。一方、こちらの実装は C# / .NET と zenz-native で構成され、実機で通しの確認をした状態です。変換エンジンはどちらも Mozc を使っています。技術スタックは異なりますが、変換・判定まわりの処理と検証手順は本家でも再利用できると考え、参考として提出します。

## 含めているもの

元のソースファイルをそのまま載せず、必要なメソッドと行だけを抜いています。読みやすさのため、キー処理は元の `switch` から該当する `case` だけを抜いてメソッドにまとめるなど、軽い整理をしています。抜粋された `.cs` ファイルは依存する型・メンバーを含むため、単体ではビルドできません。差分の考え方を読むための資料として扱ってください。

| パス | 内容 |
| --- | --- |
| `core/ClauseResize.excerpt.cs` | Shift+矢印で文節の先頭／末尾 1 音を隣とやり取りし、再変換する処理 |
| `core/CandidateBuild.excerpt.cs` | 文節・英語・ローマ字の候補を組み立てる順番 |
| `core/CandidateDictionary.excerpt.cs` | 分野辞書のロード、候補順、文節区切り判定への非採用 |
| `core/CompositionText.excerpt.cs` | BackSpace 後のローマ字再判定 |
| `dictionaries/domain-*.txt` | テストに使う語だけを抜いた分野辞書 6 ファイル |
| `tests/DomainDictionaryTests.cs` | 分野辞書・候補順・BackSpace 再判定の単体テスト |
| `tests/test_domain_*_device.py` | 実機回帰テスト |
| `THIRD-PARTY-NOTICES.md` | 抜粋した辞書の出典とライセンス |

## 本家 Core との関係

手元の Core は 1.3.0 をベースに、本家 1.6.0 の辞書・判定改善をバックポートしたものです。抜粋には次の変更が反映されています。

- 分野辞書（`domain-*.txt`）と候補順
- 分野辞書を文節区切り判定へ入れない扱い
- BackSpace 後の再判定
- 候補の直接選択
- Shift+矢印による文節調整

文節区切り学習は、本家で削除が提案されている機能（#2047）です。参考資料として記載していますが、採用するかどうかは本家の判断に委ねます。

## 検証結果

### 単体テスト

全群通過。新規の `DomainDictionaryTests` 4 件を含む。

### 実機（A142 / Android 16 / arm64-v8a）

- 矢印で文節を移動し、Shift 固定で範囲を変更して候補を選ぶ一連の操作
- 候補タップで選択文節までを確定し、後ろの文節を未確定で残す
- 文節区切りを変更した範囲全体で候補を取得し直す
- 英字と判定した入力からの日本語変換
- zenz による文脈変換・誤字補正と、OFF 時の既存処理への切り替え
- 予測に応じたキー境界の調整、クリップボード候補の 1 タップ貼り付け、GODAN 配列・ダークテーマ・キーボード内設定

配布物は署名済み APK（`Meltype-Android-1.3.2-domain-20261122.apk`）としてビルドし、実機へ導入して確認しました。JNI 両 ABI、モデルハッシュ、署名証明書の検証も済んでいます。
