06 変換（Mozc）

確定

変換の窓口（Converter）

engine が定め、mozc が実装する。engine はこの窓口だけを通して変換を頼む。

操作 渡すもの 返るもの
変換 読み（ひらがな）。あれば、カーソルの前の文脈 文節の並び。各文節は、対応する読みと、候補の一覧（第一候補が先頭）を持つ
予測 読み 読み全体に対する予測候補の一覧
学習 確定した文節の並び（読みと選んだ表記）。あれば文脈 なし

文脈は、未確定文字の直前にある文章。app が、未確定文字が始まるときに、それを入力欄に出す前に1回だけ読む（かな配列では最初のかな、ローマ字配列では最初の打ちかけの英字を出す前）。出したあとに読むと、未確定文字そのものが文脈に混ざる。変換しない欄では読まない。読みの先頭だけを確定して残りが続くときは、確定した分を文脈の末尾に足す。

決まりごと:

  • 返る文節の読みを順につなげると、渡した読みと一致する。一致しない結果は失敗として扱う。
  • 失敗したときは「結果なし」を返す。例外を engine に投げない。
  • 呼び出しは同時に1つだけ。app が用意する変換用のスレッドから呼ぶ。
  • 1回の呼び出しは 2 秒で打ち切る。
  • 学習は、渡した読みを Mozc が変換し直したときに、同じ文節の区切りで同じ表記が候補にある場合だけ行う。合わないときは何もしない（Mozc にない表記を作って覚えさせない）。このため、予測候補やカタカナを選んだときは学習されないことがある。

Mozc の組み込み

かな漢字変換には、オープンソース版の Mozc を端末の中で動かす。

同梱するもの:

ファイル 中身
libmozc.so 変換エンジン本体。arm64-v8a と x86_64 の2種類
mozc.data 変換用の辞書

呼び出し方:

  • Mozc が Android 用に用意している JNI の入口を使う。入口のクラス名とメソッドは Mozc の側で固定されているので、それに合わせる（com.google.android.apps.inputmethod.libs.mozc.session.MozcJni）。
  • やり取りは Mozc の命令形式（Protocol Buffers）で行う。命令の組み立てと結果の読み取りには、Mozc の定義ファイルから生成したコードを使う。
  • 変換は、セッションを作る → 読みを渡す → 変換を指示する → 文節と候補を読み取る → セッションを捨てる、の順で行う。この手順で動くことは、既存の移植（Meltype-Android）で確認されている。

Mozc の学習データは、アプリ専用の領域に保存する。ほかのアプリからは読めない。

Mozc を開けなかったとき

Mozc の用意（辞書を写して初期化する）は、キーボードが起動したときに変換用のスレッドで行う。失敗したら、変換は「結果なし」を返し、かなの入力だけで動き続ける。

失敗をそのままにしない。キーボードのプロセスは何日も動き続けるので、一時的な失敗（空き容量の不足など）のあとも、やり直す。

  • やり直すのは、あとの変換が頼まれたとき。変換用のスレッドで行う（画面のスレッドではやり直さない）。
  • 前の試みから 30 秒たつまでは、やり直さない。
  • やり直しは 5 回まで。それでも開けなければ、そのプロセスのあいだは、かなの入力だけで静かに動き続ける。

Mozc のビルド

Mozc は Git に入れず、手順をスクリプトにして再現できるようにする。

  • ビルドする Mozc の版は、コミットを1つに固定してリポジトリに記録する。最初に使う版は 60fe4012e5eaa26805dbbb8e5548cbe6db4aaf98（既存の移植が Android で動作を確かめた版）。
  • スクリプト1本で、Mozc の取得、エンジン本体と辞書のビルド、mozc モジュール内の所定の場所への配置、ライセンス表記の収集までを行う。
  • ビルドした成果物（libmozc.so、mozc.data）は Git に入れない。
  • ビルドには Bazel（Bazelisk 経由）を使う。初回は依存の取得を含めて 30〜40 分かかる。
  • 成果物（libmozc.so 2種類、mozc.data、ライセンス表記の MOZC_NOTICES.txt）のどれかがない状態でアプリをビルドしようとしたら、スクリプトを先に実行するよう伝えるメッセージを出して止める。ライセンス表記も含めるのは、それがない APK は Mozc に含まれるものの配布条件を満たさないため。

版を上げるとき

Mozc の版を上げるのは、変換の質や不具合で必要になったときだけ。上げたら 11 の変換の確認をやり直す。
