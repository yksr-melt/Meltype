仕様書

このディレクトリが、このキーボードアプリの仕様の唯一の正（SSOT）です。

運用ルール

  • このディレクトリのHTMLを正本とし、章ごとに管理する。../markdown/spec/ にはレビューしやすいMarkdown版を併置し、機能変更時に両方更新する。
  • 章を足す・名前を変えるときは、全ファイルの左の目次と、下の「章の一覧」を揃えて直す。
  • 仕様を変えるときは、先にここを直してからコードを直す。コードと食い違ったら、仕様書が正しいものとして扱い、どちらかを直して揃える。
  • 1つの事柄は1か所にだけ書く。他の章から触れるときは、内容を写さずリンクする。
  • 実装計画、作業メモ、議事録はここに置かない。ここに書くのは「何を作るか」と「なぜそうするか」だけ。
  • 各章の先頭に状態を書く。
    • 確定: この内容で実装してよい。
    • 概要: 方向だけ決まっている。その段階に着手するとき、詳細を詰めて「確定」に上げる。
