# 04 キーボード画面

確定（段階1の範囲）

## 配列の種類

| 配列 | 用途 |
| --- | --- |
| かな | 12キーのフリックで日本語を打つ |
| ローマ字 | QWERTY でローマ字を打って、日本語を入れる |
| 英字 | QWERTY で英字を打つ。打った文字をそのまま入力する |
| 英字フリック | 12キーのフリックで英字を打つ |
| 数字・記号 | 数字とよく使う記号 |

日本語を打つ配列（かな、ローマ字）と、英字を打つ配列（英字、英字フリック）は、それぞれ設定で1つ選ぶ（[設定](#設定)）。この仕様書で「日本語の配列」「英語の配列」と書いたときは、選んである方を指す。選んでいない方の配列は出てこない。

入力欄がパスワード、数字、電話番号、メールアドレス、URL のときは、[09](09-privacy-security.md) の規則で最初に出す配列と動作が変わる。

### 配列の切り替え

- 入力欄に入ったとき、[09](09-privacy-security.md) の表が決める配列を出す。日本語の配列、英語の配列、数字・記号の配列のどれか。
- 12キー配列の `あa` は言語切り替え。QWERTYは自動判別を基本とし、スペース長押しで明示選択する。
- `?123` は、数字・記号の配列を出す。その戻るキーは、`?123` を押したときの配列に戻る。数字・記号の配列で始まる欄（数字、電話番号）では、英語の配列に戻る。
- 絵文字キーは、絵文字の画面を開く。その戻るキーは、開いたときの配列に戻る。
- 戻るキーには行き先を出す。日本語の配列なら `あa`、英語の配列なら `abc`（数字・記号の配列から絵文字の画面を開いたときは `?123`）。
- 配列を切り替えるとき、未確定文字があれば先に確定する。⇧ は解除する（英字配列で大文字に固定したまま、ローマ字配列に替えても、大文字にならない）。
- 入力欄が替わったとき、キーボードが出し直されたとき（画面の回転を含む）は、その入力欄の最初の配列に戻る。
- 設定で日本語の配列や英語の配列を選び直すと、キーボードが出ていても、すぐ替わる。いま出ている配列が選び直した側のものなら、未確定文字を確定してから、新しく選んだ配列を出す。数字・記号の配列や絵文字の画面の戻るキーの行き先も、新しく選んだ配列になる。

## かな配列

5列 × 4行。中央の3列が文字キー、左右の列が操作キー。3行目の左の1ますは、幅が半分のキー2つ（`?123` と絵文字）に分ける。

```
┌───────┬──────┬──────┬──────┬──────┐
│ 戻す  │  あ  │  か  │  さ  │ 削除 │
├───────┼──────┼──────┼──────┼──────┤
│  ◀    │  た  │  な  │  は  │  ▶   │
├───┬───┼──────┼──────┼──────┼──────┤
│?123│絵 │  ま  │  や  │  ら  │ 空白 │
├───┴───┼──────┼──────┼──────┼──────┤
│  あa  │ ゛゜小│  わ  │、。?! │ 確定 │
└───────┴──────┴──────┴──────┴──────┘
```

図の「戻す」「削除」「空白」「確定」「絵」は、キーの名前。画面には絵で出す（[キーの表示と名前](#キーの表示と名前)）。

### フリックの割り当て

| キー | タップ | 左 | 上 | 右 | 下 |
| --- | --- | --- | --- | --- | --- |
| あ | あ | い | う | え | お |
| か | か | き | く | け | こ |
| さ | さ | し | す | せ | そ |
| た | た | ち | つ | て | と |
| な | な | に | ぬ | ね | の |
| は | は | ひ | ふ | へ | ほ |
| ま | ま | み | む | め | も |
| や | や | （ | ゆ | ） | よ |
| ら | ら | り | る | れ | ろ |
| わ | わ | を | ん | ー | 〜 |
| 、。 | 、 | 。 | ？ | ！ | … |

- キーを押しているあいだ、5方向の文字を示す案内を出す（[フリックの案内](#フリックの案内)）。指を離した位置の方向で文字が決まる。
- 指の移動がキーの幅の 1/4 未満ならタップとして扱う。
- 同じキーを続けてタップしたときの動作は、トグル入力の設定で変わる（次の節）。

### トグル入力

同じキーを続けてタップすると、文字が段の順に切り替わる入力方法。設定でオン・オフを切り替える（[設定](#%E8%A8%AD%E5%AE%9A)）。

オフのとき: 同じキーを続けてタップすると、同じ文字が続けて入る（`あ` を2回で `ああ`）。

オンのとき:

- 同じキーを続けてタップすると、直前に入れた文字が、フリックの表の「タップ → 左 → 上 → 右 → 下」の順に切り替わる。最後まで行くと最初に戻る（`あ` → `い` → `う` → `え` → `お` → `あ`）。
- 切り替わるのは、直前の操作が同じキーのタップで、そこから待ち時間以内のときだけ。待ち時間がたつ、ほかのキーを押す、フリックで入れる、のいずれかで文字が決まり、次のタップは新しい文字になる。
- 待ち時間は設定で変えられる（[設定](#%E8%A8%AD%E5%AE%9A)）。最初の値は 1.0 秒。
- 同じ文字を続けて入れたいときは、待ち時間がたつのを待つか、▶ キーを押して文字を決めてからタップする（`あ` `▶` `あ` で `ああ`）。
- 行きすぎたときは、戻すキーで1つ前の文字に戻せる（[戻すキー](#戻すキー)）。
- フリックはオンのときも同じように使える。フリックで入れた文字は切り替わらない。
- 濁点・半濁点・小文字キーは、切り替えている途中の文字にもそのまま効く。押すと文字が決まる。

### フリックの案内

かな配列と英字フリック配列の文字キーを押しているあいだ、十字の形の案内を、キーの上に重ねて出す。

- 十字の中央は、押したキーの位置にぴったり重ねる。画面の端や上の段でも、ずらさない。中央にタップの文字、左・上・右・下に、その向きへフリックしたときの文字を置く。
- 案内は、ふつうのキーと見分けられるようにする。キーとは違う色で塗り、ふちに線を引き、十字全体をひとつながりの形にする。
- いま指がある向きのますは、強調の色で塗る。指を動かすと、すぐに追う。
- 中央と下のますは指に隠れる。そこで、いま選んでいる文字を、十字の左上（上のますの左どなり）に、大きく出す。ここは、右手でも左手でも指がかからない。
- いちばん上の段のキーでは、上のますと、選んでいる文字の表示が、候補バーの上に重なる。候補バーより上には描けないので、上のますの高さは候補バーの高さまでにする。
- いちばん下の段のキーでは、下のますが、キーボードの下の余白（[見た目](#見た目)）に重なる。余白に入りきらない分は描かない。入りきらなくても、選んでいる文字は左上の表示で分かる。
- 文字キーは中央の3列にあるので、左右のますは画面の外に出ない。
- 文字のない向き（英字フリック配列の `abc` の右など）には、ますを出さない。指がその向きにあるあいだは、どのますも強調せず、選んでいる文字の表示も出さない。
- 指を離す、押下が取り消される、もう1本の指でほかのキーを押す、のいずれかで案内を消す。
- パスワードの欄では、選んでいる文字の大きな表示を出さない（[09](09-privacy-security.md)）。

### 濁点・半濁点・小文字キー（゛゜小）

直前に打った1文字を、次の順に切り替える。押すたびに1つ進み、最後まで行くと元に戻る。

| 元の文字 | 切り替わる順 |
| --- | --- |
| か行・さ行・た行（つ以外） | 清音 → 濁音 → 清音 |
| つ | つ → っ → づ → つ |
| は行 | 清音 → 濁音 → 半濁音 → 清音 |
| あ行・や行（や・ゆ・よ）・わ | 通常 → 小文字 → 通常 |
| う | う → ぅ → ゔ → う |
| 上記以外 | 何もしない |

読みが空のときは何もしない。

## 操作キー

「未確定文字があるとき」と「ないとき」で動作が変わる。

| キー | 未確定文字があるとき | ないとき |
| --- | --- | --- |
| 削除 | 読みの最後の1文字を消す。ローマ字配列で打ちかけの英字があれば、その最後の1文字を消す | 入力欄のカーソルの前の1文字を消す。いくつかの符号を組み合わせて1文字に見せているもの（絵文字、濁点付きの文字）は、まとめて消す |
| 空白 | 次の変換候補を選ぶ（[05](05-input-engine.md) の明示変換。予測候補は選ばない） | 日本語の配列（かな、ローマ字）では全角の空白、英語の配列（英字、英字フリック）と数字・記号の配列では半角の空白を入れる。長押しでカーソルを動かす（[空白キーの長押し](#空白キーの長押し)） |
| 確定 | 未確定文字を確定する | 入力欄が求める動作をする（改行、送信、検索、次へ など） |
| ◀ ▶ | カーソルは動かさない。トグル入力がオンで ▶ を押したときは、切り替え中の文字を決める。最後の1文字だけを持っているとき（英字フリック配列と、変換しない欄）は、◀ でも ▶ でも、その1文字を確定する | 入力欄のカーソルを1文字動かす |
| 戻す | トグル入力で切り替えている文字を1つ前に戻す。空白で候補を選んでいるときは、選択を解く（[戻すキー](#戻すキー)） | 何もしない |
| `?123` | 未確定文字を確定してから、数字・記号の配列へ | 数字・記号の配列へ |
| `あa` | 未確定文字を確定してから、日本語の配列と英語の配列を入れ替える | 日本語の配列と英語の配列を入れ替える（[配列の切り替え](#配列の切り替え)） |
| 絵文字 | 未確定文字を確定してから、絵文字の画面を開く | 絵文字の画面を開く（[絵文字の画面](#絵文字の画面)）。どの入力欄でも押せる |

- 削除、◀、▶ は、押し続けると繰り返す。押して 400 ミリ秒後から、50 ミリ秒ごとに1回。指を離す、配列や画面が切り替わる、入力欄が切り替わる、キーボードが閉じる、のいずれかで止める。
- 確定キーの絵は、入力欄が求める動作に合わせて変える（[キーの表示と名前](#キーの表示と名前)）。
- 英字フリック配列は、読みを作らず、最後に打った1文字だけを持つ（[英字フリック配列](#英字フリック配列)）。その1文字が、この表の「未確定文字」に当たる。ただし空白と確定は、変換しない欄（[09](09-privacy-security.md)）と同じに働く。空白は、持っている1文字を確定してから半角の空白を入れる。確定は、持っている1文字を確定してから、入力欄が求める動作をする。◀ ▶ は、持っている1文字を確定するだけで、カーソルは動かさない（▶ は、同じ字を続けて打つために文字を決めるキーでもある。`l` ▶ `l` で ll。ここでカーソルまで動くと、次の字を飛びこえたり、ほかの入力欄へ移ったりする）。何も持っていなければ、カーソルを動かす。
- 英字配列と数字・記号の配列は、未確定文字を作らない。いつも「ないとき」の動作をする。
- ローマ字配列で、空白・確定・候補のタップが打ちかけの英字をどう扱うかは [05](05-input-engine.md#ローマ字入力)。

### 戻すキー

かな配列と英字フリック配列の左上にある。打ちまちがいを1手だけ戻す。

- トグル入力で文字を切り替えている途中なら、そのキーの順を1つ前に戻す（`う` → `い` → `あ`）。最初の文字からは、最後の文字に回る（`あ` → `お`）。戻したあとも切り替えは続く。待ち時間は、戻すキーを押したときから数え直す。
- 空白キーで候補を選んでいるときは、選択を解いて、選ぶ前の表示に戻す。文字は消さない。
- それ以外のときは何もしない。トグル入力が効かない欄（パスワード）でも何もしない。

### 空白キーの長押し

空白キーを押したまま指を左右に動かすと、入力欄のカーソルが動く。

- 空白キーを 300 ミリ秒押し続けると、カーソルを動かす状態に入る。入ったことを、振動で1回知らせる。それまでにタップの範囲（キーの幅の 1/4）を超えて指が動いたら、入らない。
- 入ったあとは、指が横に 12dp 動くごとに、カーソルを1文字動かす。左へ動かせば左、右へ動かせば右。行き来できる。動かす量は、入ったときの指の位置から測る。縦の動きは見ない。
- 指を離すと終わる。空白は入れない。もう1本の指でほかのキーを押したときも終わり、空白は入れない。
- 300 ミリ秒より前に指を離したときは、これまでどおり空白キーとして働く。
- 未確定文字があるあいだは使えない（空白キーは「次の変換候補を選ぶ」のまま。長く押しても、離したときに1回働くだけ）。
- どの配列でも使える。変換しない欄（[09](09-privacy-security.md)）でも使える。持っている1文字があれば、先に確定してから動かす。
- カーソルは文字の途中に止めない。サロゲートペアの間にも、いくつかの符号を組み合わせて1文字に見せている絵文字（家族の絵文字、国旗など）や濁点付きの文字の間にも止めない。文章の先頭と末尾では止まり、ほかの入力欄へは移らない。入力欄から読む文字の扱いは [09](09-privacy-security.md)。

300 ミリ秒と 12dp は、それぞれ定数1つで変えられるようにする。

### キーの表示と名前

操作キーの多くは、文字ではなく絵で出す。絵は、このアプリが線と面で描く（画像や、絵を集めたフォントを使わない）。どのキーも、読み上げに使う日本語の名前を持つ。

| キー | 表示 | 名前 |
| --- | --- | --- |
| 削除 | 左向きの札の形に × | 削除 |
| 空白 | 上が開いた「コ」の字を寝かせた形（␣） | 空白 |
| 確定 | 改行を入れるときは、折れた矢印（⏎）。検索は虫めがね、送信は紙ひこうき、完了はチェックの印、そのほかの動作（開く、次へ など）は右向きの矢印 | 改行、検索、送信、開く、次へ、完了、実行（入力欄が求める動作に合わせる） |
| ◀ ▶ | 塗りつぶした三角 | 左、右 |
| 戻す | 左回りの矢印（↶） | 戻す |
| 絵文字 | 丸い笑顔 | 絵文字 |
| ⇧ | 上向きの矢印。ふだんは線だけ、次の1文字だけ大文字のときは塗りつぶし、固定のときは塗りつぶしに下線 | シフト |
| `?123` | 文字 `?123` | 記号 |
| `あa` | 文字 `あa` | かな・英字切り替え |
| 数字・記号の配列の、戻るキー | 日本語の配列に戻るときは `あa`、英語の配列に戻るときは `abc` | 前の配列に戻る |
| ゛゜小 | 文字 `゛゜小` | 濁点・半濁点・小文字 |
| `a⇔A` | 文字 `a⇔A` | 大文字・小文字 |

文字キーの名前は、そのキーに書いてある文字。

## 英字QWERTY

独立した英字配列。打った文字を直接確定する。日本語と英語を自動判別する場合は日本語QWERTYを使用する（[08](08-auto-detection.md)）。

```text
 q w e r t y u i o p
  a s d f g h j k l
 ⇧ z x c v b n m 削除
 ?123 , 空白 . 確定
```

QWERTYでは独立した`あa`キーを表示せず、スペース長押しから言語を選ぶ。

## 日本語QWERTY（ローマ字配列、日英自動判別対応）

4行のQWERTYで、日本語・英語・混在文を自動判別して入力する。既存のC# `Meltype.Core`をNativeAOT/JNIで共有し、Kotlinに判別ロジックを再実装しない。

```text
 q w e r t y u i o p
 a s d f g h j k l ー
 ⇧ z x c v b n m 削除
 ?123 、 空白 。 確定
```

- 通常候補・予測候補・原文の英字・かな・カタカナの訂正候補を表示し、候補の元インデックスを保ったまま選択・確定する。
- スペース長押しで言語選択メニューを開く。QWERTYには単独の `あa` 切り替えキーを置かない。
- 日本語QWERTYでは `、` と `。` を専用キーとして残す。記号は2ページに分け、`!` `?` に対応する。
- 画面のdp幅・高さ・縦横比から行高・分割を決める。横長の展開端末は中央テンキーなし、十分に大きい画面だけ中央テンキーありとする。
- 日本語QWERTY以外の配列は従来Kotlinエンジンで処理する。詳しくは[08 日英自動判別](08-auto-detection.md)。

## 英字フリック配列

かな配列と同じ 5列 × 4行。中央の3列が文字キー、左右の列が操作キー。操作キーの並びと大きさは、かな配列と同じ。

```
┌───────┬──────┬──────┬──────┬──────┐
│ 戻す  │ @#/& │ abc  │ def  │ 削除 │
├───────┼──────┼──────┼──────┼──────┤
│  ◀    │ ghi  │ jkl  │ mno  │  ▶   │
├───┬───┼──────┼──────┼──────┼──────┤
│?123│絵 │ pqrs │ tuv  │ wxyz │ 空白 │
├───┴───┼──────┼──────┼──────┼──────┤
│  あa  │ a⇔A  │ '"() │ .,?! │ 確定 │
└───────┴──────┴──────┴──────┴──────┘
```

### フリックの割り当て

| キー | タップ | 左 | 上 | 右 | 下 |
| --- | --- | --- | --- | --- | --- |
| `@#/&` | @ | # | / | & | 1 |
| abc | a | b | c | （なし） | 2 |
| def | d | e | f | （なし） | 3 |
| ghi | g | h | i | （なし） | 4 |
| jkl | j | k | l | （なし） | 5 |
| mno | m | n | o | （なし） | 6 |
| pqrs | p | q | r | s | 7 |
| tuv | t | u | v | （なし） | 8 |
| wxyz | w | x | y | z | 9 |
| `'"()` | ' | " | ( | ) | 0 |
| `.,?!` | . | , | ? | ! | - |

- 下のフリックは、電話のキーと同じ数字。
- 「（なし）」の向きにフリックしても、何も入らない。フリックの案内にも、その向きのますを出さない（[フリックの案内](#フリックの案内)）。
- 打った文字は変換しない。候補バーは使わない。`a⇔A` とトグル入力が効くように、最後に打った1文字だけを未確定文字として持つ。持ち方と、持っている1文字が確定するきっかけは、変換しない欄でかなを打つときと同じ（[09](09-privacy-security.md)）。ふつうの文章の欄でも、この配列ではこの持ち方をする。パスワードの欄では何も持たない。
- トグル入力（[トグル入力](#トグル入力)）がオンのとき、同じキーを続けてタップすると、表の「タップ → 左 → 上 → 右 → 下」の順に、文字のある向きだけを回る。数字は最後に回ってくる（a → b → c → 2 → a、p → q → r → s → 7 → p）。戻すキーで1つ前に戻せる。
- 空白は半角。`あa` で日本語の配列に替わる。

### 大文字・小文字キー（a⇔A）

直前に打った1文字が英字なら、小文字と大文字を入れ替える（a → A → a）。押すたびに入れ替わる。数字や記号のとき、持っている文字がないときは、何もしない。

トグル入力で切り替えている途中の文字にも効く。押すと文字が決まる（濁点・半濁点・小文字キーと同じ）。

## 数字・記号配列

```
 1 2 3 4 5 6 7 8 9 0
 - / : ; ( ) ¥ & @ "
 # % * + = _ ~ 「 」 削除
 戻る 絵文字 ,   空白   .  確定
```

いちばん下の行の幅（列の数）: 戻る 1.5、絵文字 1、`,` 1、空白 4、`.` 1、確定 1.5。

- 戻るキーで、直前に使っていた配列（日本語の配列 または 英語の配列）に戻る（[配列の切り替え](#配列の切り替え)）。
- 打った文字はそのまま確定して入力する。

## 絵文字の画面

絵文字キーを押すと、候補バーとキーのあった場所が、絵文字の画面に入れ替わる。未確定文字があれば、先に確定する（配列の切り替えと同じ）。

### 並びと高さ

上から順に、次の3つを並べる。

| 部分 | 高さ | 内容 |
| --- | --- | --- |
| 種類のタブ | 候補バーと同じ | 絵文字の種類を選ぶ。10 個を同じ幅で並べる（パスワードの欄では「最近使ったもの」を除いた 9 個） |
| 絵文字のます目 | キーの3段ぶん | 選んだ種類の絵文字。縦にスクロールする |
| 操作キーの行 | キーの1段ぶん | 左から、戻るキー、空白、削除、確定 |

- 合わせた高さは、候補バーとキー4段を合わせた高さと同じ（[高さと横画面](#高さと横画面)）。開いても閉じても、キーボードの高さは変わらない。縦画面でも横画面でも同じ。
- キーボードの下の余白（[見た目](#見た目)）は、そのまま残す。
- 色と形は、キーボードと同じものを使う。ライトでもダークでも読めること。

### 種類

タブは、左から次の順に並べる。名前は、読み上げに使う。タブには、名前の代わりに絵を出す。

| 名前 | 入れる絵文字（Unicode の一覧でのグループ） | タブの絵 |
| --- | --- | --- |
| 最近使ったもの | （[最近使ったもの](#最近使ったもの)） | 時計（線で描く） |
| 顔と気持ち | Smileys & Emotion | 😀 |
| 人 | People & Body | 🧑 |
| 動物と自然 | Animals & Nature | 🐶 |
| 食べ物 | Food & Drink | 🍎 |
| 活動 | Activities | ⚽ |
| 旅行と場所 | Travel & Places | 🚗 |
| 物 | Objects | 💡 |
| 記号 | Symbols | 🔣 |
| 旗 | Flags | 🏁 |

- 選んでいるタブは、強調の色で印を付ける。
- 画面を開いたとき、「最近使ったもの」に1つでもあれば、それを選んでおく。なければ「顔と気持ち」を選んでおく。
- パスワードの欄（数字だけのパスワードを含む。見分け方は [09](09-privacy-security.md) と同じ）では、「最近使ったもの」のタブを出さない。残りの 9 個を同じ幅で並べ、画面を開いたときは「顔と気持ち」を選んでおく。
- タブの絵に使う絵文字を端末が描けないときは、その種類の先頭の絵文字を出す。
- タブを選ぶと、ます目はその種類の先頭から出す。

### 絵文字の一覧

- 一覧は、Unicode が公開している絵文字の一覧（`emoji-test.txt`）から作って、アプリに入れておく（版と入手元は [10](10-licensing.md)）。作り直すためのスクリプトを `tools/` に置く。
- 使うのは、その一覧で「fully-qualified」とされているものだけ。種類への振り分けは上の表のとおりで、種類の中の並びは一覧の順のまま。「Component」のグループは使わない。絵文字の名前や並びを、ほかのキーボードやライブラリから取らない。
- 肌の色の違いは出さない。肌の色の符号（U+1F3FB〜U+1F3FF）を含むものを、一覧から外す。肌の色を選ぶ画面は作らない。
- それ以外は、いくつかの符号を組み合わせたもの（家族、職業、男女の違い、向きの違い、国旗など）も、一覧にあるとおり1つずつ出す。
- 端末が1つの絵として描けない絵文字は出さない（新しい版の絵文字を、古い端末で四角や、ばらばらの絵として出さないため）。描けるかどうかは、画面のスレッドの外で調べ、アプリが動いているあいだ覚えておく。調べ終わる前に画面を開いたときは、終わりしだい出す。

### ます目

- 1行のますの数は、画面の幅を 50dp で割った数（端数は切り捨て）。ただし 8 より少なくしない。縦画面のスマートフォンで 8、横画面ではそれより多い。ますの幅は、画面の幅をますの数で等分する。ますの高さは 46dp。
- 指で縦に動かすとスクロールし、はじくと流れて止まる。先頭と末尾より先へは行かない。右の端に、いまの位置を示す細い印を出す。
- 絵文字をタップすると、その絵文字がすぐ入力欄に入る。画面は開いたままにする（続けて選べる）。スクロールのために動かした指を離したときは、入れない。
- 押しているますは、色を変えて分かるようにする。タップしたとき、キーと同じ短い振動で応える。
- 「最近使ったもの」が空のときは、そのことを1行で書く。ほかの種類では、絵文字がないあいだ（一覧を調べ終わる前、一覧を読めなかったとき）も、この文を書かない。ます目には何も出さない。

### 操作キーの行

1行は 10 列ぶんの幅。幅（列の数）: 戻るキー 1.5、空白 5.5、削除 1.5、確定 1.5。

- 戻るキーで、絵文字の画面を開く前の配列に戻る。キーには行き先を出す（[配列の切り替え](#配列の切り替え)）。名前は「キーボードに戻る」。戻ると、候補バーとキーが元のとおりに出る。
- 空白、削除、確定は、開く前の配列にあるときと同じ動作をする（[操作キー](#操作キー)）。日本語の配列から開いたときの空白は全角、ほかは半角。削除は押し続けると繰り返す。空白キーの長押しも使える。
- 絵文字は、符号をいくつも組み合わせたものでも、削除の1回で1つ消える。

### 最近使ったもの

- 選んだ絵文字を、新しい順に 40 個まで覚える。同じ絵文字は1つだけ持ち、選び直すと先頭に移る。40 個を超えたら、古いものから捨てる。
- 「最近使ったもの」のます目の並びは、そのタブを選んだとき（画面を開いて最初から選ばれているときを含む）のもの。そこで絵文字を選んでも、見ているあいだは並びを変えない（指の下でますが動かないように）。
- 端末の中の、アプリ専用の領域にだけ保存する。ほかのアプリからは読めず、端末のバックアップの対象にもならない（学習データと同じ扱い。[09](09-privacy-security.md)）。キーボードを閉じても、端末を再起動しても残る。アプリを削除すると消える。
- 学習しない欄（[09](09-privacy-security.md) の表で学習が「しない」の欄。パスワード、入力先が「学習しないでほしい」と指定している欄など）で選んだ絵文字は、覚えない。絵文字キーと絵文字の画面は、これらの欄でも出す。
- パスワードの欄では、覚えてある絵文字を見せない（タブごと出さない。[種類](#絵文字の種類)）。伏せ字にする欄の上に、ふだん使っている絵文字を並べないため。そこで選んだ絵文字を覚えないのは、ほかの学習しない欄と同じ。

### 閉じるとき

- 戻るキーを押すと閉じて、開く前の配列に戻る。
- 入力欄が替わったとき、キーボードが出し直されたとき（画面の回転を含む）は閉じて、その入力欄の最初の配列を出す（配列の扱いと同じ）。

### 読み上げ

タブと操作キーの行は、決まった名前を持つ。ます目は、1つの部品として「絵文字の一覧」という名前だけを持ち、ますの1つ1つは読み上げに知らせない（読み上げで絵文字を1つずつ選べるようにするのは、キーボードのキーと合わせて後で作る）。選んだ絵文字を、読み上げに知らせない（[09](09-privacy-security.md)）。

## 候補バー

キーボードの上に1行で出す。横にスクロールできる。

- 並べる内容と順番は [05](05-input-engine.md) が決める。
- 候補をタップすると、その候補を確定する。
- 空白キーで選択中の候補は、色を変えて示す。
- 候補がないときは空の行として高さを保つ（キーボードの高さが打つたびに変わらないようにする）。

## 見た目

- 端末のライト/ダーク設定に従う。
- キーは角を丸くする（半径 10dp ほど）。文字キーはキーの色、操作キーはそれより少し沈んだ色で塗る。`あa`（数字・記号の配列の戻るキーを含む）と確定キーは、両端を半円にした形にして、強調の色を薄くした色で塗り、その上で読める色で文字や絵を描く。押しているキーは、どの種類でも色を変えて分かるようにする。
- キーボードの下には、端末のナビゲーション領域と重ならないだけの余白を取る。余白はキーボードの背景色で塗る。
- ジェスチャーナビゲーションの端末では、キーボードが出ているあいだ、端末が「閉じる」と「キーボードの切り替え」のボタンを画面の下に描く。このボタンのための帯を、いちばん下の段のさらに下に空ける。キーはボタンの下に入らない。
- 3ボタンナビゲーションの端末では、いちばん下の段はナビゲーションバーのすぐ上で終わる。それより広い余白は取らない。
- 余白の大きさは、端末が知らせる値にそのつど合わせる（画面の回転や、ナビゲーションの方式の切り替えのあとも）。キーボードの画面を作り直したとき（ライトとダークの切り替えなど）も、端末からの知らせを待たずに、そのときの値で合わせる。
- キーを押したとき、短い振動で応える。端末の設定で振動が切られていれば鳴らさない。

### 高さと横画面

横画面でも、縦画面と同じ配列を使う。段を低くして、入力先のアプリの画面が見える広さを残す。

| 向き | キーの1段の高さ | 候補バーの高さ |
| --- | --- | --- |
| 縦画面 | 54dp | 44dp |
| 横画面 | 40dp | 36dp |

画面を回したら、キーボードを出し直さなくても、その向きの高さになる。

## 導入画面

アプリを開くと出る画面。キーボードが使えるようになるまでを案内する。

1. 「キーボードを有効にする」ボタン。押すと Android の設定画面を開く。
2. 「キーボードを選ぶ」ボタン。押すと Android のキーボード選択を開く。
3. 試し書き用の入力欄。

1 と 2 は、済んでいるかどうかを画面に表示する。済んでいない手順のボタンを目立たせる。

## 設定

導入画面の下に並べる。変えた内容はすぐに効き、アプリを閉じても残る。

| 項目 | 選べる値 | 最初の値 |
| --- | --- | --- |
| トグル入力 | オン / オフ | オフ |
| トグル入力の待ち時間 | 0.3 秒 〜 2.0 秒（0.1 秒きざみ） | 1.0 秒 |
| 日本語の入力 | 12キー（フリック） / QWERTY（ローマ字） | 12キー（フリック） |
| 英字の入力 | QWERTY / 12キー（フリック） | QWERTY |

「トグル入力の待ち時間」は、トグル入力がオフのあいだは操作できない表示にする。値は残しておき、オンに戻すと前の値がそのまま使われる。

「日本語の入力」は、日本語の配列を、かな配列とローマ字配列から選ぶ。「英字の入力」は、英語の配列を、英字配列と英字フリック配列から選ぶ。選び直したときの動きは [配列の切り替え](#配列の切り替え)。トグル入力の設定は、かな配列と英字フリック配列の両方に効く。

設定の項目を足すときは、この表に行を足す。
