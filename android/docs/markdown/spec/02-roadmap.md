# 02 段階と範囲

確定

開発当初の3段階の区切りを残したもの。現在、段階3相当の日英自動判別は日本語QWERTYで実装済み。独立した「読みから英字」の推薦機能（段階2）は未対応。

段階ごとに、仕様の詳細を詰める → 実装計画を書く → 実装する、を繰り返す。

## 段階1: フリックとライブ変換

キーボードとしての土台。これだけで普段使いできる状態にする。

作るもの:

- 12キーのかなフリック配列（[04](04-keyboard-ui.md)）。押しているキーに重ねて出す、フリックの案内
- 濁点・半濁点・小文字の切り替え、削除、空白/変換、確定
- トグル入力（設定でオン・オフを切り替える）
- ライブ変換と候補バー（[05](05-input-engine.md)）
- Mozc の組み込み（[06](06-conversion-mozc.md)）
- 英字の QWERTY 配列（直接入力のみ。判別はしない）
- 日本語QWERTYと英字12キーフリック。第1段階では日本語QWERTYの判別は未対応だったが、現行版ではC# Coreによる自動判別を実装済み（[08](08-auto-detection.md)）
- 数字・記号の配列
- 絵で出す操作キー、戻すキー、空白キーの長押しでのカーソル移動
- 絵文字の画面
- キーボードを有効にする手順を案内する導入画面と、設定

## 段階2: 読みから英字

フリックで打った外来語を、英字でも出せるようにする（[07](07-kana-to-english.md)）。

## 段階3: 日英自動判別

**実装済み。** C# `Meltype.Core`をNativeAOT/JNI経由で共有し、日本語QWERTYで自動判別する（[08](08-auto-detection.md)）。

## どの段階でも作らないもの

必要になったら、この表から外して該当の章に仕様を書く。

| もの | 理由 |
| --- | --- |
| ユーザー辞書の編集画面 | Mozc の学習で当面足りる |
| 顔文字の専用画面 | 変換候補に出るもので当面足りる |
| テーマや配色の変更 | 端末のライト/ダークに従うだけにする |
| 音声入力、手書き入力 | 目的の外 |
| クラウド変換、利用状況の送信 | 入力を端末の外に出さない方針に反する |
| 他のキーボードからの学習データの取り込み | 目的の外 |
| フリック配列の日英自動判別 | 今回は日本語QWERTYのみ。かな／英字フリックはKotlin処理を継続 |
