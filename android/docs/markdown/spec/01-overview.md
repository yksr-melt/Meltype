# 01 概要

確定

## 目的

Android で、日本語と英語が混じった文を、変換キーや配列の切り替えをなるべく押さずに打てるキーボードを作る。

## 作るもの

Android の仮想キーボード（IME アプリ）。次の3つを柱にする。

1. **ライブ変換**: 12キーのフリックでかなを打つと、変換キーを押さなくても打つそばから漢字になる。
2. **読みから英字（未対応）**: かなフリックから直接英単語を推薦する独立機能は今後の対象。
3. **日英自動判別（実装済み）**: 日本語QWERTYで日本語・英語・混在文を判別。既存C# `Meltype.Core`をAndroid NativeAOT/JNIで共有し、Kotlinへの判別ロジック移植は行わない（[08](08-auto-detection.md)）。

12キーフリックは従来のKotlinエンジンを使用。日本語QWERTYでの日英自動判別は共有C# Coreを使用する。

## 利用者

まず開発者本人が自分の端末で普段使いする。使えるものになったら、本家の [Meltype](https://github.com/yksr-melt/Meltype) に取り込んでもらう予定。「Meltype」の名前を使うことと取り込みの方針は、本家の作者から許諾を得ている（2026-10-13、開発者が確認）。取り込みの時期と形（どのリポジトリに、どの単位で出すか）は、本家の作者と相談して決める。出すときは本家の `CONTRIBUTING.md` と CLA の手続きに従う。

## 成功の基準

- 開発者本人が、普段のキーボードをこのアプリに置き換えて使い続けられる。
- フリックで打った文が、変換キーを押さずに意図どおりの漢字かな交じり文になることが多い。
- キーを押してから文字が出るまでに、引っかかりを感じない（目安は [11 テスト](11-testing.md) の性能の節）。
- 入力した内容が端末の外に出ない（[09 プライバシーと安全](09-privacy-security.md)）。

## 用語

| 用語 | 意味 |
| --- | --- |
| IME | 文字入力を担うアプリ。Android ではキーボードアプリのこと |
| 読み | 利用者が打ったかなの並び。変換前の元になる |
| 未確定文字 | 入力欄に下線付きで出ている、まだ確定していない文字 |
| 確定 | 未確定文字を入力欄に書き込み、変更できない状態にすること |
| 文節 | 変換の単位。`今日は` `天気が` `いい` のような区切り |
| ライブ変換 | 変換キーを押さなくても、打つたびに未確定文字を変換結果で表示すること |
| 候補バー | キーボードの上に出る、変換候補を横に並べた欄 |
| フリック | キーを押したまま上下左右に指を滑らせて、段を選ぶ入力方法 |
| Mozc | Google 日本語入力のオープンソース版。かな漢字変換を担う |
| Meltype | ローマ字入力で日英を自動判別する日本語入力。本家は C# 製 |
