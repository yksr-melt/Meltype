# 09 プライバシーと安全

確定

キーボードは、利用者が打つすべての文字を扱う。次を守る。

## 通信しない

- インターネットの権限を要求しない。入力した内容は端末の外に出ない。
- 変換、予測、学習はすべて端末の中で行う。
- 利用状況や障害の情報を送る仕組みを入れない。

## 権限

権限を1つも要求しない。キーを押したときの振動は、権限の要らない Android 標準の仕組みで鳴らす。

## 入力欄の種類ごとの動作

入力欄の種類は、入力先のアプリが指定する。その指定に従って動作を変える。

| 入力欄 | 最初に出す配列 | 変換 | 学習 |
| --- | --- | --- | --- |
| ふつうの文章 | かな | する | する |
| パスワード | 英字 | しない | しない |
| 数字、電話番号 | 数字・記号 | しない | しない |
| メールアドレス | 英字 | しない | しない |
| URL | 英字 | する（日本語の配列に切り替えたとき） | しない |
| 入力先が「学習しないでほしい」と指定している欄（シークレットモードなど） | かな | する | しない |

- URL の欄で変換するのは、ブラウザーのアドレスバーが検索欄でもあるため。英語の配列で始まり、日本語の配列に切り替えると、ふつうの欄と同じようにライブ変換と候補バーが使える。学習はしない。
- 表の「かな」は日本語の配列、「英字」は英語の配列のこと。設定で選んである方を出す（[04](04-keyboard-ui.md#配列の種類)）。
- 「変換しない」欄では、日本語の配列に切り替えても、打ったかなをそのまま入力する。候補バーは使わない。
- 「変換しない」欄のうちパスワード以外（数字、電話番号、メールアドレス）では、濁点・半濁点・小文字とトグル入力が効くように、最後に打った1文字だけを未確定文字として持つ。持っている1文字は、次の文字、空白、確定、配列の切り替え、◀ ▶、空白キーの長押しでのカーソル移動のどれかで確定する（◀ ▶ は確定するだけで、カーソルは動かさない。[04](04-keyboard-ui.md#操作キー)）。濁点・半濁点・小文字と削除は、持っている1文字に効く。
- パスワードの欄（数字だけのパスワードを含む）では、何も持たない。打ったかなは1文字ずつすぐ確定する（未確定のあいだは伏せ字にならないので、ほかの文字と同じようにすぐ伏せ字になるようにする）。濁点・半濁点・小文字は、カーソルの前の1文字を読んで置き換える（読めないとき、切り替えられない文字のときは何もしない）。トグル入力は使えない（タップはいつも、そのキーの最初の文字を入れる）。
- ローマ字配列でも同じ。「変換しない」欄のうちパスワード以外では、打ちかけの英字と、できたかなの1回分（`kya` の きゃ、`kk` の っ など）だけを未確定文字として持つ。次のかなができたとき、前のかなを確定する。空白、確定、配列の切り替えで、持っているものを確定する（打ちかけの `n` ひとつは、ここでも仮の ん として出し、ん として確定する。ほかの英字は打ったまま）。削除は、打ちかけの英字、持っているかなの順に効く。
- パスワードの欄では、ローマ字配列はローマ字を組み立てない。キーの英字を1文字ずつそのまま確定する（⇧ で大文字）。`ー` `、` `。` のキーは `-` `,` `.` を入れる。打ちかけの英字は、未確定のあいだ伏せ字にならないので、持たない。
- 英字フリック配列は、どの欄でも変換せず、最後に打った1文字だけを持つ（[04](04-keyboard-ui.md#英字フリック配列)）。ここで打った文字は学習しない。パスワードの欄では、かな配列と同じく何も持たない。打った文字は1文字ずつすぐ確定し、トグル入力は使えず、`a⇔A` はカーソルの前の1文字を読んで置き換える（読めないとき、英字でないときは何もしない）。
- パスワードの欄（数字だけのパスワードを含む）では、フリックの案内（[04](04-keyboard-ui.md)）のうち、選んでいる文字を大きく出す表示を出さない。入力欄が伏せ字にしている文字を、キーボードが画面の上のほうに大きく出してしまわないようにするため。十字のますは出すが、文字の大きさはキーの文字と同じにする。
- パスワード欄かどうかは入力先のアプリの指定に頼る。指定が正しくないアプリでは、ふつうの欄として扱われる。

## 読み上げなどの補助機能

キーボードは、利用者が打った文字、読み、候補を、自分から補助機能（読み上げなど）に知らせない。どの入力欄でも守る。パスワードの欄ではとくに大事。

- 打った文字や候補を、読み上げの依頼として送らない。
- 打った内容に合わせて変わる説明を、画面の部品に付けない。キーの名前（[04](04-keyboard-ui.md) の「キーの表示と名前」）は、キーごとに決まった名前で、打った文字ではない。
- フリックの案内は絵として描くだけで、補助機能には何も知らせない。
- 打った文字を載せた補助機能の通知を、キーボードから出さない。
- 絵文字の画面（[04](04-keyboard-ui.md)）でも同じ。選んだ絵文字を知らせない。タブの名前は種類ごとに決まった名前で、選んだ絵文字では変わらない。

## カーソルの移動

空白キーの長押しでのカーソル移動（[04](04-keyboard-ui.md)）は、入力欄の文章を、文字の途中に止まらないために要る分だけ読む。読むのは、動かす向きの側の、動かす1文字につき 16 単位（UTF-16）まで。読んだ文字は動かす量を決めるのに使ったら捨てる。保存しない。ログに出さない。

## 削除で読む文字

削除キーは、符号を組み合わせた文字をまとめて消すために、カーソルの前の文章を 16 単位（UTF-16）まで読む。読んだ文字は消す長さを決めるのに使ったら捨てる。保存しない。ログに出さない。読めない入力欄では、削除のキーを送る。

## 学習データ

- Mozc の学習データは、アプリ専用の領域に保存する。ほかのアプリからは読めない。
- 端末のバックアップの対象から外す（別の端末やクラウドに写らないようにする）。アプリのバックアップを止める指定（`allowBackup="false"`）に加えて、クラウドへのバックアップと端末から端末への引き継ぎの両方から、アプリのデータをすべて外す規則（Android 12 以降は `dataExtractionRules`、それより前は `fullBackupContent`）を付ける。設定の値も写らない。
- アプリを削除すると、学習データも消える。
- 絵文字の「最近使ったもの」（[04](04-keyboard-ui.md)）も、同じ扱いにする。学習しない欄で選んだ絵文字は、そこに残さない。パスワードの欄では、覚えてある絵文字を画面に出さない。

## ログ

- 利用者が打った文字、読み、変換結果、候補、選んだ絵文字を、ログに出さない。開発用のビルドでも出さない。
- ログに出してよいのは、起きた出来事の種類と件数、かかった時間だけ（例: 「変換が時間切れになった」）。
- 性能を測るためのログがある。ふだんは出さない。端末ごとに、システムのプロパティで有効にしたときだけ出す（`adb shell setprop log.tag.KeyboardPerf DEBUG`）。出すのは出来事の種類、件数（読みの文字数、候補の数）、ミリ秒だけで、文字は出さない。キーの種類は「フリックのキー」「ローマ字のキー」「削除」のような区別までで、どの文字かは出さない。
