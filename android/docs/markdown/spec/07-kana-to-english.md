# 07 読みから英字

概要（段階2。着手するときに詳細を詰めて「確定」に上げる）

## 目的

フリックで打った外来語を、英字キーボードに切り替えずに英字で出せるようにする。

| 打つ | 出る |
| --- | --- |
| `きょうはぐーぐるでけんさく` | `今日はGoogleで検索` |
| `あしたのみーてぃんぐ` | `明日のmeeting` |
| `りなっくす` | `Linux` |

## 決まっていること

- 対応表には、Meltype が同梱している「読み → 英字」の辞書（`loanwords.txt`。JMdict から作られたもの）を使う。ライセンスの扱いは [10](10-licensing.md)。
- `engine` の中で行う。Mozc の変換結果に、対応表から引いた英字の候補を足す。
- 英字の候補は候補バーに必ず出す。
- 一度英字を選んだ語は、次からライブ変換でも英字で出す（語ごとに覚える）。カタカナを選び直したら、カタカナに戻す。

## できないこと

- 対応表にない英単語は出せない。英字の配列で打つ。
- 英語の文は打てない。英字の配列で打つ。

## 着手するときに決めること

- 初めて打つ語を、ライブ変換でカタカナと英字のどちらで出すか。語ごとに既定を持つのか、一律にするのか。
- 文の途中にある外来語を、どうやって見つけるか（Mozc の文節の区切りに頼るか、対応表で先に探すか）。
- 覚えた内容をどこに、どんな形で保存するか。
- 対応表にアプリ独自の語を足す仕組みを持つか。
