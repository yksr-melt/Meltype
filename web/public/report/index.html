問題を報告する

不具合・変換や判定の間違い・辞書に足してほしい語・改善の提案を送れます。届いた報告は開発者が読んで、直すときの手がかりにします。

  • メールアドレス・GitHub などのアカウントは必要ありません
  • スクリーンショット・録画・ログを添付できます

パスワードや個人的な文章は書かないでください。ログには直前に打った文字の一部が入ることがあります。見られたくない部分は消してから送ってください。

悪用される可能性のあるセキュリティの問題は、ここではなく GitHub の非公開の報告 に送ってください。
