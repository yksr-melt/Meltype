タイピング

お手本の日本語の文 (英語が混ざった文もあります) を、ローマ字で打ちます。打ち終わったら、打った記録を「どのキーが抜けやすいか」「どこで打ち間違えやすいか」の調査に送ることもできます (送らなくても遊べます)。日本語のローマ字入力では、こうした公開データがほとんどありません。

  • 10 文で 3 分ほど
  • 名前・メールアドレスは要りません
  • パソコンのキーボードで遊べます

スマートフォン・タブレットの画面のキーボードでは打てません。パソコンのキーボードで開いてください。

2お手本を打つ

  1. IME をオフ (半角英数) にしてください。日本語はローマ字で、英語はそのまま打ちます。「！？〜「」（）」は ! ? ~ [ ] ( )、「…」は . を 3 回打ちます
  2. 間違えたら Backspace で直しても、そのまま進んでも大丈夫です。ふだん通りに打ってください
  3. 打ち終わったら Enter で次の文へ進みます

打った記録を調査に送る

送ると、ローマ字入力の打ち間違いの調査に使われます。送らなくても、このまま続けて遊べます。

この調査は雪代 (Yukishiro) が Meltype のために行います。データの扱いについてのお問い合わせは、Meltype の Discord か GitHub の Issue へどうぞ (データを消してほしいなど、人に見られたくないお問い合わせは Discord の DM で)。

送るもの

  • いま打った文ごとの、押したキー (キーの種類・押した時刻と離した時刻)
  • はじめに答えた質問の答えと、OS の種類
  • お手本と関係ない入力が続いた文は送りません
  • 参加ごとのランダムな番号 (同じ人の打ち方をまとめて見るため)

送らないもの・使い方

  • 名前・メールアドレス・アカウントは送りません。押したキーはそのまま残るので、お手本と関係ない文字は打たないでください
  • IP アドレスはハッシュにして、回数の制限にだけ使い、1 日で消します。調査のデータには入れません
  • Meltype の打ち間違いの直し方・変換を良くするために使います。研究用のデータとして CC BY-SA 4.0 で公開することがあり、そのときも参加ごとのランダムな番号のほかに、人を特定するための手がかりは入れません

18 歳未満の方は、おうちの人に話してから送ってください。
