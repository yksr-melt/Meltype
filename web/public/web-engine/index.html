Web エンジン

あなたのサイトの入力欄に、半角/全角のいらない日本語入力を。ローマ字のまま打つだけで、日本語と英語を Meltype が見分けて変換します。判定も漢字変換もブラウザーの中で動くので、サーバーは要りません。

  • 打った文字はどこにも送りません
  • 2 行で組み込めます
  • 最初に 20 MB ほど読み込みます
<script src="/meltype/meltype.js"></script> <script>Meltype.attach(document.querySelector("textarea"));</script>

デモ

エンジンは、押したときに読み込みます (20 MB ほど)。

    Space 変換・次の候補　Enter 確定　Esc 戻る　←→ 文節を移る　1〜9 候補を選ぶ

    できること

    • 打つだけで日本語と英語を分ける

      kyouhagooglede kensakusita は「今日はgoogleで検索した」に。半角/全角を切り替えずに、英単語もそのまま打てます。

    • ブラウザーの中だけで動く

      Meltype の判定と Mozc の漢字変換を WebAssembly で動かします。サーバーは要らず、打った文字は外に送りません。

    • アプリと同じ Meltype

      Windows・Mac・Linux 版と同じ判定と辞書を使います。英単語の予測や、候補の英訳・全角・半角も出ます。

    • スマートフォンでも

      指で操作する端末では、端末のキーボードの代わりに画面の下にキーボードを出します。長押しで続けて消せて、押すと短く震えます。

    • 使うほど賢く

      選んだ変換を覚え、そのブラウザーの中に残します。次に開いたときも、前に選んだ変換が先に出ます。

    • どの入力欄にも

      <textarea>・<input>・contenteditable に付けられます。候補の欄は Shadow DOM の中に描くのでサイトの CSS と混ざらず、色と字は CSS の変数で変えられます。

    インストール

    npm にはまだ公開していません。公開するまでは、「ソースから作る」の手順で作ったものを使ってください。

    npm install meltype-web-engine
    import { attach } from "meltype-web-engine"; await attach(document.querySelector("textarea"));

    本体 (_framework/・mozc/) は index.mjs の隣から読みます。まとめるツール (バンドラー) が index.mjs だけを別の場所に移すときは、パッケージのフォルダーを丸ごと公開する場所に写し、load({ baseUrl }) でその場所を指定します。

    パッケージの中身をサイトに置き、meltype.js を読みます。本体は meltype.js の隣から読みます。

    <textarea id="text"></textarea> <script src="/meltype/meltype.js"></script> <script> Meltype.attach(document.getElementById("text")); </script>

    Mozc (漢字変換) を作るには、初回は 30 分以上かかります。作らなければ、かなのまま確定する版になります。

    git clone https://github.com/yksr-melt/Meltype.git cd Meltype dotnet workload install wasm-tools native/mozc/build-mozc-wasm.sh web-engine/build.sh

    web-engine/dist/ ができます。これがそのまま npm のパッケージで、<script> で使うときもこのフォルダーを置きます。

    API

    関数内容
    attach(element, options)入力欄に付けます。本体をまだ読んでいなければ読みます。返す物の detach() で外します
    load(options)本体だけを先に読みます。返す物 (Engine) の attach() は待たずに付けられます
    engine.clearLearning()覚えたことを消します
    loadCore(options)判定・変換・学習だけを読みます。拡張機能のページなど、ほかの場所で動かして load({ core }) で渡すときに使います
    設定既定内容
    keyboard"auto"画面のキーボードを出すか。"auto" は指で操作する端末だけ、"always"・"never"
    persisttrue覚えたことを残すか
    storageIndexedDB覚えたことの置き場 ({ get(), set(json), clear() })
    onCommit(text)確定した文字を入力欄に入れたとき
    onProgress(p)読み込みの進み具合。p.phase は "core"・"dictionary"・"ready"
    baseUrlスクリプトの隣本体を置いた場所

    見た目を変える

    :root { --meltype-accent: #e8590c; --meltype-font: "Zen Maru Gothic", sans-serif; }

    組み込むときに

    CSP
    WebAssembly を動かすため、script-src に 'wasm-unsafe-eval' が要ります。本体を別のドメインに置くときは、そのドメインも script-src・connect-src に入れます。
    配り方
    .wasm は application/wasm で配ります。別のドメインに置くときは、Access-Control-Allow-Origin を返します。
    大きさ
    最初に 20 MB ほど (圧縮後) 読み込みます。入力欄を使うページでだけ読むか、押したときに load() を呼ぶと、ほかのページを重くしません。
    ライセンス
    GPL-3.0-or-later です。エンジンはページを開いた人のブラウザーに配られるので、組み込んだサイトは、このエンジンについて GPL の条件 (ソースを手に入れられるようにするなど) を守ります。Mozc は BSD-3-Clause です。
    アプリとの違い
    AI の変換 (Zenzai) はありません。設定は初期値のままです。Mozc が覚えたこと (漢字の候補の順番) はページを閉じると忘れます。
