使い方 Windows Mac Linux

Windows・Mac・Linux で共通の機能とキー操作です。OS ごとの設定と困ったときは WINDOWS.md・MACOS.md・LINUX.md にあります。

ここに書いていない設定は、Windows では設定画面で項目にマウスを乗せると説明が出ます。Mac・Linux では、config.json と同じフォルダーの config.schema.json に設定の一覧と説明があります。


キー 動作
英字・記号 入力中の文字に足す (ローマ字はかなで表示)
Space 文節に区切って漢字に変換する。英単語で終わっているときは変換せず、確定して空白を入れる
← → 文節を選ぶ。Space を押す前でも、矢印キーで文節の選択に入る
Shift+Space (何も打っていないとき) 全角スペース (英数のときは半角)
Space / ↓ ↑ (変換中) 選んでいる文節の候補を切り替える (Shift+Space は前の候補へ)
1〜9 (変換中。上の段・テンキー) 候補の一覧の番号で選ぶ。設定「変換中の数字キーで候補を選ぶ」を OFF にすると、確定して数字を入れる
PageDown / PageUp (変換中) 候補の一覧の次 / 前のページを出す
Tab / Shift+Tab (入力中) 予測変換の候補を選ぶ。前に確定した語句・ユーザー辞書・英単語の続き (decis → decisions) などから出す
Shift + ← → (変換中) 文節の区切りを 1 文字ずらす
Enter 確定する
BackSpace / Ctrl+H かな 1 音 (きょ・っ など) ずつ消す。変換中なら変換をやめてかなに戻す
Esc 変換中なら変換をやめる。そうでなければ入力を取り消す
F6 / F7 / F8 / F9 / F10 ひらがな / カタカナ / 半角カタカナ / 全角英数 / 半角英数 にする。F9 / F10 を続けて押すと 大文字 → 先頭だけ大文字 → 小文字 と切り替わる (ai → AI → Ai → ai)
Ctrl+U / I / P / O (入力中) F6 / F7 / F9 / F10 と同じ
入力モード切り替えキー (初期: 半角/全角、Alt + `) 入力中: 日本語 ⇔ 英字。何も打っていないとき: 日本語入力 ⇔ 英数 (直接入力)。Shift+Space も登録できる (#1033)。変換中は切り替えず、上の「前の候補へ」のまま
変換 (日本語で文字を選んでいるとき) 選んだ文字を再変換する。ローマ字のまま入った文 (asita no meeting de review shimasu) は、日本語の所だけを日本語にした文 (明日の meeting で review します) にする。漢字の文は Windows だけ (読みを Windows の機能で調べる)
Space・変換・無変換・ひらがな/カタカナ (入力中) 設定の「入力中のキーの役割を分ける」が ON のとき: Space は常に候補を開く、変換は日本語を優先して変換、無変換は英字にする、ひらがな/カタカナ (Mac は かな) は ひらがな ⇔ カタカナ (変換・無変換 キーは Windows・Linux)
その他のキー・クリック 確定してから、そのキーやクリックをアプリに通す。CapsLock・NumLock・ScrollLock は確定せずに通す

無変換 / 変換・左右の Alt でのモードの切り替えは 英数状態 にあります。



基本は Microsoft IME と同じです。

  • ん: n (子音の前) / nn / xn。tanni → たんい、こんにちは は konnnichiha
  • 小書き文字: x か l を付ける (xtu ltsu → っ、xa la → ぁ、xya → ゃ)
  • そのほか: who ulo → うぉ、vu → ゔ、thi → てぃ、dhi → でぃ、ye → いぇ、wi → うぃ
  • - → ー、, → 、、. → 。、[ ] → 「」、/ → ・ (英文の続きなら半角のまま)
  • 数字だけなら半角のまま。Space で ①・一・Ⅰ・１ などの候補を出す。数字の後にかなが続けば日本語 (3ji → 3時)


打った文字のうち、英単語の部分だけを自動で英字にします。

  • ローマ字として読めない英単語はすぐ英字になる: google github hello npm
  • 日本語の中の英単語だけが英字になる: kyouhagoogledekensaku → 今日はgoogleで検索
  • 英語の固有名詞は、ローマ字として読めても英字: amazon adobe netflix
  • 大文字で打ち始めた語は英字: Tokyo、1 文字の I も英字
  • sushi repo のように英語とも日本語とも読める語は、入力欄のカーソルの前後の文字で決める: 「I love ｜ is great」→ sushi、「今日は｜」→ すし、分からないとき → すし
  • no to ga のように助詞と同じ形の 2 文字の語は、英文の途中のときだけ英字 (GitHub + no → GitHubの、I want + to → to)
  • Space を押した時点でかなにならない子音が残る英単語 (my by) は、英字で確定して空白を入れる
  • 自分で直した語を覚える: 英語とも日本語とも読める語 (api など) を F10 / 半角/全角 で英字にして確定するか、候補から打ったままの英字を選んで確定したら、次からその語は英字にする。F6 / F7 でかなにして確定したら、次からかなにする
  • 変換の候補の最後には、打ったままの英字と全角の英字も出る (あぴ → … → api → ａｐｉ)
  • 知っている英単語の最後の n の後に n + 母音を打ったときは、英単語の n と次の音に分ける (pythonnobug → pythonのbug)


設定の「判定」→「英語 / 日本語を自動で判定する」(Windows ではトレイのメニューでも) を OFF にすると、Shift で打った大文字始まりの語だけ英字にします。ほかは「Tab → google (英字に)」と提案するので、Tab で英字にします。英数状態のローマ字の検知もしません。



よくある書き間違いを打つと「もしかして: ブレスレット　で修正」と出し、Tab で正しい読みに直します。

  • 辞書 misspellings.txt にある誤り (シュミレーション → シミュレーション、バトミントン → バドミントン …)
  • 辞書にある正しい形 (5 文字以上) と、濁点・半濁点・促音・長音・小書き文字だけが違う綴り (ブレスレッド → ブレスレット)
  • 自分で足すときは dictionaries\misspellings.txt に書きます (データと辞書)


設定の「入力方式」を「かな入力 (JIS)」にすると、JIS かな配列で入力します (Shift+E = ぃ、Shift+Z = っ、Shift + ね = 、、濁点・半濁点は直前のかなに付く)。 打ったキーの英字が英単語 (google のキー → きららきりい) なら英字で見せます。かなとしても日本語になる語は、ローマ字入力と同じく前後の文脈で決めます。

設定の「かな配列」で、JIS かな以外の配列も選べます (Windows の Meltype キーボード)。

かな配列 打ち方
月配列 (U9) D・K を押してから次のキーで 2 段目、S・L を押してから次のキーで 3 段目 (前置シフト)
花配列 D・K を押してから次のキーで 2 段目 (前置シフト)
NICOLA 親指シフト。無変換が左、変換が右の親指キー
中指NICOLA NICOLA に加え、K を押したまま左手のキーを押して先に離すと左シフト、D を押したまま右手のキーを押して先に離すと右シフト (D・K を先に離したら、ふつうの文字)
TRON 配列 親指シフト。無変換が左、変換が右の親指キー
  • 親指シフトは、親指キーを押したまま文字キーを押すか、文字キーを押している間 (押してから 0.1 秒以内) に親指キーを押します。親指キーだけを押して離すと、ふつうの変換・無変換です
  • Shift を押したキーは、ふつうの英字・記号です。JIS かな以外では、打ったキーの英字を英単語として見せません

設定の「ローマ字の配列」を「SKY 配列」にすると、ローマ字入力で SKY 配列 (左手が子音、右手が母音・二重母音・撥音) を使えます。拗音は子音 + Y + 母音、促音は子音を 2 回打ちます。英語の自動判定はしません。

α版 (試験中) です。おかしな判定があれば、打ったかなと結果を Issue で教えてください。



Windows 版は、同梱の Mozc と Microsoft IME で変換します。設定の「変換エンジン」で選べます。Mac 版は azooKey、Linux 版は Mozc で変換します。

変換エンジン 動き
両方 (Mozc を優先) (既定) Mozc で変換し、Mozc が使えないときは Microsoft IME で変換する。候補の一覧は、Mozc の候補の後ろに Microsoft IME の候補 (Microsoft IME に登録した単語も) を足す
Mozc Mozc だけで変換する
Microsoft IME Microsoft IME だけで変換する
  • ライブ変換: 4 文字以上の日本語は、Space を押さなくても打ったそばから漢字で表示します (設定で OFF にできます)
  • 英単語の前後に半角スペース: 設定の「全般」で ON にすると、日本語と英単語の間に半角スペースを入れます (今日は GitHub に push した。既定は OFF)
  • 句読点: 設定の「全般」で「、。」「，．」「，。」「、．」から選べます。数字の間の . , (1.5、1,000) は半角のままです。Mac・Linux 版では config.json の "Punctuation" に Japanese (、。) / FullWidthCommaPeriod (，．) / FullWidthCommaKuten (，。) / ToutenFullWidthPeriod (、．) を書きます
  • 英字の後ろの , . も句読点にする: 英字だけを打ったとき (IME.) の , . は半角のままです。設定の「全般」で ON にすると、句読点 (IME。) にします (既定は OFF)。Mac・Linux 版では config.json の "JapanesePunctuationAfterEnglish": true で ON にします
  • 候補の一覧: 並びは 文の中での変換結果 → 変換エンジンの候補 → その文節だけでの変換結果 → 補助辞書 → ひらがな → カタカナ。英語の文節は 打ったまま → 固有名詞の正しい形 (iPhone) → 先頭大文字 → すべて大文字 → 全角
  • 括弧の候補: 括弧だけを打って Space を押すと、同じ系統の括弧を候補に出します (「」・()・{}・<> などの空のペアも選べます)
  • Meltype のバージョン: ばーじょん だけを打って変換すると、今使っている版 (Meltype-1.4.0 など) が候補に出ます。この候補や変換エンジンが出す版 (Mozc-…) を選んでも覚えず、次回の通常の「バージョン」より先や予測の候補には出ません
  • 文脈に合わせた変換: 最初の候補は次の順で決めます
    1. 文脈の手がかり辞書: 前後に手がかりの語があればその候補 (気温 → 暑い、財布 → 革、ご飯 → 箸)
    2. 学習: 前に選び直した変換
    3. 変換エンジンの結果: カーソルの前の日本語も文脈にする (この本は + あつい → 厚い)


次の読みだけを打って変換すると (きょうは のようにほかの語と続けたときは出ません)、かなの候補の後ろに日付や時刻が出ます。選んでも覚えません。

  • 「いま」「なう」: 17:22 / 17時22分 / 午後5時22分 / 2026年10月9日(金) 17時22分 など
  • 「なう」: 再生中の曲があれば、時刻より先に 曲名 / アーティスト・曲名・#NowPlaying 曲名 / アーティスト (Windows。設定「「なう」で再生中の曲を候補に出す」。曲・再生状態が変わったときに Windows から知らせを受けて読みます。メモリに今の 1 曲を持つだけで、保存・送信はしません)
  • 「とけい」「じこく」: 設定「時計の候補のタイムゾーン」の今の時刻 (19:21 / 19時21分 / 午後7時21分。空ならこの PC のタイムゾーン。America/New_York などを書くと、この PC と違うタイムゾーンなら日付とタイムゾーンの名前を付けた候補も出ます。「いま」「なう」の時刻もこのタイムゾーン)
  • 「きょう」: 2026年10月9日 / 10月9日(金) / 2026/10/09 / 2026-10-09 / 金曜日 など
  • 打った日付 (10がつ9にち): 10/9 / 10月9日(金) / 2026/10/09(金) など (年と曜日は今年として求める)


絵文字・顔文字は、変換したときの候補の一覧の最後に出ます。変換してすぐ ↑ を押すと、いちばんよく使う絵文字になり、続けて ↑ で次に進みます (えがお → 😊、かおもじ → 顔文字の一覧、ねこ → 🐱 (=^・^=)、にほん → 🇯🇵 など)。 自分で足すときは dictionaries\emoji.txt に書きます (データと辞書)。



登録した語は、変換で最優先に使います。Windows ではトレイの「ユーザー辞書...」で登録します (Mac 版は MACOS.md)。

  • 読みはローマ字でも入力できます (kigoutou → きごうとう)
  • 変換する読みの中に登録した読みが含まれていれば、その部分は登録した単語になります (きごうとう → 記号等 を登録すると、kigoutoufukume → 記号等｜含め)
  • 1 文字の読みは、その 1 文字だけを変換するときだけ使います
  • 「取り込む...」で、Microsoft IME の「一覧の出力」、Google 日本語入力のエクスポート、macOS の「ユーザ辞書」の .plist を取り込めます


英語とも日本語とも読める語を確定した後、次の語で英語か日本語かがはっきりしたら、自動で確定し直します (設定の「確定後も文脈に合わせて直す」で OFF にできます)。

  • i を確定 → 続けて want と打つ → 「I want」
  • make sure you → まけすれよう → 続けて have と打つ → 「make sure you have」
  • 英文の続きで sushi と確定 → 続けて gasuki と打つ → 「すしがすき」
  • 日本語で確定した語を英語に直すのは、その語の後ろを Space で区切ったときだけ。Enter で確定した語は、後ろに英語を続けても直しません (are ON → 「are ON」、are Enter ON → 「あれON」)
  • 候補を自分で選び直したときと、確定の後にカーソルを動かしたときは直しません


何も打っていないときに 半角/全角 を押すと英数状態になり、打った文字がそのまま入ります。

英数状態でも、単語の打ち始めの数文字でローマ字 (日本語) かを判定し、ローマ字だと分かったら日本語入力に戻して入れ直します (設定「英数状態でもローマ字を検知」で OFF にできます)。

半角/全角 は押すたびに切り替わります。英数・無変換 キーでは英数に、ひらがな/カタカナ・変換 キーでは日本語入力になります (Mac は 英数 / かな キー。親指シフトのかな配列では、無変換・変換 は親指キー)。

  • 設定「左 Alt で英数 / 右 Alt で日本語」を ON にすると、左右の Alt の単独押しで英数 / 日本語入力にします (半角/全角 キーの無い US 配列向け。既定は OFF。Windows)

英字を主に入力したいとき

設定の「英字を主に入力 (変換キー / ↓ で日本語に)」を ON にすると、自動判定をせず、打った英字をそのまま入力します。Space は空白、Enter は英字のまま確定です。日本語にしたい語は、変換キーか ↓ でローマ字として読んで変換します (sakura → 桜)。Microsoft IME の「主に英語を入力する」と同じ動きです。



入力欄・行の先頭か空白の直後に打った /review・$skill・@src/app.ts は、空白までそのままアプリに渡すので、アプリ側の補完がそのまま使えます。空白の後は、いつもの自動判定に戻ります (/review kyouha → /review 今日は)。

  • メールアドレスの @ (taro@example.com) のように前が英字・日本語のときと、かな入力のときは対象外です
  • 設定の「/ $ @ で始まる語はそのまま入力」で OFF にできます

定型文 (;名前): トレイの「定型文...」(Mac・Linux はデータフォルダの snippets.json) で名前と文 (署名・ひな形など。複数行でもよい) を登録しておくと、行の先頭か空白の直後に ;名前 と打って Space / Tab を押したときに、登録した文に置き換えます。

  • 置き換えた直後に Esc を押すと、打った ;名前 に戻します
  • 記号は設定の「定型文を出す記号」で変えられます
  • 「書き出す / 取り込む」で、別の PC に移したり、チームで同じひな形を配ったりできます
  • キャレットの前の文字をアプリから読めない入力欄では使えません

学習データ (userdict.txt・snippets.json と設定以外) は、Windows ではトレイの「学習データを消す」で消せます。

  • 「この 1 時間に覚えたもの」「今日覚えたもの」: その間に覚えたものだけを消す
  • 「すべて (リセット)」: 学習データをすべて消す
  • 1 語ずつ消すときは、トレイの「学習した語...」
  • 設定「ユーザー学習を使う」を OFF にすると、新しく覚えません

Mozc も自分の学習を mozc フォルダーに持っていて、「学習データを消す」では消えません (Meltype を終了してから mozc フォルダーを消すと消えます)。
