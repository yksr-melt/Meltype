できること

混ぜたまま打てる

英単語は英字のまま、日本語はひらがな/カタカナ/漢字に。半角/全角 キーで切り替えなくても、文の途中の英単語だけが英字になります。

コードの手も止めない

エディターやターミナルでは英数が基本で、コメントと文字列の中だけ日本語に。/command もそのまま入ります。

ぜんぶ PC の中で

判定も変換も PC の中で完結します。打った文字を外部のサーバーへ送ることはありません。

混ぜて打つ 変換 打ち間違い コード・AI アプリに合わせる 安心して使う

混ぜて打つ

打った英字を英語の部分と日本語の部分に分けて、日本語の部分だけをかなにします。

英単語は英字のまま

ローマ字として読めない語 (google npm)、固有名詞、大文字始まりの語 (Tokyo) は、途中で「ごおｇ」のようにならず英字になります。

kyouhagoogledekensaku今日はgoogleで検索

文脈で判断する

sushi のようにどちらとも読める語は、前後の文字で決めます。英文の中では to no のような短い語も英語です。

I love ＋ sushiI love sushi今日は ＋ sushi今日はすし

確定した後も直す

迷ったまま確定した語も、続きを打って分かったら確定し直します。英数のまま打ち始めても、ローマ字だと分かれば日本語に切り替えます。

i wantI want

変換を学習する

F10 で英字に、F6 でかなに直した語は、次からはその形で出ます。覚えた語はトレイの「学習した語...」で消せます。

判定の強さを選べる

積極的・標準・慎重・手動の 4 段階。手動では大文字始まりの語だけを英字にして、ほかは「Tab で英字に」と提案します。

変換

Windows では Mozc (Google 日本語入力のオープンソース版) と Microsoft IME の両方で変換し、候補に並べます。

文脈に合わせたリアルタイム変換

4 文字以上は Space を押さなくても打つそばから漢字に。前後の語や、前に選び直した変換も手がかりにします。

この本は + あつい厚い

予測変換

打っている途中に続きの候補を出し、Tab で選べます。英単語の続き (decis → decisions) も出ます。

絵文字・顔文字

候補の最後に絵文字と顔文字が並びます。変換してすぐ ↑ で絵文字に。

えがお😊ねこ🐱 (=^・^=)

英訳と意味

候補に英訳も出ます (複雑な → complex)。候補の上で少し止まると横に意味が出ます。

F6〜F10・記号・日付

F6〜F10 (と Ctrl+U I P O) でひらがな・カタカナ・英数に直せます。3ji → 3時、zh → ← の記号、「きょう」「いま」で日付と時刻も出ます。

ユーザー辞書

登録した語は最優先で使います。Microsoft IME・Google 日本語入力・macOS の辞書を取り込めて、語を選んで Ctrl+F7 ですぐ登録できます。

打ち間違い・書き間違い

打ち間違いや、よくある書き間違いに気づいて直します。

ローマ字の打ち間違い

隣のキーの押し間違い・入れ替わり・抜けを 1 文字だけ直します。

sumimasneすみません

英単語の打ち間違い

Windows の自動修正の一覧にある打ち間違いを直します。

tehtherecievereceive

もしかして

よくある書き間違いには「もしかして」を出し、Tab で正しい読みに直します。

ブレスレッドブレスレットシュミレーションシミュレーション

コード・ターミナル・AI エージェント

VS Code・Cursor・Visual Studio・JetBrains の IDE・Windows Terminal・PowerShell などは、最初から「コード」のアプリとして扱います。

コードの中は英数のまま

コードの行ではキーをそのままアプリに通すので、補完もいつもどおり効きます。

コメントと文字列だけ日本語

// # /* などのコメントと、"…" `…` の文字列の中だけ日本語を判定します。

// pythonnobug// pythonのbug

AI の入力欄とプロンプト

Copilot Chat などのチャット欄と、Claude Code・Gemini CLI の「> 」、Codex の「› 」の入力行では、通常どおり日本語を判定します。

/ $ @ や URL はそのまま

/review $skill @src/app.ts はアプリの補完に渡し、URL・メールアドレス・パスは打ったままの形で入ります。

/review kyouha/review 今日は

その行だけ日本語に

コードの行で 半角/全角 を押すと、その行は日本語で打てます。カーソルを動かすと英数に戻ります。

アプリに合わせる

アプリごと・使う場面ごとに、動き方や見た目を変えられます。

アプリ別設定・プロファイル

アプリごとに ON/OFF と種類 (一般・コード・ゲーム) を決められます。リモートデスクトップ・VM・ゲームでは最初から何もしません。設定は仕事用・趣味用などのプロファイルで切り替えられます。

定型文

;sig と打って Space で、登録した署名やひな形に置き換えます。Esc で元に戻せます。

好みのキーで切り替え

「無変換 で英数、変換 で日本語」や、左右の Alt 単独での切り替えも選べます。

句読点・空白・見た目

句読点 (「、。」「，．」など)、日本語と英単語の間の半角スペース、変換ボックスの位置・フォント・色を選べます。

安心して使う

キー入力を扱うソフトなので、打った文字の扱いには特に気をつけています。セキュリティの方針と連絡先は SECURITY.md にあります。

打った文字は送らない

判定も変換も PC の中で完結します。通信するのは自動更新の確認と、自分で開いた報告のフォームだけです。設定・学習データ・辞書は %LOCALAPPDATA%\Meltype に保存します。

入力しない場所

パスワード欄・サインインや UAC の画面・管理者として動くアプリ・シークレットウィンドウでは何もしません。

自動更新

新しい版は自動で入ります。直したことのある語の表記が変わるときは、入れる前に一覧で見せます。

学習データは自分で消せる

「この 1 時間」「今日」「すべて」の単位で消せます。バックアップして別の PC に戻すこともできます。

すべての機能と設定は docs/USAGE.md で

インストール

  1. ダウンロードMeltype-<version>-setup.exe をダウンロード
  2. 開いて進める案内どおりに進めます。途中で管理者権限の確認が出たら「はい」を選んでください (Meltype IME の登録に使います)
  3. 準備完了タスクトレイに「あ」が出たら、あとはいつもどおりローマ字で打つだけです。新しい版は自動で入ります

管理者権限の確認で「いいえ」を選んだ場合は、Meltype IME の代わりに、変換ボックスで入力する Meltype キーボードで動きます。

コード署名をしていないため、「Windows によって PC が保護されました」と出ることがあります。そのときは「詳細情報」→「実行」で進めてください。

zip 版で入れる

Meltype-<version>-windows.zip を展開して Install.cmd をダブルクリックします。インストーラーでも zip でも、入る場所は同じ %LOCALAPPDATA%\Programs\Meltype です。

必要なのは Windows 10 / 11 (64bit) と Microsoft IME だけで、.NET は同梱しています。

「ウイルスを検出しました」と出たとき

SmartScreen の警告とは別のものです。誤検知のこともありますが、検出名だけでは見分けられません。

  1. Windows セキュリティ →「ウイルスと脅威の防止」→「保護の更新」で定義を新しくする
  2. 公式のリリースからダウンロードし直して、もう一度検査する
  3. それでも検出されるときは、保護を切ったりフォルダーを除外したりせずに、「保護の履歴」で検出名を確かめて 報告 してください。個人名やパス、ダウンロード URL の一時トークンは隠してください

ファイルが本物か確かめたいときは、PowerShell で次のコマンドを実行して、リリースのページにある SHA-256 と比べてください。

Get-FileHash .\Meltype-<version>-windows.zip
アンインストール

トレイのアイコンを右クリックして「アンインストール...」を選ぶか、Windows の「設定」→「アプリ」から消せます。インストーラーで入れた場合は、最後に設定と学習データも消すかを聞かれます。zip 版は Uninstall.cmd でも消せて、こちらは設定と学習データもまとめて消えます。

Windows 版の詳しい説明

macOS 標準の IME の仕組み (Input Method Kit) で動く入力ソースです。漢字変換には azooKey を使います。Meltype.app をダブルクリックしても何も起きません。

  1. ダウンロードMeltype-<version>-mac.zip をダウンロードして、zip 全体を展開します
  2. インストーラーを開く「Install Meltype.command」をダブルクリックします
  3. 準備完了インストーラーが Meltype を登録・起動し、入力ソースを切り替えます

「開発元が未確認のため開けません」と出たら、右クリック (control + クリック) →「開く」。macOS 15 以降は、システム設定 → プライバシーとセキュリティ の「このまま開く」を押してください。

配布している zip は Apple シリコンの Mac 用です。Intel の Mac ではソースからビルドしてください。

Mac 版の詳しい説明

IBus (GNOME など) と fcitx5 (KDE など) の入力ソースとして動きます。ディストリビューションのパッケージマネージャーで入れます。

  1. インストールLinux 版の説明の「インストール」から、使っているディストリビューションの手順を端末で実行します
  2. 入力ソースを追加ログインし直してから、IBus は「設定」→「キーボード」→「入力ソース」で Meltype を追加し、fcitx5 は fcitx5-configtool で追加します

Linux 版の詳しい説明

使い始める

特別な操作は要りません。いつもどおりローマ字で打って、必要なときだけ下のキーを使います。

Meltype IME 既定

Windows の IME として動き、文字は入力欄に直接入ります。ほかの IME との切り替えは Win+Space。

Meltype キーボード

IME を登録しなかったときや ARM64 の Windows では、カーソルの下の変換ボックスで入力します。

2 つのモードはトレイのアイコンを右クリックして切り替えられます。よく使う言葉は「ユーザー辞書...」から登録できます。

Enter
確定
Space
変換して候補を選ぶ (4 文字以上は、押さなくても打つそばから漢字になります)
F7 F10
カタカナ / 英字。F10 で英字に直した語は次から英字で出ます
Tab
予測変換の候補を選ぶ。「もしかして」が出たときは正しい読みに直す

よくある質問

タスクバーの IME の表示がずっと「A」のまま

Meltype キーボードで使っているときの表示で、故障ではありません。Meltype が Windows の IME に代わって入力を受け持っているためです。

今のモードは、カーソルの近くに出る「あ」「A」か、トレイのアイコンで確認できます。

Google 日本語入力など、ほかの IME も使いたい

Meltype IME なら、Win+Space でほかの IME に切り替えられます。

Meltype キーボードのときは、Ctrl+半角/全角 で Meltype を一時停止すれば使えます。

英語のつもりがかなに、かなのつもりが英字になった

F10 (英字) か F6 (ひらがな) で直して確定すれば、次からはその形で出ます。

自動で英字にしてほしくないときは、トレイのメニューの「英語 / 日本語を自動で判定する」を OFF にすると、Shift で打った大文字始まりの語だけ英字になります。
