できること

混ぜたまま打てる

英単語は英字のまま、日本語はひらがな/カタカナ/漢字に。半角/全角 キーで切り替えなくても、文の途中の英単語だけが英字になります。

コードの手も止めない

エディターやターミナルでは英数が基本で、コメントと文字列の中だけ日本語に。/command もそのまま入ります。

ぜんぶ PC の中で

判定も変換も PC の中で完結します。外部サーバーへの転送などは行いません。

kyouhagoogledekensaku今日はgoogleで検索
ashitanomeetingwotsuika明日のmeetingを追加
I want to go to the parkI want to go to the park
混ぜて打つ 変換 打ち間違い コード・AI アプリに合わせる 安心して使う 3つの動作モード

混ぜて打つ

打った英字を英語の部分と日本語の部分に分けて、日本語の部分だけをかなにします。

英単語は英字のまま

ローマ字として読めない語 (google github npm) は、途中で「ごおｇ」のようにならず、すぐ英字になります。

kyouhagoogledekensaku今日はgoogleで検索

文脈で判断する

sushi repo のように英語とも日本語とも読める語は、カーソルの前後にある文字を見て決めます。英文の続きなら英字、日本語の続きならかなです。

I love ＋ sushiI love sushi今日は ＋ sushi今日はすし

英文は英文に

空白で区切った英単語が続く英文の中では、to no のような短い語も英語として扱います。

I want to goI want to go

固有名詞と大文字

amazon netflix のような固有名詞や、大文字で打ち始めた語 (Tokyo)、1 文字の I は英字。変換の候補には正しい書き方 (iPhone・GitHub) も出ます。

確定した後も直す

英語か日本語か分からないまま確定した語も、続きを打って分かったら自動で確定し直します。

i wantI want

変換を学習する

F10 で英字に、F6 でかなに直して確定した語は、次からその見え方で出ます。api を一度英字に直せば、日本語の文の中でも apiのerror のように出ます。不本意に覚えた語はトレイの「学習した語...」で 1 語ずつ消せます。

判定の強さを選べる

積極的・標準・慎重・手動の 4 段階から選べます。手動では、Shift で打った大文字始まりの語だけを英字にして、ほかの語には「Tab で英字に」と提案を出します。

英数のままでも気づく

英数 (直接入力) のまま打ち始めても、ローマ字だと分かった時点で入れた文字を消して日本語入力に切り替え、変換中の文字に置き換えます。

変換

Windows では、かな漢字変換に Mozc (Google 日本語入力のオープンソース版) と Microsoft IME の変換エンジンを使い、候補には両方の結果が並びます。Mozc が使えないときは Microsoft IME だけで変換します。

リアルタイム変換

4 文字以上の日本語は、Space を押さなくても打つそばから漢字になります。短い語は Space で変換します。

文脈に合わせた変換

前後の語を手がかりに最初の候補を選びます。前に選び直した変換も覚えています。

この本は + あつい厚い

予測変換

打っている途中に続きの候補を出し、Tab / Shift+Tab で選べます。前に確定した語句・ユーザー辞書・英単語の続き (decis → decisions) から探します。

絵文字・顔文字

変換の候補の最後に絵文字と顔文字が並びます。変換してすぐ ↑ を押すと、よく使う絵文字になります。

えがお😊ねこ🐱 (=^・^=)

英訳と意味

候補の後ろに英訳も出ます (複雑な → complex, complicated)。候補の上で少し止まると横に意味が出るので、同音異義語を選ぶ手がかりになります。

今日の日付・今の時刻

「きょう」「いま」を変換すると、日付や時刻のいろいろな書き方が候補に出ます。3じ15ふん を 3:15 にすることもできます。

F6〜F10 と Ctrl のキー

F6〜F10 で、ひらがな・カタカナ・半角カタカナ・全角英数・半角英数に直せます。半角カタカナ以外は Ctrl+U I P O でも直せます。英字は続けて押すと AI → Ai → ai と切り替わります。

記号・数字・単位

3ji → 3時、1.5 と 1,000 は半角のまま。zh → ←、z. → … のような z の記号も Microsoft IME と同じです。

ユーザー辞書

読みと単語を登録すると最優先で使います。Microsoft IME・Google 日本語入力・macOS の辞書を取り込めます。前面のアプリで語を選んで Ctrl+F7 を押すと、その語を入れた状態で登録の画面が開きます。

打ち間違い・書き間違い

打ち間違いや、よくある書き間違いに気づいて直します。

ローマ字の打ち間違い

読めない子音が残ったとき、隣のキーの押し間違い・入れ替わり・抜けを 1 文字だけ直します。直した結果がよく使う語の読みになるときに限ります。

sumimasneすみません

英単語の打ち間違い

Windows の自動修正の一覧にある打ち間違いを直します。

tehtherecievereceive

もしかして

よくある書き間違いがあると「もしかして」を出し、Tab で正しい読みに直します。

ブレスレッドブレスレットシュミレーションシミュレーション

コード・ターミナル・AI エージェント

VS Code・Cursor・Visual Studio・JetBrains の IDE・Windows Terminal・PowerShell などは、最初から「コード」のアプリとして扱います。

コードの中は英数のまま

コードの行ではキーをそのままアプリに通すので、補完もいつもどおり効きます。

コメントと文字列だけ日本語

カーソルの前が // # -- /* <!-- のコメントか、"…" '…' `…` の中なら日本語を判定します。#include のような指令はコメントとみなしません。

// pythonnobug// pythonのbug

AI の入力欄とプロンプト

Copilot Chat などのチャット欄と、Claude Code・Gemini CLI の「> 」、Codex の「› 」の入力行では、ふつうに日本語を判定します。

/ $ @ はそのまま

行の先頭か空白の後の /review $skill @src/app.ts は変換せずにアプリへ渡すので、アプリの補完をそのまま使えます。

/review kyouha/review 今日は

その行だけ日本語に

コードの行で 半角/全角 を押すと、その行は日本語で打てます。カーソルを別の場所に動かすと英数に戻ります。

URL やパスは打ったまま

URL・メールアドレス・ファイルのパス・@メンション は、ローマ字として読めても打ったままの形で入ります。

アプリに合わせる

アプリごと・使う場面ごとに、動き方や見た目を変えられます。

アプリ別設定

アプリごとに ON/OFF と種類 (一般・コード・ゲーム) を決められます。リモートデスクトップと VM は最初から OFF、Steam などのゲームでは何もしません。

プロファイル

仕事用・趣味用など、設定をまとめて切り替えられます。ファイルに書き出して人に渡すこともできます。

定型文

;sig と打って Space を押すと、登録した署名やひな形に置き換えます。すぐ Esc で元に戻せます。

好みのキーで切り替え

「無変換 で英数、変換 で日本語」や「左右の Alt を単独で押して切り替え」も選べます。US 配列なら Alt+` でも切り替わります。

句読点と空白

句読点は「、。」「，．」など 4 通りから選べます。確定するときに日本語と英単語の間へ半角スペースを入れることもできます (今日は GitHub に push した)。

変換ボックスの見た目

Meltype キーボードの変換ボックスの位置・文字の大きさ・フォント・色 (ライト・ダーク)・不透明度を選べます。

安心して使う

キー入力を扱うソフトなので、打った文字の扱いには特に気をつけています。

打った文字は送らない

判定も変換も PC の中で完結します。通信するのは、自動更新の確認と、自分で開いた報告のフォームだけです。

入力しない場所

パスワードの入力欄・サインインや UAC の画面・管理者として動くアプリ・ブラウザーのシークレットウィンドウでは、何もしません。

自動更新

新しい版は自動で入ります。入れる前に、自分で英字やかなに直したことのある語の見え方が変わらないかを確かめ、変わる語があれば一覧で見せます。

学習データは自分で消せる

「この 1 時間」「今日」「すべて」の単位で、覚えた語をまとめて消せます。設定と学習データはバックアップして別の PC に戻せます。

3 つの動作モード (Windows)

タスクトレイのアイコンを右クリックして選びます。判定・変換・キー操作はどれも同じです。

Meltype IME 既定

Windows の IME として動きます。打った文字は下線付きで入力欄に直接入り、候補は入力位置の下に一覧で出ます。ほかの IME とは Win+Space で切り替えます。

インストールのときに IME を登録した人に

Meltype キーボード

Meltype 自身の変換ボックスで入力します。Enter を押すまで入力欄には何も入りません。定型文や選んだ文字の再変換も使えます。

IME を登録しなかった人、ARM64 の Windows に

IME 自動切替

打ち始めの数文字から日本語と判定したときだけ Microsoft IME を ON にします。変換は Microsoft IME が行います。

変換は使い慣れた Microsoft IME のままがいい人に

インストール

  1. ダウンロードMeltype-<version>-setup.exe をダウンロード
  2. 開いて進める案内どおりに進めます。途中で管理者権限の確認が出たら「はい」を選んでください (Meltype IME の登録に使います)
  3. 準備完了タスクトレイに「あ」が出たら、あとはいつもどおりローマ字で打つだけです。新しい版は自動で入ります

管理者権限の確認で「いいえ」を選んだ場合は、Meltype IME の代わりに、変換ボックスで入力する Meltype キーボードで動きます。

コード署名をしていないため、「Windows によって PC が保護されました」と出ることがあります。そのときは「詳細情報」→「実行」で進めてください。

zip 版で入れる

Meltype-<version>-windows.zip を展開して Install.cmd をダブルクリックします。インストーラーでも zip でも、入る場所は同じ %LOCALAPPDATA%\Programs\Meltype です。

必要なのは Windows 10 / 11 (64bit) と Microsoft IME だけで、.NET は同梱しています。

「ウイルスを検出しました」と出たとき

SmartScreen の警告とは別のものです。誤検知のこともありますが、検出名だけでは見分けられません。

  1. Windows セキュリティ →「ウイルスと脅威の防止」→「保護の更新」で定義を新しくする
  2. 公式のリリースからダウンロードし直して、もう一度検査する
  3. それでも検出されるときは、保護を切ったりフォルダーを除外したりせずに、「保護の履歴」で検出名を確かめて 報告 してください。個人名やパス、ダウンロード URL の一時トークンは隠してください

ファイルが本物か確かめたいときは、PowerShell で次のコマンドを実行して、リリースのページにある SHA-256 と比べてください。

Get-FileHash .\Meltype-<version>-windows.zip
アンインストール

トレイのアイコンを右クリックして「アンインストール...」を選ぶか、Windows の「設定」→「アプリ」から消せます。インストーラーで入れた場合は、最後に設定と学習データも消すかを聞かれます。zip 版は Uninstall.cmd でも消せて、こちらは設定と学習データもまとめて消えます。

Windows 版の詳しい説明

Mac の正式な IME の仕組み (Input Method Kit) で動く「入力ソース」で、漢字変換には azooKey を使います。Meltype.app をダブルクリックしても何も起きません。

  1. ダウンロードMeltype-<version>-mac.zip をダウンロードして、zip 全体を展開します
  2. インストーラーを開く「Install Meltype.command」をダブルクリックします
  3. 準備完了インストーラーが Meltype を登録・起動して、入力ソースを選びます

「開発元が未確認のため開けません」と出たら、右クリック (control + クリック) →「開く」。macOS 15 以降は、システム設定 → プライバシーとセキュリティ の「このまま開く」を押してください。

配布している zip は Apple シリコンの Mac 用です。Intel の Mac ではソースからビルドしてください。

Mac 版の詳しい説明

Ubuntu 24.04 などの x86_64 で、IBus (GNOME など) と fcitx5 (KDE など) の入力ソースとして動きます。

  1. ダウンロードMeltype-<version>-linux.zip をダウンロードして展開します
  2. インストール展開したフォルダーで端末を開き、下のコマンドを実行します。足りない部品は自動で入ります
  3. 入力ソースを追加IBus はログインし直してから 設定 → キーボード → 入力ソース で Meltype を追加、fcitx5 は fcitx5-configtool で追加します
bash install.sh

よくある質問

タスクバーの IME の表示がずっと「A」のまま

Meltype キーボードで使っているときの表示で、故障ではありません。Meltype が Windows の IME に代わって入力を受け持っているためです。

今のモードは、カーソルの近くに出る「あ」「A」か、トレイのアイコンで確認できます。

Google 日本語入力など、ほかの IME も使いたい

Meltype IME なら、Win+Space でほかの IME に切り替えられます。

Meltype キーボードのときは、Ctrl+半角/全角 で Meltype を一時停止すれば使えます。

英語のつもりがかなに、かなのつもりが英字になった

F10 (英字) か F6 (ひらがな) で直して確定すれば、次からはその語を覚えています。

トレイのメニューの「自動判定の強さ」でも調整できます。
