# Meltype 部首・構成要素の呼び名 (呼び名<Tab>要素)。「ごんべんにふるとり」→ 誰 のように、部首の説明から漢字を探すのに使う (#345)。
# 要素は kanji-parts.txt (KRADFILE) の要素の字。単独で無い要素は、それを含む字で書く (にんべん → 化、さんずい → 汁、しんにょう → 込)。
# 呼び方の揺れ (ごんべん / ことばへん) は、行を足して同じ要素に向ける。手で書いた表。
# 呼び名は「に」でつないで打つので、呼び名の中に「に」が入ってもよい (にんべん)。読みはひらがな。
# 「と」ではつながない。字そのものの名前 (ひ・くち・かね) を「と」でつなぐと、ふだんの語 (ひとくち = ひ|と|くち) や句 (かねとひと) になる。
