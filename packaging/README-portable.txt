Meltype ポータブル版
====================

Meltype.exe を好きな場所に置いて実行してください。
この実行ファイルはアプリと .NET ランタイムを内包しているため、.NET のインストールは不要です。
起動時の展開に Windows 標準の Windows PowerShell を使います。
設定・学習データ・ログ・ユーザー辞書は、実行ファイルの隣の data に保存されます。
展開先は、Windows のユーザーアカウントで書き込みできる場所にしてください。

この版は Windows IME への登録、自動起動、アプリ内更新を行いません。
Meltype キーボード方式で動作します。起動時にアプリ一式を一時フォルダーへ展開し、終了時に削除します。
終了してからフォルダーを移動または削除すると、
この版と保存データをまとめて移動・削除できます。
通常のインストール版のデータは %LOCALAPPDATA%\Meltype に保存されます。

Meltype は GNU GPL v3 です。.NET ランタイムのライセンス・通知は、同梱の
DOTNET-LICENSE.txt、DOTNET-THIRD-PARTY-NOTICES.txt と THIRD-PARTY-NOTICES.txt を参照してください。
Mozc ヘルパーが含まれる配布物では、MOZC-LICENSE.txt、MOZC-CREDITS.html、VC-RUNTIME.txt も同梱します。
