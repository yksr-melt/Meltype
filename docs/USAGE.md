<a name="動作モード"></a>
<img src="images/headings/usage/01.svg" alt="動作モード" height="53"><br>


Meltype のタスクトレイアイコンを右クリックし、次の 2 つから選びます。Meltype IME がインストールされていない場合、そのモードは選べません。

| モード | 動き |
| --- | --- |
| **Meltype IME** (既定) | Windows の IME として、打った文字が入力欄にそのまま下線付きで入る。変換の候補は入力位置の下に一覧で出る。判定・変換・キー操作は Meltype キーボードと同じ |
| **Meltype キーボード** (Meltype IME を入れていないときの既定) | Meltype 自身の変換ボックスで入力する。ローマ字はかなに、英単語 (`google` `github` …) は自動で英字のまま。Space で漢字に変換、Enter で確定 |

動作の仕組みは [DEVELOPMENT.md](DEVELOPMENT.md#動作の仕組み)、Meltype IME の仕組みは [TSF_DESIGN.md](TSF_DESIGN.md) にあります。

<br>

<a name="meltype-ime"></a>
<img src="images/headings/usage/02.svg" alt="Meltype IME" height="53"><br>


インストールのときに管理者権限の確認に「はい」と答えると入ります (Windows に IME として登録するため)。断った場合は Meltype キーボードで動きます。
Meltype IME が無かった版から更新したときは、Meltype を起動したときに一度だけ、Meltype IME を入れるかを聞きます。

- 入れると、入力方式が Meltype に切り替わり、既定の入力方式も Meltype になります (自分で既定を決めていたときは変えません)。Microsoft IME など、ほかの IME との切り替えは **Win + Space** です
- 日本語の入力方式が Microsoft IME と Meltype の 2 つになるので、Windows の **Ctrl + Shift** (キーボード レイアウトの切り替え) でも入力方式が切り替わります。ゲームなどで Ctrl と Shift を一緒に押して切り替えの表示が出るときは、「設定」→「時刻と言語」→「入力」→「キーボードの詳細設定」→「入力言語のホット キー」→「キー シーケンスの変更」で、「キーボード レイアウトの切り替え」を「割り当てなし」にしてください
- 打った文字は入力欄にそのまま入ります。打っている途中は点線、変換した文節は細い線、選んでいる文節は太い線 (アプリによっては反転表示) の下線が付きます
- Space で変換すると、選んでいる文節の下に候補の一覧が出ます。一覧は Windows のライト / ダークの設定とアクセントの色に合わせます。候補はクリックでも選べます
- 初期登録の **半角/全角** または **Alt + &#96;** で日本語 ⇔ 英数。設定の「入力モード切り替えキー」で好きなキーに変更できます。タスクバーの「あ」「A」をクリックしても切り替わります設定の「左 Alt で英数 / 右 Alt で日本語」を ON にすると、左右の Alt の単独押しでも切り替わります (「コード」のアプリのコードの行だけを日本語にするのは入力モード切り替えキー)。
- 「入力モード切り替えキー」の登録・変更は Windows 版のみ対応しています。Mac / Linux 版には、この設定は反映されません。各 OS の既存の入力モード切り替えは引き続き使えます。
- 入力の本体は Meltype.exe (タスクトレイ) です。Meltype.exe が動いていない・一時停止中・動作モードが Meltype IME でないときは、Meltype IME を選んでいても英字がそのまま入ります
- ストアアプリでも使えます。管理者として動いているアプリ (UAC を切っている PC を除く)・サインインや UAC の画面・パスワードの入力欄・ブラウザーのシークレット / InPrivate ウィンドウの入力欄 (入力を覚えないように求める入力欄) では、安全のため何もしません (英字がそのまま入ります)
- アプリ別設定で OFF にしたアプリと、種類を「ゲーム」にしたアプリでも何もしません (変換ボックスの方式と同じ)
- IME の登録は PC 全体なので、同じ PC のほかのユーザーも Meltype を使っているときにアンインストールすると、そのユーザーの Meltype IME も使えなくなります (そのユーザーが Install.cmd か Install-Meltype.ps1 を実行し直せば戻ります)
- 種類を「コード」にしたアプリでは、Meltype キーボードと同じく、コメントと文字列の中だけ日本語を判定します ([アプリの種類 (コードエディター・ターミナル)](#アプリの種類-コードエディターターミナル))。コードの行ではタスクバーに「A」を出し、半角/全角 で日本語にできます (改行しても続く。もう一度押すか、クリック・矢印でキャレットを別の場所に動かすと戻る)
- Meltype キーボードにあった、アプリの種類ごとの「最初は英数」、カーソルの近くの「あ」「A」の表示、選んだ文字の再変換は、Meltype IME ではまだ使えません
- 不具合を調べるときは、`%LOCALAPPDATA%\Meltype` に `tip-log` という名前の空のファイルを作ると、`tip.log` に Meltype IME の動きが残ります (管理者として動いているアプリの中の動きは残りません)

<a name="meltype-キーボード"></a>
<img src="images/headings/usage/03.svg" alt="Meltype キーボード" height="53"><br>


文字入力欄で英字を打つと、カーソルの下に変換ボックスが出ます。Enter を押すまで、入力欄には何も入りません。

<a name="キー操作"></a>
<img src="images/headings/usage/s01.svg" alt="キー操作" height="40">


| キー | 動作 |
| --- | --- |
| 英字・記号 | 変換ボックスに追加する (ローマ字はかなで表示) |
| Space | 文節に区切って漢字に変換する。英単語で終わっているときは変換せず、確定して空白を入れる |
| ← → | 文節を選ぶ。Space を押す前でも、矢印キーで文節の選択に入る |
| Shift+Space (何も打っていないとき) | 全角スペース (日本語入力のとき。英数のときは半角) |
| Space / ↓ ↑ (変換中) | 選んでいる文節の候補を切り替える (Shift+Space は前の候補へ) |
| 1〜9 (変換中) | 候補の一覧の番号で選ぶ。次の文節へ進み、最後の文節なら確定する。設定「変換中の数字キーで候補を選ぶ」を OFF にすると、確定して数字を入れる (テンキーは今までどおり候補を選ぶ) |
| PageDown / PageUp (変換中) | 候補の一覧の次 / 前のページを出す (9 件ずつ) |
| Tab / Shift+Tab (入力中) | 予測変換の候補を選ぶ (Windows)。Enter で確定する。選んだまま続けて打つと、その候補で確定してから続きを入力する。選ぶのをやめるときは Esc か、Shift+Tab で選ぶ前まで戻す。前に確定した語句・ユーザー辞書・選び直した変換・英単語の続き (decis → decisions) から出す。ライブ変換が ON のときは、最後の文節の続きも出す (たんいをとる → 単位を取ることができる)。最後の文節の文字か読みで始まる候補だけ出す |
| Shift + ← → (変換中) | 文節の区切りを 1 文字ずらす |
| Enter | 確定して入力欄に入れる |
| BackSpace | かな 1 音 (きょ・っ など) ずつ消す。変換中なら変換をやめてかなに戻す |
| Esc | 変換中なら変換をやめる。そうでなければ入力を取り消す |
| Ctrl+U / I / P / O (入力中) | F6 / F7 / F9 / F10 と同じ (ひらがな / カタカナ / 全角英数 / 半角英数)。続けて押すと大文字・小文字も切り替わる |
| Ctrl+H (入力中) | BackSpace と同じ (かなを 1 音消す。変換中なら変換をやめてかなに戻す) |
| F6 / F7 / F8 / F9 / F10 | ひらがな / カタカナ / 半角カタカナ / 全角英数 / 半角英数 にする。F9 / F10 を続けて押すと 大文字 → 先頭だけ大文字 → 小文字 と切り替わる (ai → AI → Ai → ai) |
| 入力モード切り替えキー (初期: 半角/全角、Alt + `) | 変換ボックス内: 日本語 ⇔ 英字。ボックスが出ていないとき: 日本語入力 ⇔ 英数 (直接入力) |
| 無変換 / 変換 | 設定の「無変換で英数 / 変換で日本語」が ON のとき、ボックスが出ていないときに英数 / 日本語入力にする |
| 変換 (文字を選んでいるとき) | 選んだ文字を再変換する。ローマ字のまま入った文 (`asita no meeting de review shimasu`) を選んだときは、Meltype の判定で日本語の所だけを日本語にした文 (明日の meeting で review します) を候補に出し、Enter で置き換える (Meltype キーボード) |
| 左 Alt / 右 Alt (単独押し) | 設定の「左 Alt で英数 / 右 Alt で日本語」が ON のとき、ボックスが出ていないときに英数 / 日本語入力にする |
| Space・変換・無変換・ひらがな/カタカナ (入力中) | 設定の「入力中のキーの役割を分ける」が ON のとき: Space は判定にかかわらず候補を開く (英字のまま確定して空白を入れない)、変換は日本語を優先して変換、無変換は英字にする、ひらがな/カタカナ は ひらがな ⇔ カタカナ。確定は Enter (Windows・Linux) |
| その他のキー・Ctrl+… ・クリック | 確定してから、そのキーやクリックをアプリに通す |

<a name="ローマ字の綴り"></a>
<img src="images/headings/usage/s02.svg" alt="ローマ字の綴り" height="40">


基本は Microsoft IME と同じです。

- ん: `n` (子音の前) / `nn` / `xn`。`tanni` → たんい、こんにちは は `konnnichiha`
- 小書き文字: `x` か `l` を付ける (`xtu` `ltsu` → っ、`xa` `la` → ぁ、`xya` → ゃ)
- そのほか: `who` `ulo` → うぉ、`vu` → ゔ、`thi` → てぃ、`dhi` → でぃ、`ye` → いぇ、`wi` → うぃ
- `-` → ー、`,` → 、、`.` → 。 (句読点は設定で ，． などに変えられる)、`[` `]` → 「」、`/` → ・ (英文の続きなら半角のまま)。これらの記号から打ち始めても変換ボックスに入る
- 数字: 数字から打ち始めても変換ボックスに入る。数字だけなら半角のまま表示する。Space を押すと、英文の中なら確定して空白を入れ、それ以外は変換して ①・一・Ⅰ・１ などの候補を出す (1 番目は半角の数字のまま)。数字の後にかなが続けば日本語 (`3ji` → 3時)。変換エンジンが全角にした数字は半角に戻す

<a name="英語の自動判定"></a>
<img src="images/headings/usage/s03.svg" alt="英語の自動判定" height="40">


変換ボックスの中で、英単語の部分だけを自動で英字にします。

- ローマ字として読めない英単語はすぐ英字になる: `google` `github` `hello` `npm` (途中の「ごおｇぇ」にはならない)
- 日本語の中の英単語だけが英字になる: `kyouhagoogledekensaku` → 今日はgoogleで検索
- 英語の固有名詞は、ローマ字として読めても英字: `amazon` `adobe` `netflix` (辞書: `propernouns.txt`)
- 大文字で打ち始めた語は英字: `Tokyo`、1 文字の `I` も英字
- `sushi` `repo` のように英語とも日本語とも読める語は、**入力欄のカーソルの前後の文字**で決める。前後それぞれ英語なら +1・日本語なら −1 と数え、合計がプラスなら英字、それ以外は日本語
  - 「I love ｜ is great」の間 → sushi、「今日は｜」の後 → すし、前後が食い違う・分からない → すし
  - 前が**英文** (空白で区切った英単語が 2 語以上続いて空白で終わる: `I want `) なら +2。日本語の文の中の英単語 1 つ (`今日は GitHub `) は +1
  - `no` `to` `ga` のように助詞と同じ形の 2 文字の語は、+2 以上のときだけ英字 (`GitHub` + `no` → GitHubの、`I want ` + `to` → to)。`is` `at` `my` のように子音で終わる語は +1 でよい
  - 1 文字の `a` `i` は英文の途中 (+2) なら英字
- 普通の英単語 (`meeting` `tomorrow` …) は同梱の辞書に加えて **Windows の英語スペルチェッカー** (ISpellChecker, en-US) で調べる。スペルチェッカーはローマ字の語 (`kore` `sore`) も単語と見なすほど緩いので、ローマ字として読めない語と、前後の文脈で英語と分かるときだけ使う
- 小書き文字の綴り (`mala` = まぁ、`xtu` = っ) で最後まで読める語は、同梱の辞書の英単語でない限り日本語
- Space を押した時点でかなにならない子音が残る英単語 (`my` `by`) は、変換せずに英字で確定して空白を入れる
- 文脈が分からないまま日本語で確定した語は、後で英語だと分かったら確定し直す。Space で区切って続けた語はまとめて直す (`make sure you` → まけすれよう → `have` で英文と分かり `make sure you have`)。助詞と同じ形の 2 文字の語 1 つだけ (`Google と Apple`) は直さない
- ユーザーが自分で直した語を覚える: 英語とも日本語とも読める語 (api など) を F10 / 半角/全角 で英字にして確定するか、変換の候補から打ったままの英字を選んで確定したら、次からその語は英字にする (日本語の文の中でも: apiのerror)。F6 / F7 でかなにして確定したら、次からかなにする。`%LOCALAPPDATA%\Meltype\languages.json` に「打った英字 → 英語か」だけを保存し、トレイの「学習データをリセット」で消える
- 変換の候補の最後には、打ったままの英字と全角の英字も出る (あぴ → … → api → ａｐｉ)。Space を連打して英字に戻せる
- 知っている英単語 (辞書・固有名詞・覚えた語) の最後の n の後に n + 母音を打ったときは、「nn → ん」とまとめずに英単語の n と次の音に分ける (pythonnobug → pythonのbug)。日本語の語は今までどおり nn → ん (こんにちは は konnnichiha)

<a name="もしかして-書き間違いの指摘"></a>
<img src="images/headings/usage/s04.svg" alt="もしかして (書き間違いの指摘)" height="40">


変換ボックスの読みに、よくある書き間違いがあると「もしかして: ブレスレット　<Tab>で修正」を変換ボックスの打った文字のすぐ下に出し、Tab で正しい読みに直します (変換中なら直して変換し直す)。

- 辞書 `misspellings.txt` に書いた誤り (シュミレーション → シミュレーション、バトミントン → バドミントン …)
- 辞書に書いた正しい形 (5 文字以上) と、濁点・半濁点・促音 (ッ)・長音 (ー)・小書き文字だけが違う綴り (ブレスレッド、ブレースレット → ブレスレット)
- どちらの綴りも使われる語 (バイオリン / ヴァイオリン) や、誤りと同じ綴りの別の語がある組 (バック / バッグ) は入れていない
- `%LOCALAPPDATA%Meltypedictionariesmisspellings.txt` に同じ形式で書くと追加できる

<a name="自動判定の強さ"></a>
<img src="images/headings/usage/s05.svg" alt="自動判定の強さ" height="40">


トレイの「自動判定の強さ」か、設定の「判定」で選びます。Meltype キーボード (ローマ字入力・かな入力・英数状態の検知) のすべてに効きます。

| 強さ | 変換ボックス | 英数状態の検知 |
| --- | --- | --- |
| 積極的 | 英単語の先頭 (3 文字以上) や、片側が英語の短い語でも英字 | 閾値 −1 |
| 標準 (既定) | 上の規則どおり | 閾値そのまま |
| 慎重 | ローマ字として読めない英単語・大文字始まり・英文の途中の語だけ英字 | 閾値 +3 |
| 手動 | Shift で打った大文字始まりの語だけ英字。ほかは「Tab → google (英字に)」と提案し、Tab で英字にする | 検知しない |

<a name="かな入力-jisα版"></a>
<img src="images/headings/usage/s06.svg" alt="かな入力 (JIS、α版)" height="40">


かな入力は α版 (試験中) です。おかしな判定があれば、打ったかなと結果を Issue で教えてください。

設定の「入力方式」を「かな入力 (JIS)」にすると、変換ボックスに JIS かな配列で入力します (Shift+E = ぃ、Shift+Z = っ、Shift + ね = 、、濁点・半濁点は直前のかなに付く)。
打ったキーの英字 (`google` のキー → きららきりい) が英単語で、かなとしては辞書の日本語の語 (の先頭) にならなければ英字で見せます。かなとしても日本語になる語は、ローマ字入力と同じく前後の文脈で決めます。
日本語のすぐ後ろ (きょうは + google) では、辞書の 4 文字以上の英単語で、かなに 3 文字以上のよく使う語 (にかいも の にかい) が入っていないものだけを英字にします。

<a name="入力モードの表示"></a>
<img src="images/headings/usage/s07.svg" alt="入力モードの表示" height="40">


Meltype キーボードの使用中は Windows の IME を OFF にしているので、タスクバーの IME の表示は常に「A」になります。今のモードは次で知らせます。

- 入力欄 (パスワード以外) に入ったときと 半角/全角 を押したとき、カーソルの近くに「あ」(日本語) か「A」(英数) を 1.2 秒だけ出す (`ModeIndicatorWindow`、フォーカスもクリックも奪わない。設定の「入力モードをカーソルの近くに表示」で OFF にできる)
- 「あ」「A」の色は、設定の「入力モードの表示の色」(日本語・英数の背景色と文字色、`#RRGGBB`) で変えられる。英数のときだけ目立つ色 (`#D32F2F` など) にすると、英数のまま打ち始めるのを防げる
- タスクトレイのアイコン

<a name="アプリの種類-コードエディターターミナル"></a>
<img src="images/headings/usage/s08.svg" alt="アプリの種類 (コードエディター・ターミナル)" height="40">


アプリ別設定の「種類」を **コード** にしたアプリ (既定で VS Code・Cursor・Visual Studio・JetBrains の IDE・Sublime Text・Notepad++・Windows Terminal・PowerShell・コマンドプロンプトなど) では、基本は英数のまま通し、日本語を書く場所だけ判定します。

- コードの中はキーをそのままアプリへ通す (変換ボックスを出さないので、補完もそのまま効く)
- 今の行のキャレットより前がコメント (`//` `#` `--` `/* …` `<!-- …` `REM`、複数行コメントの ` * ` 行) か、文字列 (`"…` `'…` `` `… ``) の中なら、ふつうどおり日本語を判定する。`#include` `#region` のような指令や `x--` はコメントとみなさない
- 今の行は、打ったキーと確定した文字から追いかける。矢印キー・クリック・Ctrl の操作などでキャレットが動いたら、UI Automation でキャレットより前を読み直す
- コードの行で 半角/全角 を押すと、日本語で入力できる (改行しても続く。もう一度押すか、クリック・矢印でキャレットを別の場所に動かすと戻る)
- README.md などの文章ファイルを開いているとき (ウィンドウのタイトルが .md .txt など) は一般として扱う
- コメント・文字列に入ったとき / 出たときは、カーソルの近くに「あ」「A」を出して知らせる
- 「コード」のアプリでも、チャット・AI への入力欄 (VS Code の Copilot Chat、Claude Code の画面など。UI Automation の名前に chat / copilot / claude / prompt / message などが入るもの) は一般として扱う。VS Code・Cursor などの Electron 製のエディターは入力欄の種類が多いので、エディター・ターミナル・検索と分かるものだけをコードとする
- ターミナルで動く AI の入力行 (Claude Code・Gemini CLI の「> 」、Codex の「› 」) は日本語を判定する。ターミナルでは改行のたびにプロンプト (出力) を読み直す。ターミナルで 半角/全角 を押して日本語にしたら、別の場所に移るまで日本語のまま

<a name="今日の日付今の時刻"></a>
<img src="images/headings/usage/s09.svg" alt="今日の日付・今の時刻" height="40">


変換すると、候補の一覧の後ろの方 (ひらがな・カタカナの後) に日付や時刻が出ます。

- 「いま」「なう」: 17:22 / 17時22分 / 午後5時22分 / 2026年10月9日(金) 17時22分 / 10月9日(金) 17時22分 / 2026/10/09 17:22 など
- 「きょう」: 2026年10月9日 / 2026年10月9日(金) / 10月9日(金) / 2026/10/09 / 2026/10/09(金) / 10/9(金) / 2026-10-09 / 金曜日 / 20261009 など
- 打った日付 (10がつ9にち): 10/9 / 10/09 / 10/9(金) / 10月9日(金) / 2026/10/09 / 2026/10/09(金) (年と曜日は今年として求める)

<a name="絵文字顔文字"></a>
<img src="images/headings/usage/s10.svg" alt="絵文字・顔文字" height="40">


絵文字・顔文字は、変換したときの候補の一覧の最後 (ひらがな・カタカナの後ろ) にまとめて出ます。変換してすぐ ↑ を押すと、いちばんよく使う絵文字になり、続けて ↑ で次の絵文字・顔文字に進みます (えがお → ↑ で 😊、↑ で 😄 …、かおもじ → 顔文字の一覧、ねこ → 🐱 (=^・^=)、かんがえるかお → 🤔、にほん → 🇯🇵 など)。変換ボックスの候補の一覧でも、絵文字は Direct2D + DirectWrite でカラーで表示します。

- `dictionaries/emoji.txt`: 手で書いた絵文字・顔文字 (顔文字には空白や # が入るので区切りはタブ)。先に並ぶ
- `dictionaries/emoji-cldr.txt`: Unicode CLDR の絵文字の日本語の名前・キーワード (約 2,300 個の絵文字、約 5,000 の読み) から自動で作ったもの。読みは Microsoft IME の変換エンジンの逆変換で求めた (`--gen-emoji` で作り直せる)。Unicode License v3
- 読み全体が辞書の語なら (かんがえるかお)、変換エンジンが文節に分けても 1 つの文節として候補を出す
- `%LOCALAPPDATA%\Meltype\dictionaries\emoji.txt` に同じ形式で書くと追加できる

<a name="ほかの-ime-との併用"></a>
<img src="images/headings/usage/s11.svg" alt="ほかの IME との併用" height="40">


Meltype キーボードを使っている間は、Windows の IME (Microsoft IME・Google 日本語入力など) を OFF に保ちます (250ms ごとに確認)。Win+Space などで IME を切り替えると新しい IME が ON で始まることがあり、そのままだと Meltype が通したキーを IME が変換してしまうためです。IME を ON にし続ける場合は 10 秒に 3 回までで奪い合いをやめます。キーボード/IME の切り替えはログに残ります。

<a name="変換"></a>
<img src="images/headings/usage/s12.svg" alt="変換" height="40">


変換には Windows に入っている Microsoft IME の変換エンジン (IFELanguage) を使います。Meltype 自身は大きな辞書を持ちません。

- **ライブ変換**: 4 文字以上の日本語は、Space を押さなくても打ったそばから漢字で表示します。短い語は Space で変換してください (設定で OFF にできます)。
- **英単語の前後に半角スペース**: 設定の「全般」で ON にすると、確定するときに日本語と英単語の間に半角スペースを入れます (今日は GitHub に push した)。数字だけの語 (3時) と記号 (、。) の隣には入れません。最初は OFF です。
- **句読点**: 設定の「全般」で、`,` と `.` を打ったときの句読点を Microsoft IME と同じ 4 通り「、。」「，．」「，。」「、．」から選べます (論文などで「，．」を使うとき)。最初は「、。」です。かな入力の 、 。 のキーにも効きます。数字の間の `.` `,` (1.5、1,000) は半角のままです。Mac・Linux 版では `config.json` の `"Punctuation"` に `Japanese` (、。) / `FullWidthCommaPeriod` (，．) / `FullWidthCommaKuten` (，。) / `ToutenFullWidthPeriod` (、．) を書きます。
- **英字の後ろの , . も句読点にする**: 変換ボックスの中が英字だけのとき (`IME.`) は、`,` `.` を英文の記号として半角のままにします。設定の「全般」で ON にすると、英字のすぐ後ろの `,` `.` も句読点 (`IME。`、`IME、`) にします。ON でも、キャレットの前が英語のとき (`Hello ` に続けて `world.`) と、英単語の中の `.` (tetr.io) は半角のままです。最初は OFF です。Mac・Linux 版では `config.json` の `"JapanesePunctuationAfterEnglish": true` で ON にします。
- **候補の一覧**: Space や ↓ で候補を切り替え始めると、Windows 標準の変換候補 API から候補の一覧を取ります (はし → 橋・端・箸・葉氏 …)。並びは 文の中での変換結果 → Windows の候補一覧 → その文節だけでの変換結果 → 補助辞書 → ひらがな → カタカナ。英語の文節は 打ったまま → 固有名詞の正しい形 (iPhone) → 先頭大文字 → すべて大文字 → 全角。
- **括弧の候補**: 括弧だけを打って Space を押すと、同じ系統の括弧を候補に出します (「Tab で変換」が ON なら Tab でも)。片括弧は同じ側だけ、`「」`・`()`・`{}`・`<>` などの空のペアは左右をまとめて選べます。設定で指定した形を優先し、指定がなければ打った形から出します。この選択は学習しません。
- **Meltype のバージョン**: `ばーじょん` (`ba-jonn`) を変換すると、今使っている版が `Meltype-1.4.0` のように候補に出ます (Windows・Mac・Linux 共通)。
- **文脈に合わせた変換**: 最初の候補は次の順で決めます。
  1. 文脈の手がかり辞書: 前後に手がかりの語があればその候補 (気温 → 暑い、財布 → 革、ご飯 → 箸)
  2. 学習: 前に選び直した変換
  3. 変換エンジンの結果: カーソルの前の日本語 (同じ文の最大 10 文字) を文脈として渡している (この本は + あつい → 厚い)

<a name="ユーザー辞書"></a>
<img src="images/headings/usage/s13.svg" alt="ユーザー辞書" height="40">


トレイの「ユーザー辞書...」で、読みと単語を登録できます。変換では最優先に使います。

- 読みはローマ字でも入力できます (`kigoutou` → きごうとう)。読みを打つと変換候補がプルダウンに出るので、選ぶか単語欄に直接打って「登録」
- 変換する読みの中に登録した読みが含まれていれば、その部分は変換エンジンの区切りに関係なく登録した単語になります (きごうとう → 記号等 を登録すると、`kigoutoufukume` → 記号等｜含め)
- 読みは 1 文字から登録できます。1 文字の読みは、その 1 文字だけを変換するときだけ使います (ほかの語の途中では使いません)。保存先は `%LOCALAPPDATA%\Meltype\userdict.txt`
- 「取り込む...」で、Microsoft IME の「一覧の出力」、Google 日本語入力のエクスポート、macOS の「ユーザ辞書」を書き出した `.plist` を取り込めます (登録済みの語は残したまま足します)
- Mac 版の手順は [mac/README.md](../mac/README.md#ユーザー辞書) を見てください

<a name="確定した後の自動修正"></a>
<img src="images/headings/usage/s14.svg" alt="確定した後の自動修正" height="40">


英語とも日本語とも読める語 (`i` `sushi` など) を確定した後、次の語で英語か日本語かがはっきりしたら、自動で確定し直します。

- `i` を Space で変換して確定 → 続けて `want` と打つ → 「I want」 (代名詞の i は I に、Space の分の空白も入れる)
- 英文の続きで `sushi ` と確定 → 続けて `gasuki` と打つ → 「すしがすき」
- 候補を自分で選び直したとき、確定の後にカーソルが動いたとき (Meltype を通らないキーやクリック) は直しません
- 設定の「確定後も文脈に合わせて直す」で OFF にできます

<a name="英数状態-直接入力"></a>
<img src="images/headings/usage/s15.svg" alt="英数状態 (直接入力)" height="40">


変換ボックスが出ていないときに 半角/全角 を押すと英数状態になり、打った文字がそのまま入ります (トレイのアイコンが「A」になります)。

半角/全角 は押すたびに日本語入力と英数を切り替えます。押す前のモードによらず決まったモードにしたいときは、設定で次のキーも使えます (どちらも既定は OFF。変換ボックスが出ている間は切り替えず、今までどおりの働きをします)。

- 「無変換で英数 / 変換で日本語」: Mac の 英数 / かな キーのように、無変換 で英数、変換 で日本語入力にする。もう日本語入力のときの 変換 は今までどおり選択した文字の再変換
- 「左 Alt で英数 / 右 Alt で日本語」: 左右の Alt の単独押しで英数 / 日本語入力にする (半角/全角 キーの無い US 配列向け)。Alt + Tab などの組み合わせ・Alt + クリックでは切り替えない。単独押しでアプリのメニューバーに移らないよう、Alt + &#96; と同じく何もしないキー (0xE8) を送る。Meltype IME のモードでも使える

「コード」のアプリのコードの行では、変換 / 右 Alt で 半角/全角 と同じくその行を日本語にし、無変換 / 左 Alt で英数に戻します (Meltype キーボード)。

### ATOK 風の操作で使いたいとき

ATOK や、ATOK 風の設定の Microsoft IME / Google 日本語入力に慣れている方向けの対応です (ATOK 互換のキーマップを丸ごと切り替える機能はありません。次のキーを組み合わせます)。

| ATOK 風の操作 | Meltype での設定・キー |
|---|---|
| 無変換で英数、変換で日本語入力 | 設定の「無変換で英数 / 変換で日本語」を ON |
| 文節の長さを変える | 変換中に Shift + ← → (選んだ文節を 1 文字伸ばす / 縮める) |
| 文節を選ぶ | ← → (Space を押す前でも文節の選択に入れます) |
| ひらがな / カタカナ / 半角英数 にする | F6 / F7 / F10 (Ctrl + U / I / O でも同じ) |

ほかの ATOK 風の変換操作 (キーを自由に割り当てる機能など) は、Issue #828 で相談しています。

### 英字を主に入力したいとき (コマンドを多く打つ使い方)

設定の「英字を主に入力 (変換キー / ↓ で日本語に)」を ON にすると、自動判定をせず、打った英字をそのまま入力中にします。Space は空白 (`ls -la` のように 1 行を続けて打てる)、Enter は英字のまま確定です。日本語にしたい語は、変換キーか ↓ を押すと、ローマ字として読んで変換します (`sakura` → 桜・さくら・サクラ)。Microsoft IME の「主に英語を入力する」と同じ動きです (既定は OFF)。

### Zenzai (ニューラルかな漢字変換) を使う (Windows・実験)

[Zenzai](https://github.com/ensan-hcl/azooKey) (azooKey の zenz モデル) で、文脈を見てかな漢字変換します。設定の「Zenzai を使う (Windows・実験)」を ON にして、次の 2 つの場所を指定してください (既定は OFF。どちらも Meltype には同梱しません)。

1. **llama-server**: 本家の [llama.cpp のリリース](https://github.com/ggml-org/llama.cpp/releases) の `llama-server` (Windows では .exe) を使えます (b11719 の CPU 版で確かめました)。zenz のモデルは前処理が特殊 (`gpt2-small-japanese-char`) で、そのままでは本家の llama.cpp で読み込めませんが、Meltype が起動するときに `--override-kv tokenizer.ggml.pre=str:gpt-2` を付けて読み込めるようにします。
2. **モデル (GGUF)**: [Miwa-Keita/zenz-v3.1-small-gguf](https://huggingface.co/Miwa-Keita/zenz-v3.1-small-gguf) の `ggml-model-Q5_K_M.gguf` など (ライセンスは CC-BY-SA 4.0)。

Meltype が llama-server を自分で起動して (127.0.0.1 の空いているポートだけ)、読みと直前の確定済みの文字列を渡して変換します。使えないとき・0.4 秒で返らないときは、今までの変換エンジン (Mozc / Microsoft IME) で変換します。

- 変換結果は、Mozc の文節ごとの候補を選んでつなげて作れるときは、Mozc の文節の区切りで出します (文節ごとに候補を選び直せます。前に選び直して覚えた変換や、文脈の手がかり辞書などの決まりは、Zenzai の結果より優先して文節ごとに効きます。確定した文節は Mozc にも覚えさせます)。作れないとき (Mozc の候補に無い字: 鐵道 など、Mozc の文節の区切りと語の切れ目が合わないとき) は、読み全体で 1 つの文節になります。
- Space で変換して Zenzai の答えを出しているときは、変換ボックスの下の説明の行の頭に「Zenzai」と出ます (学習や選び直しで Zenzai の答えと違う文字列にした文節は数えません)。トレイのメニューには、Zenzai の今の状態 (使えます・起動中・少し休んでいます・使えません など) が出ます。
- CPU の負荷が高いときは、1 回の変換が 0.4 秒を超えることがあります。そのときは 5 秒間 Zenzai を使わず、今までの変換エンジンで変換します。常に使うと CPU の負荷が増えるので、改善を感じない場合は OFF のままにしてください (Mac 版の fork の作者からも、「ものによって改善・改善なしがあり、処理が増えると遅延が出る」という報告をいただいています)。
- GPU 版 (Vulkan・CUDA) の llama-server を指定したときは、「Zenzai: 使う GPU」に `llama-server --list-devices` で出る名前 (例: `Vulkan0`) を書くと GPU で計算し、CPU の負荷を減らせます (`--device` に渡します。GPU に載せる量は llama-server が空いているメモリに合わせて決めます)。空なら今までどおり CPU だけで計算します (既定)。変えると llama-server を起動し直します。
- llama-server は、スレッド数を 4 までに制限して起動します。計算後に CPU を使い続けないよう、引数 `--poll 0` を付け、環境変数 `KMP_BLOCKTIME` を 5 (ミリ秒) に設定します (`KMP_BLOCKTIME` を読むのは、本家の Windows の CPU 版のように LLVM / Intel の OpenMP でビルドした llama-server、`--poll` を読むのは OpenMP なしでビルドした llama-server です。MSVC の OpenMP でビルドしたものは、スレッド数の制限だけになります)。環境変数 `LLAMA_ARG_THREADS`・`KMP_BLOCKTIME` を設定している場合は、その値を使います。
- Zenzai には、Mozc / Microsoft IME より広い前の文脈 (キャレットの前の日本語の文章を、文をまたいで最大 100 文字) を渡します。文脈があるほど強く、短い読みでも、前の文があれば当たります (文脈なしの きょう → 強 が、「昨日」だけで 今日 になる)。
- 前の文脈が全く無いとき (文書の先頭など) は、文の始まりの合図「。」を文脈として渡します。何も渡さないと、モデルが迷って外れやすい (きょう → 強 / 今 / 鏡 / 京 がほぼ同じ確率) ためです。モデルが読みのまま返したとき (かんたん → かんたん) だけは使わず、今までの変換エンジンに任せます。
- 動きは、モデルを CPU で動かしたとき 1 回の変換で 20〜100 ミリ秒ほどでした (zenz-v3.1-small、ローカルでの計測)。

英数状態でも、単語の打ち始めの数文字でローマ字 (日本語) かを判定します。打った文字は判定を待たずにそのまま入り、ローマ字だと分かったら、入れた文字を消して日本語入力に戻し、変換ボックスに入れ直します。Meltype IME では入力欄に届いた文字を判定し、日本語なら変換中の文字に切り替えます。英語と分かった単語の続きと、0.7 秒打たなかった後は判定しません (設定「英数状態でもローマ字を検知」で OFF にできます)。

<a name="---で始まる語-ai-エージェントのコマンドファイル名"></a>
<img src="images/headings/usage/s16.svg" alt="/ $ @ で始まる語 (AI エージェントのコマンド・ファイル名)" height="40">


入力欄・行の先頭か空白の直後に `/` `$` `@` を打つと、記号と続く名前 (空白まで) は変換ボックスに入れず、打つたびにそのままアプリに渡します。AI エージェントの入力欄で `/review`・`$skill`・`@src/app.ts` を打つと、アプリ側の補完の候補がそのまま出て選べます。名前の後に空白を打つと、いつもの自動判定に戻ります (`/review kyouha` → /review 今日は)。

- 先頭: 入力欄に入った直後 (まだ何も打っていない)、Enter の後。Mac・Linux でアプリがキャレットの前の文字を教えてくれるときは、それで決めます
- メールアドレスの @ (`taro@example.com`) のように前が英字・日本語のときは対象外です。矢印・クリックでキャレットを動かした後も、前の文字が分からないので対象外です (Windows のコードエディター・ターミナルでは、行を読めれば対象)
- かな入力 (JIS) では対象外です (/ のキーは「め」)
- 設定の「/ $ @ で始まる語はそのまま入力」で OFF にできます (最初は ON)。OFF にすると、先頭の `///` を … に変換できます

**定型文 (`;名前`)**: トレイの「定型文...」で、名前と文 (署名・決まった返事・ひな形など。複数行でもよい) を登録しておくと、入力欄・行の先頭か空白の直後に `;名前` と打って Space / Tab を押したときに、登録した文に置き換えます (Meltype キーボード)。

- `;sig` + Space → 署名 (複数行の文は、途中で送信されないように貼り付けで入れます)
- 名前が登録したものでなければ何もしません (`;foo` + Space → `;foo `)。`for(;i<n;i++)`・`a;b` の `;` は前が空白ではないので対象外です
- 置き換えた直後に Esc を押すと、打った `;名前` に戻します
- 記号は設定の「定型文を出す記号」で変えられます (空にすると使わない)。定型文を 1 つも登録していなければ、`;` は今までどおり入力します
- 「定型文...」の画面の「書き出す / 取り込む」で、別の PC に移したり、チームで同じひな形を配ったりできます (`snippets.json` と同じ形式)
- Meltype IME・Mac・Linux ではまだ使えません

<a name="変換ボックスの見た目と位置-windows"></a>
<img src="images/headings/usage/s17.svg" alt="変換ボックスの見た目と位置 (Windows)" height="40">


トレイの「設定...」→「全般」で変えられます。変更は再起動せずに、次に変換ボックスを出したときから反映されます。

| 設定 | 選べるもの |
|---|---|
| 変換ボックスの位置 | **入力位置に重ねる** (既定。入力欄の中に打っているように見える) / **カーソルの下** / **カーソルの上** |
| 変換ボックスの文字の大きさ | 自動 (入力欄に合わせる、既定) / 小 / 中 / 大 / 特大 / 最大 |
| 変換ボックスのフォント | この PC にあるフォント (既定は Yu Gothic UI) |
| 変換ボックスの色 | **ダーク** (既定。今までの見た目) / **ライト** (白っぽい背景に黒い文字) / **Windows の設定に合わせる** (Windows の 設定 → 個人用設定 → 色 の「既定のアプリ モード」に合わせる) |
| 変換ボックスの不透明度 | 100% (既定、透けない) / 90% / 80% / 70% |

- **変換や候補の一覧が入力欄や下の行を隠すとき**は、「変換ボックスの位置」を **カーソルの上** にすると、入力位置の上に出します。候補の一覧が出て高くなっても下の端は入力位置の上のままなので、入力欄や下の行を隠しません (画面の上に入らないときだけ入力位置の下に出します)。後ろの文字を透かして見たいときは「不透明度」を下げてください
- 候補で止まったときに横に出る意味の枠は、「候補の意味を表示」を OFF にすると出なくなります
- 文字の下に小さく出る打ったキー (kyouhagoogle) は、「打ったキーを表示」を OFF にすると出なくなります
- 入力位置が分からないアプリでは、どの位置を選んでいても入力欄の下に出します。Windows の検索・スタートメニューでは、検索の画面の横に出します
- Mac・Linux 版では、これらの設定は使いません

<a name="変換ボックスが出ない場面"></a>
<img src="images/headings/usage/s18.svg" alt="変換ボックスが出ない場面" height="40">


- 文字入力欄以外 (Gmail の `j`/`k` のようなショートカット、エクスプローラー、ゲーム)。UI Automation でフォーカスのある要素を調べて判断します
- パスワード欄
- 管理者権限のアプリ、全画面のアプリ、アプリ別設定で OFF にしたアプリ (既定でリモートデスクトップと VM は OFF)
- ほかのソフトが送ったキー (AnyDesk・VNC などの遠隔操作、ULE4JIS などキー配列を変えるソフト)。設定「遠隔操作などの入力も処理する」を ON にすると、手で打ったキーと同じように処理します。ULE4JIS (JIS キーボードを US 配列で使う) は、Meltype より後に起動してください (先に起動していると、Meltype が JIS 配列のキーとして読んでしまいます)

出ない理由はトレイの「ログ / 判定理由」に「フォーカス → 入力欄ではない: …」のように残ります。

<a name="文字を打つ所なのに変換ボックスが出ないアプリ-windows"></a>
<img src="images/headings/usage/s19.svg" alt="文字を打つ所なのに変換ボックスが出ないアプリ (Windows)" height="40">


画面をすべて自分で描くアプリ (Premiere Pro など) では、文字を打つ所でも Windows に「入力欄」と伝わらず、変換ボックスが出ないことがあります。ログに「フォーカス → 入力欄ではない: …」と出ていたら、次のどちらかで打てます。

- 設定の「アプリ」→「入力欄とみなすアプリ」にプロセス名を書く (カンマ区切り。例: `Adobe Premiere Pro.exe`。プロセス名はタスクマネージャーの「詳細」タブの「名前」で分かります。「実行中のアプリから選ぶ…」で、開いているアプリから選んで足すこともできます)。そのアプリでは、入力欄と判定できなくてもフォーカスのある所を入力欄として扱います (ログでは「(入力欄とみなすアプリ)」と付きます)。既定は空です
- そのアプリだけ Meltype を止めて Windows の IME で打つ: アプリ別設定でそのアプリを OFF にするか、Ctrl + 半角/全角 で一時停止する

「入力欄とみなすアプリ」に書いたアプリでは、`V` `C` のような 1 文字のショートカットも変換ボックスに入るようになります。ショートカットを使うときは Ctrl + 半角/全角 で一時停止してください。
Meltype キーボードの使用中は、二重に変換しないよう Microsoft IME を OFF にしておきます。

<br>

<a name="タスクトレイと設定"></a>
<img src="images/headings/usage/05.svg" alt="タスクトレイと設定" height="53"><br>


- アイコン: 青い「あ」= 日本語入力、青い「A」= 英数、灰色の「A」= 一時停止
- **Ctrl + 半角/全角**、アイコンのダブルクリック、または Ctrl+Alt+F12 で一時停止/再開 (Ctrl+Alt+F12 が他のアプリと重なっていたら Ctrl+Alt+F11 → Ctrl+Shift+Alt+A → Ctrl+Alt+Pause の順に試します)
- 右クリック: 動作モードの切替、設定、ユーザー辞書、ログ / 判定理由、データフォルダを開く、学習データのリセット、アンインストール、終了
- 設定画面: ON/OFF はスイッチ (クリックか Space で切り替え)、選択肢はプルダウン、数値は数値入力、アプリ別設定は表 (ON/OFF はスイッチ) で変更します。項目にマウスを乗せると下に説明が出ます。上の「下部に説明を表示」を OFF にすると、説明の欄を消して一覧を広く使えます。「マウスホイールで値を変更」を OFF にすると、プルダウンや数値の上でホイールを回しても値は変わらず、一覧がスクロールします
- **トレイのメニューが出ないとき**: Windows の入力インジケーター (「あ」「A」。左クリックで Microsoft IME との切り替えが出るもの) と、Meltype のアイコン (青い「あ」/「A」) は別のものです。Meltype のアイコンは、タスクバーの右の「^」(隠れているインジケーター) の中に入っていることがあります。そこから右クリックしてください。それでも出ない会社の PC などでは、次のファイルを直接編集できます (Meltype を終了してから編集すると確実です)
  - ユーザー辞書: `%LOCALAPPDATA%\Meltype\userdict.txt` (1 行に「読み[Tab]単語」)
  - 設定: `%LOCALAPPDATA%\Meltype\config.json` (設定画面の項目と同じ名前)
  - データフォルダ: `%LOCALAPPDATA%\Meltype` (エクスプローラーのアドレス欄に貼り付けると開きます)
- 設定画面の「判定テスト」欄に英字を打つと、ローマ字 (日本語) か英語かの判定結果と理由を確認できます
- **プロファイル**: 仕事用・趣味用・SNS 用など、設定の値をまとめて切り替えられます。設定画面の上で作成・名前の変更・削除、トレイの右クリックの「プロファイル」で切り替え (Meltype の ON/OFF・動作モード・ログ・更新の設定はどのプロファイルでも共通)。「書き出す...」でファイル (`*.meltype-profile.json`) にして人に渡し、相手は「読み込む...」で新しいプロファイルとして足せます (アプリ別設定のプロセス名も入ります)
- **更新の前に変わる語を見せる**: 自動更新で新しい版をダウンロードしたら、入れる前に、自分で英字 / かなに直したことのある語 (`languages.json`) を今の版と新しい版の両方で判定し、見え方が変わる語があれば一覧を出します。「今のまま覚えて更新」でその語を今の見え方で覚えてから更新し、「あとで」なら今回は更新しません。判定はこの PC の中だけで行い、何も送りません (この仕組みを持つ版への更新から効きます)
- **プレリリース版の自動更新**: 設定の「更新」→「プレリリース版も自動で更新する」を ON にすると、正式版の前に公開するプレリリース版 (`1.3.1-pre.4` など) にも自動で更新します。ON にするときは、不具合や動作の不安定さが含まれることがあると確かめてから有効にします。OFF (標準) では正式版だけに更新し、ON の間にダウンロードしていたプレリリース版にも更新しません
- **リリースノート**: 新しい版に更新したあとの初めての起動で、その版のリリースノート (新しい機能・直した不具合など) を一度だけ出します。リリースノートは配布物に同梱しているので、自動更新でもインストーラーでも同じものが出ます (GitHub のリリースのページにも同じ本文を載せています)。あとから見るときは、トレイの右クリック →「更新」→「リリースノート...」(「過去のリリースノート...」で前の版のも見られます)

<br>

<a name="日本語キーボードのときだけ動作させる-windows"></a>
<img src="images/headings/usage/06.svg" alt="日本語キーボードのときだけ動作させる (Windows)" height="53"><br>


トレイの「設定...」→「全般」→「日本語キーボードのときだけ動作」を ON にして「OK」を押すと、前面の入力欄で日本語のキーボード / IME が選ばれているときだけ動作します。全プロファイル共通で、既定は OFF (従来どおり) です。変更は再起動せずに反映されます。

Win+Space などで韓国語・英語などに切り替えると、Meltype キーボードが停止し、その言語の IME の ON/OFF も変更しません。日本語に戻すと自動で再開します。判定するのは Windows の入力言語で、物理キーボードの JIS / US 配列や「あ」「A」の状態ではありません。切り替え時に残っている未確定の変換は取り消し、まだ処理していないキーはそのまま通します。

<br>

<a name="貼り付けで入力するアプリ-windows"></a>
<img src="images/headings/usage/07.svg" alt="貼り付けで入力するアプリ (Windows)" height="53"><br>


確定した文字を 1 文字ずつ送ると取り違えるアプリがあります (DaVinci Resolve で「あいうえお」→「あああああ」)。設定の「アプリ」→「貼り付けで入力するアプリ」に書いたアプリ (プロセス名、カンマ区切り。最初は `Resolve.exe`) では、クリップボードを使って貼り付けで入れます。元のクリップボードの中身は 0.5 秒後に戻します。

**Qt アプリ (LINE / OBS Studio / Telegram Desktop / DaVinci Resolve etc.) は、この設定に書かなくても自動で貼り付けになります。** Qt Windowsは、送った文字のkeyupがアプリに届かない環境 (おもにIMEの影響) で、2文字目以降を「押しっぱなしの自動リピート」と判定して最初の1文字を繰り返すことがあります。貼り付けは文字をキーとして送らないので、このバグは起きません。Qtアプリかどうかはウィンドウクラス名 (`Qt663QWindowIcon` など) で判定します。

これを無効化したいアプリがある場合は、設定「貼り付けを使わないアプリ」にプロセス名を書くと、通常通り1文字ずつ送ります。

<br>

<a name="データと辞書"></a>
<img src="images/headings/usage/08.svg" alt="データと辞書" height="53"><br>


保存場所はすべて `%LOCALAPPDATA%\Meltype\` です。打った内容をネットワークに送ることはありません (通信するのは自動更新の確認だけ。[README](../README.md) の「プライバシー」)。

| ファイル | 内容 | 持つ量 | 消し方 |
| --- | --- | --- | --- |
| `config.json` | 設定 (トレイ → 設定... から編集) | | |
| `config.schema.json` | `config.json` の項目の一覧と説明 (エディターで編集するときの補完用。起動のたびに書き直す) | | |
| `conversions.json` | 変換で選び直した結果 (文節の読み → 選んだ文字列と、最後に使った時刻)。次から最初の候補になる | 5000 件 (古いものから消す) | 1 語ずつ・最近・すべて |
| `languages.json` | ユーザーが F10 / F6 などで英字 / かなに直して確定した語 (英語か日本語か・回数・最後に使った時刻) | 3000 語 (古いものから消す) | 1 語ずつ・最近・すべて |
| `phrases.txt` | 予測変換のために覚えた、確定した語句 (読み・語句・回数・時刻) | 3000 件 (古いものから消す) | 最近・すべて |
| `translations.json` | 変換の候補から選んだ英訳 (読み → 英訳と回数) | | すべて |
| `userdict.txt` | ユーザー辞書 (1 行に「読み[Tab]単語」)。トレイの「ユーザー辞書...」で編集する | | ユーザー辞書の画面で |
| `snippets.json` | 定型文 (名前 → 文)。トレイの「定型文...」で編集する | | 定型文の画面で |
| `meltype.log` | 設定で「ファイルにログを書く」を ON にしたときだけ | | ファイルを消す |

学習データ (`userdict.txt` と設定以外) は、トレイの「学習データを消す」で消せます。

- 「この 1 時間に覚えたもの」「今日覚えたもの」: その間に覚えた (使った) 変換・英字 / かなに直した語・予測変換の語句だけを消す。一時的な入力や、間違えて覚えたものを消すとき
- 「すべて (リセット)」: 上の表の学習データをすべて消す
- 1 語ずつ消すときは、トレイの「学習した語...」
- 設定「ユーザー学習を使う」を OFF にすると、新しく覚えない

組み込みの辞書 (同梱の辞書) は別のファイルで、学習データを消しても変わりません。変換エンジン (Mozc) も自分の学習を `mozc` フォルダーに持っていて、「学習データを消す」では消えません (Meltype を終了してから `mozc` フォルダーを消すと消えます)。

組み込みの辞書は [dictionaries/](../dictionaries/) にあり、ビルド時に埋め込まれます。
`%LOCALAPPDATA%\Meltype\dictionaries\` に同じ名前・同じ形式のファイルを置くと、組み込みの辞書に追加されます (反映には再起動が必要)。

| ファイル | 形式 | 用途 |
| --- | --- | --- |
| `japanese.txt` | ローマ字の語 (ヘボン式) | 日本語の判定 |
| `english.txt` | 英単語 | 英語の判定 |
| `propernouns.txt` | 大文字小文字どおりの固有名詞 (`GitHub`) | ローマ字として読めても英語にする語と、変換候補の正しい形 |
| `candidates.txt` | `読み 候補 候補 …` | 同音異義語の補助 (Windows の候補一覧に無い語を足す) |
| `contexts.txt` | `読み 候補 : 手がかり …` | 前後に手がかりの語があればその候補を最初にする |
| `romaji.txt` | `綴り<Tab>かな` | 自分のローマ字の綴りを足す (AZIK などの拡張ローマ字)。組み込みの綴りより優先する。ユーザーのフォルダーにだけ置ける |

AZIK を使う場合は、見本 [romaji-azik-sample.txt](romaji-azik-sample.txt) (撥音拡張・二重母音拡張) を `romaji.txt` として置いてください。
英語 / 日本語の自動判定は、同梱の日本語の語の一覧 (ヘボン式) で日本語らしさを見ているので、AZIK で短く打った語 (kzji = かんじ) は
ふつうの綴りより英語と判定されやすくなります。英字になってしまうときは F6 / Shift+Space で日本語にしてください。

<a name="制限"></a>
<img src="images/headings/usage/09.svg" alt="制限" height="53"><br>


- 変換候補の一覧は Windows 標準の変換候補 API (TextConversionGenerator) から取るため、Microsoft IME の候補ウィンドウとは順番や数が違うことがあります。
- 文脈に合わせた変換は、手がかり辞書 `contexts.txt` と学習にある範囲で効きます。
- カーソルの前後の文字は UI Automation で読むため、読めないアプリでは Meltype が最後に確定した文字列で代用します。Chrome などでは UI Automation を使うことで動作が少し重くなる可能性があります。
- 32bit Windows には対応していません。
