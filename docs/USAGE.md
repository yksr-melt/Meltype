<a name="meltype-の使い方"></a>
<img src="images/headings/usage/title.svg" alt="Meltype の使い方" height="80">

Windows・Mac・Linux で共通の機能とキー操作です。OS ごとの設定と困ったときは [WINDOWS.md](WINDOWS.md)・[MACOS.md](MACOS.md)・[LINUX.md](LINUX.md) にあります。

ここに書いていない設定は、Windows では設定画面で項目にマウスを乗せると説明が出ます。Mac・Linux では、`config.json` と同じフォルダーの `config.schema.json` に設定の一覧と説明があります。

<a name="キー操作"></a>
<img src="images/headings/usage/01.svg" alt="キー操作" height="53"><br>

| キー | 動作 |
| --- | --- |
| 英字・記号 | 入力中の文字に足す (ローマ字はかなで表示) |
| Space | 文節に区切って漢字に変換する。英単語で終わっているときは変換せず、確定して空白を入れる |
| ← → | 文節を選ぶ。Space を押す前でも、矢印キーで文節の選択に入る |
| Shift+Space (何も打っていないとき) | 全角スペース (英数のときは半角) |
| Space / ↓ ↑ (変換中) | 選んでいる文節の候補を切り替える (Shift+Space は前の候補へ) |
| 1〜9 (変換中。上の段・テンキー) | 候補の一覧の番号で選ぶ。設定「変換中の数字キーで候補を選ぶ」を OFF にすると、確定して数字を入れる |
| PageDown / PageUp (変換中) | 候補の一覧の次 / 前のページを出す |
| Tab / Shift+Tab (入力中) | 予測変換の候補を選ぶ。前に確定した語句・ユーザー辞書・英単語の続き (decis → decisions) などから出す |
| Shift + ← → (変換中) | 文節の区切りを 1 文字ずらす |
| Enter | 確定する |
| BackSpace / Ctrl+H | かな 1 音 (きょ・っ など) ずつ消す。変換中なら変換をやめてかなに戻す |
| Esc | 変換中なら変換をやめる。そうでなければ入力を取り消す |
| F6 / F7 / F8 / F9 / F10 | ひらがな / カタカナ / 半角カタカナ / 全角英数 / 半角英数 にする。F9 / F10 を続けて押すと 大文字 → 先頭だけ大文字 → 小文字 と切り替わる (ai → AI → Ai → ai) |
| Ctrl+U / I / P / O (入力中) | F6 / F7 / F9 / F10 と同じ |
| 入力モード切り替えキー (初期: 半角/全角、Alt + `) | 入力中: 日本語 ⇔ 英字。何も打っていないとき: 日本語入力 ⇔ 英数 (直接入力)。Shift+Space も登録できる (`#1033`)。変換中は切り替えず、上の「前の候補へ」のまま |
| 変換 (日本語で文字を選んでいるとき) | 選んだ文字を再変換する。ローマ字のまま入った文 (`asita no meeting de review shimasu`) は、日本語の所だけを日本語にした文 (明日の meeting で review します) にする。漢字の文は、読みを Mozc で調べて再変換する (Windows と Linux の IBus。Mac・fcitx5 では、選んだ文字を Meltype が受け取れないので使えない) |
| Space・変換・無変換・ひらがな/カタカナ (入力中) | 設定の「入力中のキーの役割を分ける」が ON のとき: Space は常に候補を開く、変換は日本語を優先して変換、無変換は英字にする、ひらがな/カタカナ (Mac は かな) は ひらがな ⇔ カタカナ (変換・無変換 キーは Windows・Linux) |
| その他のキー・クリック | 確定してから、そのキーやクリックをアプリに通す。CapsLock・NumLock・ScrollLock は確定せずに通す |

無変換 / 変換・左右の Alt でのモードの切り替えは [英数状態](#英数状態-直接入力) にあります。

<br>

<a name="モードの種類"></a>
<img src="images/headings/usage/15.svg" alt="モードの種類" height="53"><br>

Meltype の動きを変える「モード」は、次の 5 つが重なっています。上から順に、上のものが優先です (上で止まっていれば、下は関係ありません)。

| モード | 種類 | 切り替え方 | 決まるもの |
| --- | --- | --- | --- |
| 動いているか | 動作中 / 一時停止 | Windows: <kbd>Ctrl</kbd> + <kbd>半角/全角</kbd>・トレイのアイコンのダブルクリック。Mac・Linux: OS の入力ソースで Meltype を選ぶ / 外す | 一時停止中は何もせず、英字がそのまま入る |
| 動作モード (Windows だけ) | Meltype IME / Meltype キーボード | トレイのメニュー ([WINDOWS.md](WINDOWS.md#動作モード)) | 入力中の文字を入力欄に直接出すか、変換ボックスに出すか。判定・変換・キー操作は同じ |
| アプリの種類 | 一般 / コード / ゲーム・OFF / 独自の種類 | 設定の「アプリ」→「アプリ別設定」 (コードエディター・ターミナルは最初から「コード」) | コード: 基本は英数で、コメントと文字列の中だけ日本語を判定する。OFF: 何もしない。ゲーム: Meltype キーボードは何もしない。Meltype IME は英数で始め、英数ではキーを横取りしない (チャットでは 半角/全角 で日本語にでき、Enter で確定・Esc で取り消すと英数に戻る) |
| 入力モード | 日本語入力 / 英数 (直接入力) | 何も打っていないときに 半角/全角 (Alt + &#96;)・英数 / 無変換・かな / 変換 キー | 英数では打った文字がそのまま入る (ローマ字だと分かったら日本語入力に戻す。[英数状態](#英数状態-直接入力)) |
| 入力中の表示 | 自動 / 日本語 / 英字 | 入力中に 半角/全角 (日本語 ⇔ 英字)、F6〜F10 (ひらがな・カタカナ・英数)、Tab (英字の提案) | その打ちかけだけを、自動判定に任せるか、決めた文字にするか。確定すると自動に戻る |

- 今の入力モードはタスクバー・メニューバーの「あ」「A」で見分けます (Windows の Meltype キーボードは [WINDOWS.md](WINDOWS.md#今のモード-日本語--英数-の見分け方))
- パスワードの入力欄・管理者として動くアプリ (Windows) などでは、どのモードでも何もしません
- 設定「英字を主に入力」が ON のときは、日本語入力でも自動判定をせず、打った英字をそのまま入れます ([英字を主に入力したいとき](#英字を主に入力したいとき))

<br>

<a name="ローマ字の綴り"></a>
<img src="images/headings/usage/02.svg" alt="ローマ字の綴り" height="53"><br>

基本は Microsoft IME と同じです。

- ん: `n` (子音の前) / `nn` / `xn`。`tanni` → たんい、こんにちは は `konnnichiha`
- 小書き文字: `x` か `l` を付ける (`xtu` `ltsu` → っ、`xa` `la` → ぁ、`xya` → ゃ)
- そのほか: `who` `ulo` → うぉ、`vu` → ゔ、`thi` → てぃ、`dhi` → でぃ、`ye` → いぇ、`wi` → うぃ
- `-` → ー、`,` → 、、`.` → 。、`[` `]` → 「」、`/` → ・ (英文の続きなら半角のまま)
- 数字だけなら半角のまま。Space で ①・一・Ⅰ・１ などの候補を出す。数字の後にかなが続けば日本語 (`3ji` → 3時)
- 何も打っていないときのテンキーの数字と記号は、変換ボックスに入れず、半角でそのまま入ります (Excel・CAD などで数値を打つとき)。入力中なら変換ボックスに入ります

<br>

<a name="英語の自動判定"></a>
<img src="images/headings/usage/03.svg" alt="英語の自動判定" height="53"><br>

打った文字のうち、英単語の部分だけを自動で英字にします。

- ローマ字として読めない英単語はすぐ英字になる: `google` `github` `hello` `npm`
- 日本語の中の英単語だけが英字になる: `kyouhagoogledekensaku` → 今日はgoogleで検索
- 英語の固有名詞は、ローマ字として読めても英字: `amazon` `adobe` `netflix`
- 大文字で打ち始めた語は英字: `Tokyo`、1 文字の `I` も英字
- `sushi` `repo` のように英語とも日本語とも読める語は、入力欄のカーソルの前後の文字で決める: 「I love ｜ is great」→ sushi、「今日は｜」→ すし、分からないとき → すし
- `no` `to` `ga` のように助詞と同じ形の 2 文字の語は、英文の途中のときだけ英字 (`GitHub` + `no` → GitHubの、`I want ` + `to` → to)
- Space を押した時点でかなにならない子音が残る英単語 (`my` `by`) は、英字で確定して空白を入れる
- 自分で直した語を覚える: 英語とも日本語とも読める語 (api など) を F10 / 半角/全角 で英字にして確定するか、候補から打ったままの英字を選んで確定したら、次からその語は英字にする。F6 / F7 でかなにして確定したら、次からかなにする
- 変換の候補の最後には、打ったままの英字と全角の英字も出る (あぴ → … → api → ａｐｉ)
- 知っている英単語の最後の n の後に n + 母音を打ったときは、英単語の n と次の音に分ける (pythonnobug → pythonのbug)

<br>

<a name="自動判定を使わない"></a>
<img src="images/headings/usage/04.svg" alt="自動判定を使わない" height="53"><br>

設定の「判定」→「英語 / 日本語を自動で判定する」(Windows ではトレイのメニューでも) を OFF にすると、Shift で打った大文字始まりの語だけ英字にします。ほかは「Tab → google (英字に)」と提案するので、Tab で英字にします。[英数状態のローマ字の検知](#英数状態-直接入力)もしません。

<br>

<a name="もしかして-書き間違いの指摘"></a>
<img src="images/headings/usage/05.svg" alt="もしかして (書き間違いの指摘)" height="53"><br>

よくある書き間違いを打つと「もしかして: ブレスレット　<Tab>で修正」と出し、Tab で正しい読みに直します。

- 辞書 `misspellings.txt` にある誤り (シュミレーション → シミュレーション、バトミントン → バドミントン …)
- 辞書にある正しい形 (5 文字以上) と、濁点・半濁点・促音・長音・小書き文字だけが違う綴り (ブレスレッド → ブレスレット)
- 自分で足すときは `dictionaries\misspellings.txt` に書きます ([データと辞書](#データと辞書))

<br>

<a name="かな入力-jisα版"></a>
<img src="images/headings/usage/06.svg" alt="かな入力 (JIS、α版)" height="53"><br>

設定の「入力方式」を「かな入力 (JIS)」にすると、JIS かな配列で入力します (Shift+E = ぃ、Shift+Z = っ、Shift + ね = 、、濁点・半濁点は直前のかなに付く)。
打ったキーの英字が英単語 (`google` のキー → きららきりい) なら英字で見せます。かなとしても日本語になる語は、ローマ字入力と同じく前後の文脈で決めます。

設定の「かな配列」で、JIS かな以外の配列も選べます (Windows の Meltype キーボード)。

| かな配列 | 打ち方 |
| --- | --- |
| 月配列 (U9) | D・K を押してから次のキーで 2 段目、S・L を押してから次のキーで 3 段目 (前置シフト) |
| 花配列 | D・K を押してから次のキーで 2 段目 (前置シフト) |
| NICOLA | 親指シフト。無変換が左、変換が右の親指キー |
| 中指NICOLA | NICOLA に加え、K を押したまま左手のキーを押して先に離すと左シフト、D を押したまま右手のキーを押して先に離すと右シフト (D・K を先に離したら、ふつうの文字) |
| TRON 配列 | 親指シフト。無変換が左、変換が右の親指キー |

- 親指シフトは、親指キーを押したまま文字キーを押すか、文字キーを押している間 (押してから 0.1 秒以内) に親指キーを押します。親指キーだけを押して離すと、ふつうの変換・無変換です
- Shift を押したキーは、ふつうの英字・記号です。JIS かな以外では、打ったキーの英字を英単語として見せません

設定の「ローマ字の配列」を「SKY 配列」にすると、ローマ字入力で SKY 配列 (左手が子音、右手が母音・二重母音・撥音) を使えます。拗音は子音 + Y + 母音、促音は子音を 2 回打ちます。英語の自動判定はしません。

α版 (試験中) です。おかしな判定があれば、打ったかなと結果を Issue で教えてください。

<br>

<a name="変換"></a>
<img src="images/headings/usage/07.svg" alt="変換" height="53"><br>

どの OS でも、同梱の Mozc で変換します。Windows・Mac 版は、Zenzai (ニューラルかな漢字変換) で前の文脈も見て変換します。

- **ライブ変換**: 4 文字以上の日本語は、Space を押さなくても打ったそばから漢字で表示します (設定で OFF にできます)
- **英単語の前後に半角スペース**: 設定の「全般」で ON にすると、日本語と英単語の間に半角スペースを入れます (今日は GitHub に push した。既定は OFF)
- **句読点**: 設定の「全般」で「、。」「，．」「，。」「、．」から選べます。数字の間の `.` `,` (1.5、1,000) は半角のままです。Mac・Linux 版では `config.json` の `"Punctuation"` に `Japanese` (、。) / `FullWidthCommaPeriod` (，．) / `FullWidthCommaKuten` (，。) / `ToutenFullWidthPeriod` (、．) を書きます
- **英字の後ろの , . も句読点にする**: 英字だけを打ったとき (`IME.`) の `,` `.` は半角のままです。設定の「全般」で ON にすると、句読点 (`IME。`) にします (既定は OFF)。Mac・Linux 版では `config.json` の `"JapanesePunctuationAfterEnglish": true` で ON にします
- **候補の一覧**: 並びは 文の中での変換結果 → 変換エンジンの候補 → その文節だけでの変換結果 → 補助辞書 → ひらがな → カタカナ → 分野の辞書 (医療・情報・駅名・固有名詞・人名・一般の語・法令名)。英語の文節は 打ったまま → 固有名詞の正しい形 (iPhone) → 先頭大文字 → すべて大文字 → 全角
- **括弧の候補**: 括弧だけを打って Space を押すと、同じ系統の括弧を候補に出します (`「」`・`()`・`{}`・`<>` などの空のペアも選べます)
- **Meltype のバージョン**: `ばーじょん` だけを打って変換すると、今使っている版と OS・入力方式 (`Meltype-1.5.1 (Windows / Meltype IME)` など) が候補に出ます。不具合の報告に貼ってください。この候補や変換エンジンが出す版 (`Mozc-…`) を選んでも覚えず、次回の通常の「バージョン」より先や予測の候補には出ません
- **文脈に合わせた変換**: 最初の候補は次の順で決めます
  1. 文脈の手がかり辞書: 前後に手がかりの語があればその候補 (気温 → 暑い、財布 → 革、ご飯 → 箸)
  2. 学習: 前に選び直した変換
  3. 変換エンジンの結果: カーソルの前の日本語も文脈にする (この本は + あつい → 厚い)

<br>

<a name="今日の日付今の時刻"></a>
<img src="images/headings/usage/08.svg" alt="今日の日付・今の時刻" height="53"><br>

次の読みだけを打って変換すると (`きょうは` のようにほかの語と続けたときは出ません)、かなの候補の後ろに日付や時刻が出ます。選んでも覚えません。

- 「いま」「なう」: 17:22 / 17時22分 / 午後5時22分 / 2026年10月9日(金) 17時22分 など
- 「なう」: 再生中の曲があれば、時刻より先に `曲名 / アーティスト`・曲名・`#NowPlaying 曲名 / アーティスト` (Windows。設定「「なう」で再生中の曲を候補に出す」。曲・再生状態が変わったときに Windows から知らせを受けて読みます。メモリに今の 1 曲を持つだけで、保存・送信はしません)
- 「とけい」「じこく」: 設定「時計の候補のタイムゾーン」の今の時刻 (19:21 / 19時21分 / 午後7時21分。空ならこの PC のタイムゾーン。`America/New_York` などを書くと、この PC と違うタイムゾーンなら日付とタイムゾーンの名前を付けた候補も出ます。「いま」「なう」の時刻もこのタイムゾーン)
- 「きょう」: 2026年10月9日 / 10月9日(金) / 2026/10/09 / 2026-10-09 / 金曜日 など
- 打った日付 (10がつ9にち): 10/9 / 10月9日(金) / 2026/10/09(金) など (年と曜日は今年として求める)
- 金額と通貨 (100どる、1まんえんをゆーろ): 別の通貨に換算した額 (100どる → 約1.6万円。古いレートの概算なので、有効数字 2 桁に丸める) と、そのレートの日付を付けた候補。レートは、その版を出したときの欧州中央銀行 (ECB) の参照レート。通貨だけなら円に、円ならドルとユーロに換算し、「〜を〜」で換算先を決められる (どる・ゆーろ・ぽんど・げん・うぉん・すいすふらん・かなだどる・ごうどる・ほんこんどる・しんがぽーるどる・ばーつ・るぴー・えん)

<br>

<a name="絵文字顔文字"></a>
<img src="images/headings/usage/09.svg" alt="絵文字・顔文字" height="53"><br>

絵文字・顔文字は、変換したときの候補の一覧の最後に出ます。変換してすぐ ↑ を押すと、いちばんよく使う絵文字になり、続けて ↑ で次に進みます (えがお → 😊、かおもじ → 顔文字の一覧、ねこ → 🐱 (=^・^=)、にほん → 🇯🇵 など)。
自分で足すときは `dictionaries\emoji.txt` に書きます ([データと辞書](#データと辞書))。

<br>

<a name="ユーザー辞書"></a>
<img src="images/headings/usage/10.svg" alt="ユーザー辞書" height="53"><br>

登録した語は、変換で最優先に使います。Windows ではトレイの「ユーザー辞書...」で登録します (Mac 版は [MACOS.md](MACOS.md#ユーザー辞書))。

- 読みはローマ字でも入力できます (`kigoutou` → きごうとう)
- 変換する読みの中に登録した読みが含まれていれば、その部分は登録した単語になります (きごうとう → 記号等 を登録すると、`kigoutoufukume` → 記号等｜含め)
- 1 文字の読みは、その 1 文字だけを変換するときだけ使います
- 「取り込む...」で、Microsoft IME の「一覧の出力」、Google 日本語入力のエクスポート、macOS の「ユーザ辞書」の `.plist` を取り込めます

<br>

<a name="確定した後の自動修正"></a>
<img src="images/headings/usage/11.svg" alt="確定した後の自動修正" height="53"><br>

英語とも日本語とも読める語を確定した後、次の語で英語か日本語かがはっきりしたら、自動で確定し直します (設定の「確定後も文脈に合わせて直す」で OFF にできます)。

- `i` を確定 → 続けて `want` と打つ → 「I want」
- `make sure you` → まけすれよう → 続けて `have` と打つ → 「make sure you have」
- 英文の続きで `sushi ` と確定 → 続けて `gasuki` と打つ → 「すしがすき」
- 日本語で確定した語を英語に直すのは、その語の後ろを Space で区切ったときだけ。Enter で確定した語は、後ろに英語を続けても直しません (`are ON ` → 「are ON」、`are` Enter `ON ` → 「あれON」)
- 候補を自分で選び直したときと、確定の後にカーソルを動かしたときは直しません

<br>

<a name="英数状態-直接入力"></a>
<img src="images/headings/usage/12.svg" alt="英数状態 (直接入力)" height="53"><br>

何も打っていないときに 半角/全角 を押すと英数状態になり、打った文字がそのまま入ります。

英数状態でも、単語の打ち始めの数文字でローマ字 (日本語) かを判定し、ローマ字だと分かったら日本語入力に戻して入れ直します (設定「英数状態でもローマ字を検知」で OFF にできます)。

半角/全角 は押すたびに切り替わります。英数・無変換 キーでは英数に、ひらがな/カタカナ・変換 キーでは日本語入力になります (Mac は 英数 / かな キー。親指シフトのかな配列では、無変換・変換 は親指キー)。

- 設定「左 Alt で英数 / 右 Alt で日本語」を ON にすると、左右の Alt の単独押しで英数 / 日本語入力にします (半角/全角 キーの無い US 配列向け。既定は OFF。Windows)

### Ctrl + 英字に好きなキーを割り当てる

F キーが打ちにくいノートパソコンなどでは、設定の「Control キーの個別の割り当て」で、入力中の Ctrl + 英字に F6〜F10 などの働きを割り当てられます。書き方と使えるキー名は、設定の説明にあります。たとえば Microsoft IME と同じにするなら `U=F6;I=F7;O=F8;P=F9;T=F10` です。

### ATOK 風の操作で使いたいとき

| ATOK 風の操作 | Meltype での設定・キー |
|---|---|
| 無変換で英数、変換で日本語入力 | そのまま使えます |
| 文節の長さを変える | 変換中に Shift + ← → |
| 文節を選ぶ | ← → (Space を押す前でも文節の選択に入れます) |
| ひらがな / カタカナ / 半角英数 にする | F6 / F7 / F10 (Ctrl + U / I / O でも同じ) |

### 英字を主に入力したいとき

設定の「英字を主に入力 (変換キー / ↓ で日本語に)」を ON にすると、自動判定をせず、打った英字をそのまま入力します。Space は空白、Enter は英字のまま確定です。日本語にしたい語は、変換キーか ↓ でローマ字として読んで変換します (`sakura` → 桜)。Microsoft IME の「主に英語を入力する」と同じ動きです。

<a name="---で始まる語-ai-エージェントのコマンドファイル名"></a>
<img src="images/headings/usage/13.svg" alt="/ $ @ で始まる語 (AI エージェントのコマンド・ファイル名)" height="53"><br>

入力欄・行の先頭か空白の直後に打った `/review`・`$skill`・`@src/app.ts` は、空白までそのままアプリに渡すので、アプリ側の補完がそのまま使えます。空白の後は、いつもの自動判定に戻ります (`/review kyouha` → /review 今日は)。

- メールアドレスの @ (`taro@example.com`) のように前が英字・日本語のときと、かな入力のときは対象外です
- 設定の「/ $ @ で始まる語はそのまま入力」で OFF にできます

**定型文 (`;名前`)**: トレイの「定型文...」(Mac・Linux はデータフォルダの `snippets.json`) で名前と文 (署名・ひな形など。複数行でもよい) を登録しておくと、行の先頭か空白の直後に `;名前` と打って Space / Tab を押したときに、登録した文に置き換えます。

- 置き換えた直後に Esc を押すと、打った `;名前` に戻します
- 記号は設定の「定型文を出す記号」で変えられます
- 「書き出す / 取り込む」で、別の PC に移したり、チームで同じひな形を配ったりできます
- キャレットの前の文字をアプリから読めない入力欄では使えません

<a name="データと辞書"></a>
<img src="images/headings/usage/14.svg" alt="データと辞書" height="53"><br>

設定と学習データは次のフォルダーに保存します。

- Windows: `%LOCALAPPDATA%\Meltype`
- Mac: `~/Library/Application Support/Meltype`
- Linux: `~/.local/share/Meltype`

| ファイル | 内容 | 持つ量 |
| --- | --- | --- |
| `config.json` | 設定 | |
| `config.schema.json` | `config.json` の項目の一覧と説明 (エディターで編集するときの補完用) | |
| `conversions.json` | 変換で選び直した結果。次から最初の候補になる | 5000 件 |
| `languages.json` | 英字 / かなに直して確定した語 | 3000 語 |
| `phrases.txt` | 予測変換のために覚えた語句 | 3000 件 |
| `translations.json` | 変換の候補から選んだ英訳 | |
| `userdict.txt` | ユーザー辞書 (1 行に「読み[Tab]単語」) | |
| `snippets.json` | 定型文 | |
| `meltype.log` | 設定で「ファイルにログを書く」を ON にしたときのログ | |
| `crash.log` | Meltype が異常終了したときの記録。設定にかかわらず書く | |
| `update\install.log` | Windows の自動更新のインストールの記録 (版・OS・工程・失敗の理由)。設定にかかわらず書く。利用者名・コンピューター名・パスは環境変数の名前に置き換える。途中で強制終了されると次の更新まで置き換わらないので、貼る前に確かめる | 1 MB で `install.old.log` へ移す |

学習データ (`userdict.txt`・`snippets.json` と設定以外) は、Windows ではトレイの「学習データを消す」で消せます。

- 「この 1 時間に覚えたもの」「今日覚えたもの」: その間に覚えたものだけを消す
- 「すべて (リセット)」: 学習データをすべて消す
- 1 語ずつ消すときは、トレイの「学習した語...」
- 設定「ユーザー学習を使う」を OFF にすると、新しく覚えません

Mozc も自分の学習を `mozc` フォルダーに持っていて、「学習データを消す」では消えません (Meltype を終了してから `mozc` フォルダーを消すと消えます)。

同梱の辞書は [dictionaries/](../dictionaries/) にあります。データのフォルダーの `dictionaries` に同じ名前・同じ形式のファイルを置くと、同梱の辞書に足せます (反映には再起動が必要)。

| ファイル | 形式 | 用途 |
| --- | --- | --- |
| `japanese.txt` | ローマ字の語 (ヘボン式) | 日本語の判定 |
| `english.txt` | 英単語 | 英語の判定 |
| `propernouns.txt` | 大文字小文字どおりの固有名詞 (`GitHub`) | ローマ字として読めても英語にする語と、変換候補の正しい形 |
| `candidates.txt` | `読み 候補 候補 …` | 変換の候補に足す語 |
| `contexts.txt` | `読み 候補 : 手がかり …` | 前後に手がかりの語があればその候補を最初にする |
| `misspellings.txt` | `誤り<Tab>正しい形` (読みで書く) | [もしかして](#もしかして-書き間違いの指摘) |
| `emoji.txt` | `読み<Tab>候補<Tab>候補 …` | [絵文字・顔文字](#絵文字顔文字) |
| `romaji.txt` | `綴り<Tab>かな` | 自分のローマ字の綴り (AZIK など)。組み込みの綴りより優先する |

AZIK を使うときは、見本 [romaji-azik-sample.txt](romaji-azik-sample.txt) を `romaji.txt` として置いてください。AZIK で短く打った語 (kzji = かんじ) は英語と判定されやすいので、英字になったときは F6 で日本語にしてください。
