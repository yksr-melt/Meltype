# Meltype v1.4.0

v1.3.0 からの変更をまとめた正式版です。pre 版 (1.3.1-pre.1〜pre.3) で試した内容と、その後の修正が入っています。

## 大きな変更
- **ニューラルかな漢字変換 Zenzai (zenz + llama-server) を設定で使えるようになりました (Windows)**。初期状態では OFF です。
  - 文をまたいで最大 100 文字の前の文脈を使って変換します
  - 自信の低い答え・応答が遅いとき (400ms 超)・文脈の無い短い読みでは、今までの変換エンジンに任せます
  - Zenzai の結果を Mozc の文節に当てはめるので、文節の区切り直しもいつもどおりできます
  - OFF にするとサーバーを止めます。Meltype が強制終了されても llama-server は残りません
- **Linux で dnf (.rpm) から入れられるようになりました**。apt と同じく GitHub Pages のリポジトリから更新できます。
- **Mozc-UT の辞書を使ったヘルパーをビルドできるようになりました** (`MELTYPE_UT_DICTIONARY`)。使い方とライセンスは docs/MOZC-UT.md にあります。

## 新しい設定
- 入力モード切り替えキーを複数登録できるようにしました。CapsLock と JIS の `英数` キーも使えます
  - 古い設定は自動で新しい一覧に移します。使えないキーは外して通知します
  - Control キーの割り当てと切り替えキーがぶつかるときは知らせます
- 変換中に数字キーで確定して、そのまま数字を入力できるようにしました
- 日本語と半角数字の間に半角スペースを入れる設定を足しました
- `z` + 記号・hjkl の記号・矢印を OFF にできるようにしました

## 変換・入力の改善
- 変換中の `PageDown` / `PageUp` で候補の一覧のページを送れるようにしました
- 日付の候補に曜日付きの形を足しました
- 文章の入力欄で、打ち始めの `/` を `・` にするようにしました。コードエディター・ターミナルでも、コメントと文字列の中なら同じように `・` にします
- 同梱の辞書で文節の区切りを書けるようにしました
- 辞書の追加・修正
  - 出るように: 一学期・二学期・県立・乾燥率・todoリスト・シリーズ・Meltype・ブルーアーカイブ・蜜柑星・→
  - 出ないように: 担った (になった)・無點そう (なさそう)・下ので (したので)・土下の (どしたの)・呂会 (りょかい)・共久しぶり (きょうひさしぶり)
  - `claudecode` は英字のままにします

## 英語と日本語の判定
- `Androidwa` → Androidわ、`Androidha` → Androidは のように、英単語の最後の d / t のあとを分けるようにしました
- 読み切れる英単語のすぐ後ろが「ん」なら、日本語の途中として扱うようにしました
- 短い英単語に続く日本語の区切りを保つようにしました (#1132)
- 確定時の未変換の子音も英語の判定に含めるようにしました
- `kamiwoA4` → かみをA4、`huusoku6me-toru` → ふうそく6めーとる、`nottotte` → のっとって のように、名前・略語・英語への誤判定を直しました
- `galaxyS24`・`e2e`・`ppt` の前の to など、今まで正しく判定できていた形は変わらないようにしています
- ローマ字として読める英単語を辞書に足しました

## 速さ・メモリ
- 組み込み辞書・スペルチェッカー・意味と英訳の辞書の持ち方を見直し、メモリを減らしました
- 確定のたびの学習データの書き直しと、予測変換の全件の走査をやめました
- Windows のスペルチェッカーへの問い合わせを 1 回にまとめ、専用のスレッドで行うようにしました
- IME の設定の取得を非同期にして、打鍵中に待たないようにしました

(どれも出る候補や判定は変わりません)

## 不具合の修正
- **Windows**
  - Zenzai を ON にすると日本語を打てなくなる問題を直しました (#973)
  - 変換中の F6〜F10 が、文節の長さを変えたあとなどに文全体に効いてしまう問題を直しました
  - IME が無効のときも、半角/全角の誤入力を防ぐようにしました
- **Linux (fcitx5)**
  - 動いている fcitx5 に Meltype を読み直させるようにしました。読み込ませられないときの手順を docs に書きました
  - ターミナルでの入力中の文字と、日本語への切り替えが崩れる問題を直しました
  - IM の切り替えやモードの解除で、コードの保護と文脈が外れる問題を直しました
- **Mac**
  - 入力ソースのアイコンの大きさと Retina 表示を直しました
  - 入れ替え直後に起動の失敗と誤って扱う問題を直しました
