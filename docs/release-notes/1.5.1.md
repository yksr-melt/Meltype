# Meltype v1.5.1

v1.5.0 の修正版です。入力・変換の不具合を直し、通貨の換算候補を追加しました。Windows では、アプリを起動し直さなくても Meltype IME を新しい版に入れ替えられるようになりました。

## 新しい機能

- **金額と通貨の読みに、円に換算した額を候補に出します**。例: 「100どる」で「約○○円」。レートはリリースのときに作った表を同梱し、ネットには接続しません (#1785)。
- **Windows: アプリを起動し直さなくても、Meltype IME を新しい版に入れ替えられるようにしました**。更新前の Meltype IME を読み込んだままのアプリが見つかったときは、再起動を案内します (#1753, #1767)。

## 入力・変換の改善

- 何も打っていないときのテンキーは、変換ボックスに入れずにそのまま入力します。テンキーの数字・記号の扱いを Mac・Linux でも Windows と揃えました (#1783)。
- 打ちかけの子音を BackSpace で消したとき、残った文字を打ち直した結果で判定し直すようにしました (#1775)。
- 同梱の辞書・ユーザー辞書の語を、変換エンジンの候補より前に並べるようにしました (#1777)。
- 表示で英字に見えた短い語も、直すと長い語になるならローマ字の打ち間違いとして直すようにしました (#1770)。
- Zenzai の変換結果は、かなが読みと合うときだけ使うようにしました。同じ並びを繰り返す結果も使いません (#1776)。
- 文を消して打ち直すと、先頭の英単語の前に半角スペースが入る問題を修正しました (#1756)。
- 句読点の設定を、読みではなく入力欄と変換ボックスに出す文字に当てるようにしました。句読点の設定で候補が重なる問題も直しました (#1733)。
- ローマ字入力表に、英単語と区別できないとして外していた Mozc の綴りを追加しました (#1728)。
- 辞書を追加・修正し、報告された誤変換をまとめて直しました (#1677, #1690, #1701, #1774)。

## その他の修正

- ユーザー辞書の取り込みで、1 文字の読みを受け付けるようにしました (#1683)。
- Mac: ZIP の読み取り専用のリソースでインストールが止まる問題を修正しました (#1705)。
- Linux: 中国語などのロケールでも、設定画面の漢字を日本語の字形で表示するようにしました (#1672)。
- Windows: タッチキーボードで打つときに、設定「遠隔操作などの入力も処理する」を使うと分かるようにしました (#1794)。
