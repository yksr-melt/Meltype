# Meltype v1.4.1-pre.4

v1.4.1-pre.3 からの修正を含むプレリリース版です。Windows の Meltype キーボードで、入力を始めるとフォーカスが外れる問題に対処しました。

## 修正

- **Windows**: Meltype キーボードで入力を始めたとき、変換ボックスが入力欄のフォーカスを奪い、文字が届かなくなることがある問題を修正しました (#1494)。
- Windows の「マウスポインターを合わせたウィンドウをアクティブにする」設定が有効な場合も、変換ボックスなどにマウスを重ねたときにフォーカスが移らないようにしました (#1494)。

## 注意事項

- これはプレリリース版です。問題があれば GitHub Issues で報告してください。
- Linux・Mac 版は引き続きプレビュー版です。
- Linux の RPM は Fedora 向けにビルドされています。AlmaLinux などの互換性は保証していません。
