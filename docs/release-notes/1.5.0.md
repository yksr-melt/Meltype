# Meltype v1.5.0

v1.4.0 からの変更をまとめた正式版です。1.4.1-pre.1〜pre.6 で試した内容に、その後の修正を加えています。日英の境界判定を見直し、Zenzai の同梱、変換中の応答性、入力方法や候補を改善しました。

## 大きな変更

- **日英の境界判定を作り直しました**。日本語の読み・英単語・前後の文脈を合わせ、複数の区切り方の点数を比べて選びます。英単語に続く日本語、ファイル名、数字やハイフンを含む入力の判定も改善しました (#1185, #1331, #1434, #1437, #1440)。
- **Zenzai を Windows・Mac 版に同梱し、既定 ON にしました**。追加のモデル設定なしで、前の文脈を使うニューラルかな漢字変換を利用できます。使えないときや応答が遅いときは、従来の変換エンジンに任せます (#1427, #1452)。
- **変換エンジンの応答を入力中に待たないようにしました**。結果が届くと表示を更新します。処理に時間がかかる場合は、最初にかなが表示され、あとから変換結果に切り替わることがあります (#1546)。
- **かな入力の配列を追加しました**。月配列・花配列・親指シフト (NICOLA・中指NICOLA・TRON)・SKY 配列を選べます (#1428, #1465)。
- **Linux に設定画面 `meltype-settings` を追加しました**。「適用」で変更を保存し、「キャンセル」やウィンドウを閉じる操作で未保存の変更を破棄できます。AlmaLinux 9 などの RHEL 9 系にも対応しました (#1392, #1553, #1496, #1535)。

## 予測変換・候補

- 最後の文節からも予測候補を出すようにしました。Tab で選んだあと、続けて打つと選んだ候補を確定します。Esc または Shift+Tab で選ぶ前に戻せます (#974)。
- 学習データがなくても、「おはようございます」「お疲れ様です」「よろしくお願いします」などを予測候補に出します。自分で確定した語句やユーザー辞書を優先します (#1337)。
- 括弧の候補を系統ごとにまとめ、`()`・`「」` などの空のペアもまとめて選べるようにしました (#1162)。
- **Windows では「なう」で再生中の曲名・アーティストを候補に出せます**。「とけい」「じこく」では、設定したタイムゾーンの今の時刻を候補に出します (#1429, #1451)。
- 「きょう」に 8 桁の日付を追加し、`10/20` のような月/日の入力からも日付の書き方を選べるようにしました (#1189, #1439)。
- 「ばーじょん」で現在の Meltype の版を候補に出します。版番号を選んでも通常の「バージョン」や予測候補に古い版番号が割り込まないようにしました (#1272, #1524)。
- 英語の文節でも、`go` に対する「後・語・碁」など、変換エンジンの漢字候補を選べるようにしました (#1141)。

## 入力・変換の改善

- **Markdown の記号を半角で入力しやすくしました**。入力の先頭で `-`・`*`・`>`・`+`・`#` のあとに Space を押すと、半角の記号と空白を入力できます。バッククォートや連続する `*`・`---` も改善しました (#1560)。
- カスタムローマ字テーブルで打ちかけの綴りを勝手に「ん」「っ」などとして確定せず、続きを待つようにしました (#1035)。
- 拗音の入力途中で不自然に区切らないようにしました (#1160)。
- Enter で確定した語の再確定と、ターミナルで引用符内に日本語を打つときの判定を改善しました (#975, #1408)。
- Zenzai の変換候補に直前の文章が混ざる問題と、「庭」「日本」など「に」で始まる語を不自然に変換する問題を修正しました (#1505, #1617)。
- 文脈補正で「確認」「確定」などの語の一部を置き換える問題を修正しました (#1352)。
- `midika` (身近)・`mixi`・数字を含む固有名詞や型番などの誤判定を改善し、辞書の語と候補を追加しました (#1180, #1280, #1294, #1432, #1437, #1440)。

## Windows

- **打鍵数のカウンターと分析を追加しました**。トレイの「打鍵数...」から、合計・日別・時間帯別・キー別の回数を確認できます。既定では OFF で、打った文章は保存せず、回数をこの PC 内に保存します。Discord Rich Presence への表示も選べます (#952, #1368)。
- 設定画面の左に分類の一覧を追加し、開くまでの時間を短くしました (#1338, #1335)。
- Meltype IME でも入力位置の近くに「あ / A」を表示できるようにしました。IME 用の表示設定は既定では OFF です (#986)。
- Zenzai の変換を使ったときの表示とトレイの状態表示、使う GPU の設定を追加しました。llama-server の CPU 負荷も抑えるようにしました (#1341, #1339, #1342)。
- **Meltype キーボードで入力を始めるとフォーカスが外れる問題と、キー入力でアプリが落ちることがある問題を修正しました**。Windows の「マウスポインターを合わせたウィンドウをアクティブにする」設定にも対応しています (#1494, #1430, #1561)。
- Meltype IME で空の括弧を Enter で確定した際、余計な改行をせず、設定に応じて内側へカーソルを移すようにしました。一部の入力欄や Windows Terminal では内側への移動に制限があります (#1602)。
- Outlook のメール一覧の行を入力欄と誤認する問題、画面外に変換ボックスが出る問題、ユーザー辞書画面の拡大率への対応を修正しました (#1305, #1336, #1081)。
- Minecraft (Java 版) を、ランチャーや Java の場所によらずゲームとして扱うようにしました (#1306, #1447)。
- 自動更新に失敗したときのログと旧版への復元、再起動後の入力パイプの再接続を改善しました (#1379, #1431)。
- プレリリース版も自動更新の対象にする設定を追加しました。既定では OFF です。更新後の初回起動でリリースノートを表示し、トレイからも見直せるようにしました (#1222, #1223)。

## Linux

- 設定画面に必要な GTK 4・PyGObject などをパッケージの必須依存にしました (#1502)。
- fcitx5 の候補を縦表示にし、固定の操作ガイドを `ShowGuide` で非表示にできるようにしました。Shift+Space による日本語・英数の切り替えにも対応しました (#1007, #1034)。
- IBus で、ターミナルのコード入力中に半角/全角キーで日本語へ切り替えられない問題を修正しました (#1025)。
- **旧インストール・アンインストールスクリプトを廃止し、apt / dnf を中心とした導入に整理しました**。ビルド済み本体の ZIP は引き続き配布します。旧スクリプトからの移行は [Linux のインストール手順](https://github.com/yksr-melt/Meltype/blob/v1.5.0/docs/LINUX.md#インストール)を確認してください (#1471, #1518)。

## Mac

- 配布 ZIP やソースビルドからの更新時に、入力メニューから Meltype が消える問題を修正しました。Homebrew からの更新はこの修正の対象外です (#1497)。
- Homebrew でのインストール処理と、入力ソースを追加する案内を改善しました (#1398, #1026, #1027)。
- モニターを移動したあとに候補が別の画面へ出る問題と、Spotlight で候補ウィンドウが検索欄の裏に隠れる問題を修正しました (#1250, #1159)。
- 未確定入力中の操作キー、ユーザー辞書のファイル選択画面、辞書取り込みと記号候補を修正しました (#1259, #1166, #1405)。

## 開発・設定

- `config.json` の補完・確認に使える `config.schema.json` を書き出すようにしました (#1074, #1311)。
- 設定項目を整理し、対応する OS の項目を表示するようにしました (#1414, #1477)。
- CI・静的解析・入力や変換の回帰テストを整備し、SignPath のテスト署名用ワークフローを追加しました (#1186, #1225, #1316, #1467, #1481, #1485)。

## 更新時の注意

- Linux・Mac 版は引き続きプレビュー版です。RHEL 9 系では IBus のみ対応しています。
- Windows で更新前から起動しているアプリに旧版の Meltype IME が読み込まれていると、変換結果の表示が次の打鍵まで更新されないことがあります。その場合は入力先のアプリを再起動してください。
- 括弧の確定後に内側へカーソルを移す機能は Windows 向けです。Mac・Linux では対応していません。
