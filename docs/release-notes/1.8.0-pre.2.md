# Meltype v1.8.0-pre.2

v1.8.0 の2回目のプレビュー版です。設定アプリの見た目と項目の並びを見直し、Mac に DMG インストーラーを追加しました。以下は v1.8.0-pre.1 からの変更です。

## 新しい機能

- **Windows・Mac・Linux の設定アプリを Fluent 2 の見た目にしました**。項目の分類も見直し、探しやすいように並べ替えました (#2453, #2475)。
- **Mac を DMG からインストールできるようにしました**。DMG を開き、「Install Meltype」を起動してください (#2377)。
- **Windows の Meltype キーボードで、対応ゲームのチャット欄が開いている間だけ日本語入力に切り替わるようにしました**。VRChat などでチャット欄を閉じると、WASD などのキーをゲームに通します (#2478)。
- ユーザー辞書に分類を付け、一覧を分類ごとに絞り込めるようにしました (#2426)。
- `hex()`・`rgb()`・`hsl()` で色コードを相互変換できます。Windows・Mac の変換候補には色見本も出ます (#2422)。
- `uuid()` や `guid()` を変換すると、新しい UUID v4・v7 の候補が出るようになりました (#2470)。
- 「Esc で一段ずつ戻す」を使うと、ひらがなに戻した読みの途中にカーソルを移動して打ち直せるようになりました (#2426)。
- 日本語入力中も CapsLock で大文字を打つ設定と、変換中の矢印キーを ATOK と同じにする設定を追加しました (#2426)。
- Control キーの個別の割り当てに「半角に変換」を追加しました。たとえば `O=HalfWidth` と書くと、Ctrl+O で半角に切り替えられます。Ctrl+J などで変換を確定する設定も利用ガイドに追記しました (#2509, #2510)。
- `......` のようにピリオドを続けて打って変換すると、同じ数の句点を選べるようになりました (#2508)。
- Linux: Vulkan・CUDA 対応の `llama-server` を使う場合、Zenzai に使う GPU を設定アプリで選べるようになりました (#2491)。

## 変わったこと

- 「ユーザー学習を使う」を OFF にすると、以前に覚えた変換も候補に反映しなくなりました (#2394)。
- コード入力で、コメントの記号を種類ごとに ON / OFF できるようになりました。コメントの中で確定しても日本語入力を続けられ、URL や `--all` などの引数は英数のまま打てます (#2279, #2280, #2418, #2421)。
- 入力欄に入ってすぐ切り替えた入力モードを覚え、次にその欄へ入ったときに使うようにしました。英数キーを切り替えキーに登録でき、Lang1・Lang2 キーでも日本語と英数を選べます (#2426, #2490)。
- かな配列・SKY 配列は、物理キーの位置に合わせて入力します。「打ったキーを表示」では、かな配列の前置シフト・同時打鍵も確認できます。NICOLA では英単語も判定します (#2441, #2511)。
- Mozc の設定を開くなどの操作用候補を、通常の変換候補から除きました (#2444)。
- 「くだしあ」の補正候補に「ください」を、「すきじご」などの変換候補に「隙自語」を追加しました (#2482, #2498)。
- 設定アプリが異常終了したとき、診断に使える `crash.log` を保存するようにしました (#2503)。

## 不具合の修正

- Windows (Meltype IME): 設定で動作モードを切り替えたときに未登録なら、登録を案内します。インストール・アンインストール時に、言語の一覧からほかの IME が消えることがあった不具合も直しました (#2410, #2423)。
- Windows (Meltype IME): UAC を無効にした PC でストアアプリから Meltype IME につながらない、Excel でセルを選んで打ち始めると先頭文字が抜ける、変換していないときにテンキーがアプリへ届かない不具合を直しました (#2402, #2426, #2446)。
- Windows: 応答しないアプリに UI Automation で問い合わせたときの長い停止や、Meltype キーボードでキーを離したあとに修飾キーが押された扱いになる不具合を直しました。英数モードの維持と Ctrl+Enter・NICOLA の打鍵も修正しました (#2429, #2430, #2477)。
- Mac: 文書の先頭で定型文を展開できなかった不具合を直しました (#2443)。
- Linux: IBus の JIS かな入力で記号や小書き文字を打てるようにしました。Debian 系のパッケージには、動作に必要な ICU の依存関係を追加しました (#2427, #2505)。
- `youtu.be` や `n8nを使う`、英単語の後ろの「では」の日英判定を修正しました。URL の末尾で無変換キーを押したときも、英数に切り替わるようになりました (#2480, #2493, #2512, #2520)。
- 英単語の前後の空白、英語の前にある `\`・`-`・`/` の幅、入力途中の子音で日英の区切りをまたぐときの表示を修正しました (#2419, #2431, #2449)。
- ライブ変換で別の入力の結果が使われることがあった不具合を直しました。Zenzai が返した壊れた文字も候補から除くようにしました (#2432, #2507)。
- アプリ別設定が空の古い設定ファイルを読み込めるようにし、定型文の記号を変えたときに案内や一覧にも反映するようにしました (#2453, #2489)。
