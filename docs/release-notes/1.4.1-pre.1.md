# Meltype v1.4.1-pre.1

v1.4.0 からの変更をまとめたプレリリース版です。日英の判定の仕組みを大きく変えています。これまでと違う判定や、不具合が含まれることがあります。

## 日英の判定

- **日本語と英語の境界を、複数の区切り方の点数を比べて選ぶようにしました** (#1185)。日本語の読み・英単語・前後の文脈を合わせて判断します。
- カタカナ語の読みを増やし、ホスティングのような語も日本語として扱いやすくしました。
- 入力途中の英単語や、英単語に続く「する」の表示と区切りを調整しました。
- ユーザー辞書の登録語を、入力の区切られ方によらず使えるようにしました。
- 英語の文節でも、変換エンジンの漢字候補を選べるようにしました。`go` の「後・語・碁」なども候補に出ます (#1141)。

## 新しい機能・設定

- **Windows: 打鍵数のカウンターと分析を足しました** (#952)。トレイの「打鍵数...」から、合計・日ごと・時間帯ごと・キーごとの回数を見られます。
  - 初期状態では OFF です。打った文章は保存せず、回数をこの PC の中に保存します。
  - テキストからの取り込み・書き出しにも対応しています。
- **Windows: プレリリース版も自動更新の対象にする設定を足しました** (#1222)。設定の「更新」から有効にできます。初期状態では OFF です。
  - v1.4.0 からこのプレリリース版を試すときは、配布物をダウンロードして更新してください。この版に更新すると、以後のプレリリース版の自動更新を選べます。
- **Windows: 更新後の初回起動でリリースノートを表示するようにしました** (#1223)。トレイの「更新」から、あとで見直すこともできます。
- `ばーじょん` を変換すると、今使っている版が `Meltype-1.4.1-pre.1` のように候補に出るようにしました (Windows・Mac・Linux 共通、#1272)。
- `config.json` の項目を補完・確認できる `config.schema.json` を書き出すようにしました (#1074)。Mac・Linux などで設定ファイルを直接編集するときに使えます。

## 不具合の修正・辞書

- Windows: Outlook のメール一覧の行を入力欄と誤って扱い、固まったり落ちたりする問題を直しました (#1305)。
- Windows: ユーザー辞書の窓と最小サイズを、画面の拡大率に合わせるようにしました (#1081)。
- Linux: 配布物の版の設定と、`--version` の取得に失敗したときの扱いを直しました (#1212・#1203)。
- `midika` (身近) を `midiか` にしてしまう問題を直しました (#1180)。
- `mixi` を英字のままにするようにしました (#1280)。
- フォロ爆・きゅうくらりん・ぶいすぽの変換と、`wakatte` の日本語判定を直しました (#1294)。`ぶいすぽっ！` も候補に足しました。

## 開発まわり

- Issue で報告された入力例を、回帰の確認に使うテストデータに足しました (#1186)。
- GitHub Actions の依存関係を更新し、PR のチェックに不要な取り消しが残る問題を直しました (#1310)。
- 古い設定を読むためだけの項目が `config.schema.json` に出ないようにしました (#1311)。

不具合や判定の変化に気づいたら、打ったキー・期待した結果・実際の結果と、この版を使っていることを添えて報告してください。
