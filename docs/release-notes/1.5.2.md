# Meltype v1.5.2

v1.5.1 の修正版です。

## 入力・変換の改善

- Windows (Meltype キーボード): 打っている途中に `?` などの Shift を使う記号を打つと、Shift なしの文字 (`?` が `・`) になる問題を修正しました。
- 設定「入力中も変換候補をいくつか表示」で出した候補を、Tab で選べるようにしました。今までは Tab で通常の変換が始まり、見えていた候補と違う語になっていました。

**Full Changelog**: https://github.com/yksr-melt/Meltype/compare/v1.5.1...v1.5.2
