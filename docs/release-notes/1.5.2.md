# Meltype v1.5.2

漢字変換をすべての OS で Mozc と Zenzai にそろえました。Windows の設定画面に「適用」ボタンを追加し、入力の不具合を直しました。

## 変わったこと

- **漢字変換を、すべての OS で Mozc と Zenzai で行うようにしました**。これまでは Windows が Mozc と Microsoft IME、Mac が azooKey で変換していたので、OS ごとに変換結果が違っていました (#1749)。
  - 設定「変換エンジン」はなくなりました。
  - Windows: Microsoft IME に登録した語は、候補に出なくなります。使いたい語は Meltype のユーザー辞書に登録してください。
  - Mac: 対応する macOS は 13.3 以降になりました。

## 新しい機能

- **Windows: 設定画面に「適用」ボタンを追加しました**。設定画面を閉じずに、変更を反映できます (#1853)。

## 入力・変換の改善

- Windows (Meltype キーボード): 打っている途中に `?` などの Shift を使う記号を打つと、Shift なしの文字 (`?` が `・`) になる問題を修正しました (#1836)。
- 読みと表記が違う語 (「きずく」の「気づく」、「ばいおりん」の「ヴァイオリン」など) も、Zenzai の変換結果を使うようにしました (#1800)。

## その他の修正

- 誤変換を調べやすいように、確定のたびに、英語と日本語をどう区切ったかの理由をログに残すようにしました。打った文字は、設定「ログに入力した文字を残す」が ON のときだけ残します (#1865)。
- 不具合の報告フォームの項目を減らし、書きやすくしました (#1563)。
