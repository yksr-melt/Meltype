# Meltype v1.8.0-pre.1

v1.8.0 のプレビュー版です。Windows・Mac・Linux で同じ設定アプリを使うようにし、ユーザー辞書の語を変換エンジン (Mozc) に直接渡すようにしました。

## 新しい機能

- **Windows・Mac・Linux で共通の設定アプリを新しく作りました**。前の設定画面と置き換わります。変えた設定をその場で打って試せる入力プレビューも付けました (#2201, #2318)。
- **Mac・Linux でも打鍵数を数え、Discord のステータスに出せるようにしました**。出すかどうかは設定「打鍵数」で選べます (#2349)。
- typect の保存ファイルから打鍵数を取り込めるようにしました (#2401)。
- 入力モードの切り替えキーに、CapsLock・カタカナ/ひらがな・変換・無変換を単独で登録できるようにしました (#2265)。
- 大文字と小文字が混ざった固有名詞 (iPhone・GitHub など) を、自動で正しい表記にするようにしました (#2299)。
- 英語と判定した語の変換の候補に、カタカナの表記も出すようにしました (#2044)。
- べき乗の計算結果を変換の候補に出すようにしました (#2212)。
- 「打ったキーを表示」で、漢字に変換する前の形を選べるようにしました (#2040)。
- 合成音声キャラクターの名前を変換の候補に足しました (#2314, #2354)。

## 変わったこと

- **ユーザー辞書の語を Mozc のユーザー辞書に渡し、ほかの語との兼ね合いを Mozc が決めるようにしました**。取り込んだ辞書の品詞も Mozc に渡します (#2241, #2242, #2252)。
- 設定を減らしました。英訳・候補の意味は常に出します。時計の候補は PC のタイムゾーンで出します。かな + w を笑いにする機能と、設定「入力中も変換候補をいくつか表示」は無くなりました (#2301, #2374)。
- 文節の区切りの学習をやめました。前の版が覚えた区切りは使いません (#2047)。
- 設定の句読点は、打った句読点にだけ当てるようにしました。モーニング娘。のように語に含まれる句読点は変えません (#2289)。
- 数字のすぐ後ろの `,` と、確定した英単語のすぐ後ろの `,` `.` を句読点にしました (#2337, #2378)。
- 入力欄の文脈は、キャレットより前の文字だけから決めるようにしました (#2341)。
- かなの候補を選んで確定した文節も学習するようにしました。かなを選んだ読みは、それまで覚えた変換を忘れます (#2213, #2237)。
- よく使う語でない 3〜4 文字の読みも、日本語の語として読むようにしました (#2050)。
- かな配列で文字キーを長押ししたときに、文字を繰り返して入力するようにしました。中指シフトの打ち直しは、直前の文字だけにしました (#2032)。
- 利用者向けの文書を、今の動きに合わせて書き直しました (#2364)。
- ターミナルのパスワードを入力する所では、パスワードの欄として扱わないようにしました (#2204)。
- Android: シフトの固定 (Caps) は、シフトを 2 回続けて押したときだけにしました (#2362)。

## 不具合の修正

- **学習データ・定型文のファイルが一時的に読めなかったとき、上書きして消してしまうことがあった不具合を直しました** (#2298)。
- Windows: Zenzai の時間切れを失敗に数えて、Zenzai を早く使わなくなっていた不具合を直しました (#2338)。
- Zenzai が打った記号を落とした答え (りんごを、たべた → 林檎を食べた) を使わないようにしました (#2307)。
- 英数とコードの行で Shift+Space が入力されなかった不具合を直しました (#2363)。
- Windows (Meltype IME): Tk のアプリ (IDLE など) で確定した p・r・t などが、F1・F3・F5 のキーとして扱われていた不具合を直しました (#2177)。
- Windows (Meltype IME): Win+X メニューで文字キーが効かなかった不具合を直しました (#2092)。
- `~/.local/share` が無い環境で、設定と学習データを正しい場所に保存できなかった不具合を直しました (#2203)。
- Linux: 設定アプリが RHEL 9 系に入らなかった不具合を直しました (#2277)。
- Mac: インストールしたあと、入力ソースが選ばれないことがあった不具合を直しました (#2376)。
- Mac: Intel の Mac に Apple シリコン用の zip を入れたときは、理由を出して止めるようにしました (#2315)。
- `dottoe` (ドット絵) や、Issue 番号のすぐ後ろの「で」などが、英語と日本語の間で誤って区切られていた不具合を直しました (#2390, #2392)。
- 設定アプリで壊れたバックアップや plist を取り込むと、設定アプリが落ちていた不具合を直しました (#2285)。
- 学習データに空の値があると、入力と変換が止まっていた不具合を直しました (#2284)。
- Discord のステータスを、ほかのユーザーが作ったパイプに送らないようにしました (#2287)。
