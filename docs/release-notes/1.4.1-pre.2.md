# Meltype v1.4.1-pre.2

v1.4.1-pre.1 からの変更をまとめたプレリリース版です。日英の判定や予測変換の改善、各 OS の不具合修正が入っています。

## 変換・予測変換

- **最後の文節からも予測変換の候補を出すようにしました** (#974)。ライブ変換が ON のとき、文章全体を頭から打ち直さなくても、最後に打っている語の続きを補完できます。
- **Tab で予測候補を選んだあと、そのまま続けて打つと選んだ候補で確定するようにしました** (#974)。選ぶのをやめるには Esc、または Shift+Tab で選ぶ前に戻します。
- 学習データがなくても、「おはようございます」「お疲れ様です」「よろしくお願いします」などのあいさつ・定型句を予測候補に出すようにしました (#1337)。自分で確定した語句やユーザー辞書の候補を優先します。
- **括弧の候補を、丸括弧・角括弧とかぎ括弧・波括弧・山括弧の系統ごとに出すようにしました** (#1162)。空の括弧ペアは、開き括弧と閉じ括弧をまとめて選択・確定できます。
- 「きょう」の変換候補に、`20261031` のような 8 桁の日付を足しました (#1189)。

## 日英の判定

- `mitemite` (見てみて)・`kitekudasai` (来てください) が、途中の英単語に引っ張られる問題を直しました (#1331)。
- `.envfairu`・`.zshrcnosettei` のようなファイル名に続く日本語と、`javanoko` のような英単語に続く日本語の区切りを調整しました (#1331)。
- `kusawww` の入力途中でも、`www` を英字のまま見せるようにしました (#1331)。
- `wakatte.tv`・`midi` を英字で扱い、`ver1.4.1-pre.2` のようなプレリリースの版番号を崩さないようにしました (#1331)。
- 長い日本語のあとに句点を打った文が、ドメイン名と誤って扱われる問題を直しました (#1331)。

## Windows

- **設定画面の左に分類の一覧を足しました** (#1338)。選んだ分類へ移動でき、スクロールしたときも現在の分類が分かります。
- Meltype IME でも、入力モードを切り替えたとき、入力位置の近くに「あ / A」を表示できるようにしました (#986)。IME 用の表示設定は、初期状態では OFF です。
- **Zenzai に「使う GPU」の設定を足しました** (#1339)。GPU 対応の llama-server と GPU 名 (例: `Vulkan0`) を指定すると、GPU で計算できます。空欄なら従来どおり CPU を使います。
- Zenzai 使用中の llama-server の CPU 負荷を抑えるようにしました (#1342)。スレッド数と計算後の待ち方を調整しています。
- Zenzai の答えを使った変換には、変換ボックスに「Zenzai」と表示するようにしました。トレイのメニューから、起動中・利用可能・応答待ちなどの状態も確認できます (#1341)。
- フォーカスを戻したときなどに、異常な入力位置によって変換ボックスが画面外や大きすぎるサイズで出る問題に対処しました (#1336)。
- Minecraft (Java 版) をゲームとして扱い、入力への干渉を避けるようにしました (#1306)。

## Mac

- 画面を移動したあと、変換候補が別の画面に出る問題を直しました (#1250)。
- 未確定入力中に、矢印などの操作キーが文字として入ってしまう問題を直しました (#1259)。
- ユーザー辞書を取り込むファイル選択画面を、操作できないことがある問題を直しました (#1166)。

## Linux

- IBus: ターミナルのコード入力で、半角/全角などのキーによる日本語への切り替えを直しました (#1025)。
- fcitx5: 変換候補を縦に並べるようにしました。`config.json` の `ShowGuide` を `false` にすると、固定の操作ガイドを隠せます (#1007)。英字提案・予測候補・スペル訂正などの案内は表示します。

## 開発・運営まわり

- Issue の関連候補を、共通点の根拠付きで案内するようにしました (#501)。
- bot の `/repro` を複数行で実行できるようにし、不具合報告に再現に必要な情報があれば自動で再現するようにしました (#1323)。
- PR の件数上限を超えたときは、Draft にせずラベルで順番待ちを示すようにしました (#1308)。
- Linux RPM ビルドの Fedora イメージ取得元、Zenzai のテスト、候補の注記の内部処理を整えました (#1350・#1343・#1370・#1164)。

不具合や判定の変化に気づいたら、打ったキー・期待した結果・実際の結果と、この版を使っていることを添えて報告してください。
