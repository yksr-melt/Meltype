# Meltype v1.7.0-rc.1

v1.7.0 のリリース候補版です。Android 版の開発を始め、端末で使う meltype-tty を足し、ARM64 の Windows でも Meltype IME を使えるようにしました。Linux 版に Zenzai を同梱し、Windows のインストールと更新はインストーラー 1 つにまとめました。

## 新しい機能

- **Android 版の開発を始めました**。ほかの OS と同じ判定と変換で、日本語と英語を QWERTY で打てます。まだ配布はしていません (#1149)。
- **Linux: 端末で使う meltype-tty を足しました**。IBus・fcitx5 は要らず、GUI の無い端末や SSH の先でも使えます。IBus・fcitx5 のパッケージとは別の zip (`Meltype-<版>-tty-linux.zip`・`Meltype-<版>-tty-linux-arm64.zip`) で配ります (#2018, #2053)。
- **Windows: ARM64 の Windows でも Meltype IME を使えるようにしました** (#1856)。
- **Linux: Zenzai を同梱しました** (#1893)。
- **Linux: 左右の Alt を単独で押すと、英数と日本語を切り替えられるようにしました** (#1852)。
- **部首の呼び名から漢字を探せるようにしました** (#1864)。
- **Space の候補に、英語と日本語の区切り方を変えた変換結果も並べるようにしました** (#1759)。
- 変換を始めたときに、最後の文節を選ぶようにしました (#1909)。
- 無変換キーでカタカナに切り替える設定を足しました (#1668)。
- Windows: 変換ボックスの色を自由に選べるようにし、設定画面を Windows のライト / ダーク モードに合わせました (#1927)。
- Windows: 更新したあとに見せるリリースノートを、見出しや太字の書式付きで表示するようにしました (#2056)。

## 変わったこと

- **Windows: インストールと更新を `Meltype-<版>-setup.exe` に一本化しました** (#1803)。
- 英単語の判定を、すべての OS で同梱の単語の一覧で行うようにしました。OS のスペルチェッカーは使いません (#1874)。
- ライブ変換は、かなが 2 文字以上のときに行うようにしました (#1951)。
- 英語の決まり文句の特別な判定と、macOS で英語の後ろに空白を入れる処理をなくしました (#1954)。
- Jump Desktop などのリモートデスクトップのクライアントでは、既定で OFF にしました (#1895)。

## 入力・変換の改善

- ローマ字の途中から英単語を切り出す誤判定を減らしました (#1914)。
- 英単語の後ろの助詞・助動詞を漢字にしないようにしました (#1950)。
- 日本語の文の中の「技術用語 + する」(`fairusharesuru` など) を英単語にするようにしました (#1906)。
- `deploys` など、英単語の -s の形も英単語として扱うようにしました (#1939)。
- 同じ変換ボックスの英字も文脈の手がかりにし、「pH の しけんし」を「試験紙」にするようにしました (#1772)。
- かなと一緒に打った `！？「」` などの記号を、変換後も打った文字のままにしました (#1875)。
- 前の版が学習した Zenzai の壊れた答えを、読み込むときに消すようにしました (#1846)。
- 「じゃくしゃだんせい」「ふにゃおす」で、もう一方の語も候補に出すようにしました (#1925)。

## その他の修正

- Mac・Linux (fcitx5): ロック画面のパスワード欄や認証ダイアログでは変換しないようにしました (#1928, #1964, #1863)。
- Linux: 左右の Alt で入力モードを切り替えたあとのクリックが、Alt 付きのクリックになる問題を修正しました (#1986)。
- Windows: 変換ボックスなどが、ほかのウィンドウの後ろに出る問題を修正しました (#1732)。
- Windows (Meltype キーボード): Meltype が使った修飾キーを離したことが、アプリに伝わらない問題を修正しました (#1898)。
- Windows: 前の版の Meltype IME が残るアプリでは、打っている所でも PC の再起動を求めるようにしました (#1921)。
- 通貨の換算に使うレートを更新しました。
- 使い方の文書を、要点だけに書き直しました (#1953)。
