# Meltype v1.4.1-pre.6

v1.4.1-pre.5 からの変更を含むプレリリース版です。変換中の入力の引っかかりや Windows のクラッシュを修正し、Markdown の入力と Linux・Mac 版を改善しました。

## 変換・入力

- **変換**: 変換エンジンの応答を入力中に待たず、結果が届いたら表示を更新するようにしました。処理に時間がかかる場合、最初はかなが表示され、あとから変換結果に切り替わることがあります (#1546)。
- **Markdown**: 入力の先頭で `-`・`*`・`>`・`+`・`#` のあとに Space を押すと、半角の記号と空白を入力できます。バッククォートや、連続した `*`・`---` も半角で入力しやすくしました (#1560)。
- **Windows**: Meltype キーボードでキーを入力したときに、アプリが落ちることがある問題を修正しました (#1561)。

## Linux

- 設定画面に「適用」と「キャンセル」を追加しました。変更は「適用」を押したときに保存されます。キャンセルまたはウィンドウを閉じると、最後に適用したあとの未保存の変更は破棄されます (#1553)。
- 設定画面に必要な GTK 4 と PyGObject などをパッケージの必須依存にし、Debian や Fedora などで不足しにくくしました (#1502)。
- AlmaLinux 9 などの RHEL 9 系で設定画面が起動しない問題を修正しました (#1535)。
- 旧インストール・アンインストールスクリプトを廃止しました。Linux ZIP のビルド済み本体は引き続き配布します。移行方法は [Linux のインストール手順](https://github.com/yksr-melt/Meltype/blob/main/docs/LINUX.md#インストール)を確認してください (#1518)。

## Mac

- 配布 ZIP やソースビルドからの更新時に、入力メニューから Meltype が消える問題を修正しました。Homebrew からの更新は対象外です (#1497)。

## 注意事項

- これはプレリリース版です。問題があれば GitHub Issues で報告してください。
- Linux・Mac 版は引き続きプレビュー版です。RHEL 9 系では IBus のみ対応しています。
- Windows の Meltype IME では、更新前から起動しているアプリに旧版の部品が読み込まれていると、変換結果の表示が次の打鍵まで更新されないことがあります。その場合はアプリを再起動してください (#1546)。
