# Meltype v1.4.1-pre.3

v1.4.1-pre.2 からの変更をまとめたプレリリース版です。Zenzai の同梱と既定設定の変更、キーボード配列の追加、候補表示の拡充、Linux・Mac の改善などを含みます。正式版ではないため、更新前に必要なデータのバックアップをおすすめします。

## 主な新機能

- **Zenzai を同梱**し、Windows で既定 ON にしました。Mac 版でも既定 ON にし、変換の待ち時間に上限を設けました (#1427, #1452)。
- **かな入力配列を追加**しました。月配列・花配列に加え、親指シフト (NICOLA・中指NICOLA・TRON) と SKY 配列に対応しました (#1428, #1465)。
- **候補を拡充**しました。「なう」で再生中の曲、「とけい」「じこく」で設定したタイムゾーンの時刻を候補に表示します。再生中の曲の情報はイベントで受け取るようにしました (#1429, #1451)。
- **Discord Rich Presence** に打鍵数を表示できるようにしました (#1368)。
- **Linux に設定画面** `meltype-settings` を追加しました (#1392)。
- **Linux (fcitx5)** で Shift+Space による日本語・英数切り替えに対応しました (#1034)。
- 月/日の形式 (例: `10/20`) の変換候補を追加しました (#1439)。

## 入力・変換の改善

- カスタムローマ字テーブルで入力途中の綴りを勝手に「ん」「っ」などとして確定しないようにしました (#1035)。
- 拗音の入力途中で不自然に区切らないようにしました (#1160)。
- Enter で確定した語の再確定や、ターミナルでの引用符内の日本語入力を改善しました (#975, #1408)。
- 数字を含む固有名詞や型番、ハイフンを含む入力の誤判定を修正しました (#1437, #1440, #1434)。
- 「確認」「確定」などの語の一部を文脈補正で置き換えてしまう問題を修正しました (#1352)。
- 辞書に語・候補を追加し、報告された誤判定を改善しました (#1432)。
- Minecraft (Java 版) のゲーム判定を、ランチャーや Java のインストール場所に依存しない形に改善しました (#1447)。

## OS 別の修正

- **Windows**: 自動更新に失敗した際のログ記録と旧版への復元を改善しました。再起動後のパイプ再接続や、変換ボックスにマウスを乗せた際のフォーカスも修正しました (#1379, #1431, #1430)。
- **Linux**: パッケージ管理 (apt / dnf) を中心とした導入手順に整理しました。従来のインストールスクリプトは legacy 名で残し、ビルド済み zip も引き続き配布します (#1471)。
- **Mac**: 操作キー・辞書取り込み・記号候補、Spotlight での候補ウィンドウ表示、Homebrew での導入や入力ソース登録の案内を改善しました (#1405, #1159, #1398, #1026, #1027)。
- 設定項目ごとに対応 OS を指定できるようにし、Linux では使えない Zenzai の設定項目を表示しないようにしました (#1477)。

## 開発・配布の改善

- CI の構成を整理し、ビルドやテストの問題を修正しました (#1467, #1485)。
- SignPath のテスト署名を独立したワークフローで導入しました (#1316)。
- 設定画面の表示速度、設定項目の構成、ドキュメントを改善しました (#1335, #1414, #1412)。

## 注意事項

- これはプレリリース版です。Windows の自動更新、各 OS での入力・変換、Linux のパッケージ導入などで問題があれば GitHub Issues で報告してください。
- Linux・Mac 版は引き続きプレビュー版です。
- Linux の RPM は Fedora 向けにビルドされています。AlmaLinux などの互換性は保証していません。
