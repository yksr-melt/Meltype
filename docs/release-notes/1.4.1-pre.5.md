# Meltype v1.4.1-pre.5

v1.4.1-pre.4 からの修正を含むプレリリース版です。Zenzai の変換処理と Linux の設定画面・パッケージ配布まわりを改善しました。

## 修正・改善

- **変換**: Zenzai の変換処理を修正し、関連するテストを追加・更新しました。
- **Linux**: GTK を利用する設定画面の起動処理を改善しました。
- **Linux**: RPM パッケージのビルドと RPM リポジトリ生成処理を改善しました。
- **Linux**: 配布パッケージのビルド設定と関連ドキュメントを更新しました。

## 注意事項

- これはプレリリース版です。問題があれば GitHub Issues で報告してください。
- Linux・Mac 版は引き続きプレビュー版です。
- Linux の RPM は Fedora 向けにビルドされています。AlmaLinux などの互換性は保証していません。
