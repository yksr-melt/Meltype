# Meltype v1.6.0

漢字変換を、すべての OS で Mozc と Zenzai にそろえました。医療・IT・駅名・人名などの分野の辞書を足し、変換できる語を増やしました。Meltype IME はゲームの中でも使えるようになり、チャットで日本語を打てます。

## 変わったこと

- **漢字変換を、すべての OS で Mozc と Zenzai で行うようにしました**。これまでは Windows が Mozc と Microsoft IME、Mac が azooKey で変換していたので、OS ごとに変換結果が違っていました (#1749)。
  - 設定「変換エンジン」はなくなりました。
  - Windows: Microsoft IME に登録した語は、候補に出なくなります。使いたい語は Meltype のユーザー辞書に登録してください。
  - Mac: 対応する macOS は 13.3 以降になりました。
- **Windows: Meltype IME は、ゲームの中でも止めずに英数で始めるようにしました**。チャットでは 半角/全角 などで日本語にでき、Enter で確定するか Esc で取り消すと英数に戻ります。これまでは Minecraft などのゲームで Meltype IME が何もしなくなり、日本語を打つ手段がありませんでした。Meltype キーボードは、今までどおりゲームでは何もしません (#1859)。
- **通貨の換算の額を、有効数字 2 桁に丸めるようにしました**。同梱したリリース時点のレートで計算した概算なので、細かい数字は出しません。例: 「100どる」で「約1.6万円」 (#1882)。

## 新しい機能

- **分野の辞書を足しました**。医療 (病名・医薬品・部位)、IT、駅名、固有名詞、人名、法律の題名の語を変換できます。候補の一覧では、ひらがな・カタカナの後ろに並ぶので、ふだんの候補の順番は変わりません (#1861, #1866)。
- **英字の国名を、日本語の文の中でも英語として扱うようにしました** (#1861)。
- **Windows: 設定画面に「適用」ボタンを追加しました**。設定画面を閉じずに、変更を反映できます (#1853)。
- **Windows: 前の版の Meltype IME が残っていて打てないアプリでは、打っている所に「再起動してください」と出すようにしました**。これまでは起動中に 1 回だけ出る通知を見逃すと、打てない理由が分かりませんでした (#1844)。
- 「ばーじょん」の候補に、OS と使っている入力方式も出すようにしました。例: `Meltype-1.6.0 (Windows / Meltype IME)`。不具合を報告するときにお使いください (#1881)。

## 入力・変換の改善

- Windows (Meltype キーボード): 打っている途中に `?` などの Shift を使う記号を打つと、Shift なしの文字 (`?` が `・`) になる問題を修正しました (#1836)。
- 読みと表記が違う語 (「きずく」の「気づく」、「ばいおりん」の「ヴァイオリン」など) も、Zenzai の変換結果を使うようにしました (#1800)。

## その他の修正

- 誤変換を調べやすいように、確定のたびに、英語と日本語をどう区切ったかの理由をログに残すようにしました。打った文字は、設定「ログに入力した文字を残す」が ON のときだけ残します (#1865)。
- 不具合の報告フォームの項目を減らし、書きやすくしました (#1563)。
