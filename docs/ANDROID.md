# Meltype for Android

日英を自動判定する QWERTY ソフトウェアキーボードのプレビュー版です。日本語・英語を混ぜて打てます。12 キー・フリック入力は未提供です。

## 動く環境

- Android 8.0 (API 26) 以降
- 64 ビットの ARM (`arm64-v8a`) または x86 (`x86_64`)

## インストール・更新

1. [Releases](https://github.com/yksr-melt/Meltype/releases) で `android-v<版>` のプレリリースを開き、`Meltype.apk` をダウンロードします。デスクトップ版の「Latest」とは別です。
2. APK を開きます。Android が確認を出したら、取得元を確認し、そのブラウザーやファイルアプリからのインストールを許可します。
3. Meltype アプリを開き、案内に沿って Android のキーボード設定で有効にし、入力方法として選びます。

更新も新しい `Meltype.apk` を開いて上書きします。公式配布版と同じ署名・アプリ ID の APK である必要があります。デバッグ版は別アプリです。上書きできない場合、すぐにアンインストールせず、配布元と版を確認してください。アンインストールすると設定・学習データが消えます。

## 操作

| したいこと | 操作 |
| --- | --- |
| 日本語・英語の自動判定 | 日本語 QWERTY でローマ字を打つ |
| 日本語 / 英語を切り替える | あa キー。スペースの長押しから上下スワイプして選ぶこともできます |
| 数字・記号を打つ | 数字・記号配列へ切り替える (2 ページ) |
| 変換候補を選ぶ | 候補バーをタップ。選んだ文節の候補を変更し、確定キーで確定 |
| 予測候補を使う | 候補バーの予測候補をタップして確定 |
| 変換中の文節を移る | スペースを長押しして左右に動かす |
| 絵文字を入れる | 絵文字パネルを開く |
| ライブ変換・スペースの幅・触覚を変える | Meltype の設定画面 |

かな漢字変換は端末内の Mozc で行います。Zenzai は同梱していません。デスクトップ版と同じ Core を使いますが、設定画面やキー操作には違いがあります。ユーザー辞書の編集・音声入力・カスタムテーマは未対応です。

## データとプライバシー

ネットワーク権限を持たず、入力内容は外部へ送りません。パスワード・メールアドレス・数字の欄では自動変換を受け持たず、打ったとおりに入力します。パスワード欄では学習しません。

設定・学習データはアプリ専用の領域に保存し、Android の自動バックアップ・端末間移行から除外しています。触覚フィードバックには `VIBRATE` 権限を使います。

## 困ったとき

Core の初期化などに失敗した場合は、入力方法の選択を開ける退避画面を表示します。キーボード自体が開かないときは Android の入力方法の切り替えで別の IME を選んでください。

[不具合の報告](https://github.com/yksr-melt/Meltype/issues/new/choose) には、Meltype の版・Android の版・端末名・アプリ名と、打った内容・期待した結果・実際の結果を書いてください。見られて困る文字は含めないでください。

開発と現在の対応範囲は [Android README](../android/README.md)、配布用 APK の作成は [署名と配布](../android/docs/SIGNING-DISTRIBUTION.md) にあります。
