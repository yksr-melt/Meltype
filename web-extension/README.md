# Meltype の拡張機能

Chrome・Edge・Firefox の拡張機能です。どのサイトの入力欄でも、ローマ字のまま打つと、日本語と英語を分けて変換します。

中身は [Web エンジン](../web-engine/README.md) で、判定 (Core) も漢字変換 (Mozc) もブラウザーの中で動きます。打った文字はどこにも送りません。

## 作る・入れる

```bash
web-extension/build.sh
```

`web-extension/dist/` と `web-extension/meltype-extension.zip` ができます (Web エンジンが無ければ、先に `web-engine/build.sh` で作ります)。

- **Chrome・Edge**: `chrome://extensions` (Edge は `edge://extensions`) で「デベロッパー モード」を ON にし、「パッケージ化されていない拡張機能を読み込む」で `dist/` を選ぶ。
- **Firefox**: `about:debugging#/runtime/this-firefox` の「一時的なアドオンを読み込む」で `dist/manifest.json` を選ぶ (Firefox を閉じると外れる)。
- ストアに出すときは `meltype-extension.zip` を使う。

アイコンは `web/scripts/make-icons.mjs` が `web/public/favicon.svg` から作ります。

## 動き

- 入力欄 (`<textarea>`・文字の `<input>`・`contenteditable`) を初めて選んだときに、Web エンジンを読み込みます。入力欄を使わないページでは読み込みません。読み込んでいる間に打ったキーは、ふつうに入ります。開くと自動でフォーカスする入力欄にも付けます。
- メールアドレス・数字・パスワードなどの `<input>` には付けません。
- 入力モードは日本語だけです (英語もそのまま打てます)。
- 覚えたことは拡張機能の保存場所 (`storage.local`) に置き、どのサイトでも共有します。サイトの IndexedDB には置きません (そのサイトから読めてしまうため)。
- 候補の欄は Shadow DOM の中に描くので、サイトの CSS とは混ざりません。
- ツールバーのボタンを押すと出る画面で、次のことができます。
  - **一時的なオン・オフ**: オフの間はボタンに「OFF」と出ます。ブラウザーを起動し直すとオンに戻ります。
  - **このサイトで使うか**と**除外サイト**: 除外したサイトでは何もしません。一覧から外したり、アドレスを入れて足したりできます。
  - **ショートカットキー**: 一時的なオン・オフのキー (最初は Alt+Shift+M)。Firefox はこの画面でキーを押して変えられ、Chrome・Edge はブラウザーのショートカットキーの設定の画面を開きます (拡張機能からは変えられないため)。
  - **覚えたことを消す**
- 指で操作する端末 (Android の Firefox など) では、画面の下に Meltype のキーボードを出します。

## CSP の厳しいサイト

サイトのセキュリティの設定 (CSP) の `script-src` に `'wasm-unsafe-eval'` が無いと、Chrome・Edge は拡張機能のスクリプト (`content.js`) の中の WebAssembly も止めます (GitHub・X など)。そのサイトでは、Core を拡張機能のページ (`frame.html`) で動かします。Firefox はサイトの CSP を拡張機能のスクリプトにかけないので、どのサイトでもページの中で動きます (Firefox 160 で、GitHub でも確かめた)。

- `frame.html` を、閉じた Shadow DOM の中の見えない iframe でページに置きます。拡張機能のページはサイトの CSP を受けません。
- `content.js` と `frame.js` は `runtime.connect` でやり取りします。拡張機能の中からしかつなげないので、サイトのスクリプトは Core と覚えたことに触れません。
- 答えを待たずにキーを通すかを決めるので、Web エンジンの `core` の動き (`web-engine/README.md`) になります。予想が外れたときに代わりに書けるのは文字・Backspace・Enter・← → だけなので、変換していないときに Core が受け取ると思って止めたほかのキー (まれ) は失われます。
- 判定と変換がページの外で動くので、打っている間にページが止まりません。

どちらで動いているかは、ツールバーのボタンを押すと出ます。どちらでも読み込めなかったときも、そのことが出ます。

## そのほか

- タブごとに Web エンジンを読み込むので、入力欄を使ったタブごとに数百 MB ほどのメモリーを使います。iframe の中の入力欄 (埋め込まれたフォームなど) を使うと、その iframe でも読み込むので、そのぶん増えます。
- 覚えたことは、Web エンジンを読み込んだタブどうしで、確定したらすぐに共有します (上書きし合わない。Web エンジンの README を参照)。
- 拡張機能を更新・再読み込みすると、開いていたタブではページを読み直すまで、覚えたことを残せません (CSP の厳しいサイトでは、Meltype が外れます)。
- Mozc が覚えたこと (漢字の候補の順番) は、タブを閉じると忘れます。
- AI の変換 (Zenzai) はありません。
- Chrome では、拡張機能の中のファイル (`engine/`) をサイトから読めるようにしているので、サイトはこの拡張機能が入っていることを知ることができます。
