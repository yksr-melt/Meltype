次に書かれた「起きたこと」から、Meltype の Issue を作る。

$ARGUMENTS

書いた人は IT に慣れていないかもしれない。言葉が足りなくても責めず、こちらで補う。目的は、あとで PR を作りやすいくらい詳しい Issue にすること。

## 手順

1. **種類を決める**: 動かない・止まる (不具合)、変換や英語 / 日本語の判定の間違い (誤判定)、辞書に語がない (辞書)、こうしてほしい (提案)。合うテンプレートを `.github/ISSUE_TEMPLATE/` から選ぶ
2. **足りないことを聞く**: テンプレートの項目で足りないものを、やさしい言葉で、1 回にまとめて聞く。専門用語を使わず、調べ方も添える
   - Meltype の版: 「ばーじょん」と打って変換すると候補に出る
   - 打ったもの: キーボードで押したキーをそのまま (例: `kyouhagoogle` と打って Enter)
   - どのアプリで: メモ帳・Chrome・Discord など
   - OS: Windows / Mac / Linux
   分からないと言われた項目は「不明」にして進める
3. **確かめられるなら確かめる**: 誤判定なら `dotnet run --project src/Meltype.Core.Tests -- --repro <打ったもの> enter` で再現し、結果を Issue に書く
4. **似た Issue を探す**: あれば、それに書き足すほうがよいかを聞く
5. **Issue の案を見せる**: テンプレートの項目どおりに、日本語で、事実だけを書く。推測は「たぶん」と分かるように書き、起きていないことを足さない
6. 書いた人が「これで出して」と言ったら Issue を立てる

## 守ること

- パスワード・個人的な文章・メールアドレスなど、見られて困るものが入っていたら、消してから出す (消したことを伝える)
- 直し方の見当がつけば、「直す場所の見当」として最後に書き添える (PR を作る人の助けになる)
