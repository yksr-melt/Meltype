PR #$ARGUMENTS の main とのコンフリクトを解消する。**コンフリクトの解消だけをして、ほかは変えない。**

## 手順

1. PR のブランチを取り、main を merge する。rebase・force push で履歴を書き換えない
2. コンフリクトした箇所ごとに、main 側で何が変わったか (どの PR で、何のために) と、PR 側で何をしたかったかを読み、両方の意図を残すように直す。どちらかを丸ごと捨てない
3. main で名前や形が変わったもの (設定の名前、関数の引数など) に PR のコードを合わせる
4. AGENTS.md の「ビルドとテスト」を流し、テストが通ることを確かめる。フォーマット (`dotnet format whitespace --folder`) もかける
5. merge のコミットを PR のブランチに push する

両方の意図を残せない (方針がぶつかっている) ときは、直さずに、どこがぶつかっているかを報告して止まる。

## 出すもの

- コンフリクトした箇所と、どう解消したか (1 行ずつ)
- テストの結果
