# Meltype-FLASH v1.1.20

- **ChromeOS・iOS・Android の設定にも通貨の換算を足しました**。この 3 つはネットからレートを取らないので、選べるのは**固定**と**手入力**、それに小数の桁です。Windows・macOS・Linux は今までどおり固定・自動・手入力を選べます。

# Meltype-FLASH v1.1.19

- **本家 v1.6.0 の分野の辞書を足しました**。医療 (病名・医薬品・部位)、IT、駅名、固有名詞、人名、法律の題名の語を変換できます。候補の一覧では、ひらがな・カタカナの後ろに並ぶので、ふだんの候補の順番は変わりません。例: せんたんきょだいしょう → 先端巨大症、あいづかのうえき → 会津加納駅。分野の辞書は、よく使う語の読み (きょう・あい など) には足しません。
- **英字の国名を、日本語の文の中でも英語として扱うようにしました**。Unicode CLDR の国・地域名から作った語で、大文字で始まる国名 (Bermuda・Puerto Rico など) をそのまま残します。ローマ字として読める語と、日本語の語のローマ字の途中と重なる語 (Hong・SAR など) は、もとの日本語の区切りが変わらないよう入れていません。
- 通貨の換算に 3 つのレートの出どころを選べるようにしました（設定「通貨のレート」）。**固定**はこの版に同梱した配布時のレートで、`≒1.6万円` のように近似の印を付けて小数第 1 位まで書きます（1 万以上は万・億・兆）。**自動**はネットから最新のレートを取ります（Windows のみ。取れなければ固定）。**手入力**は自分で入れた数（`150` とだけ書けば 1 ドル=150 円）をそのまま使います。例: 「100どる」で「≒1.6万円」、「10000えん」で「≒62.8ドル」。
- 「ばーじょん」の候補に、OS と入力方式 (Windows は IME方式 / キーボード方式) も書くようにしました。例: `Meltype-FLASH 1.1.19 (Windows / IME方式)`。不具合を報告するときにそのまま貼れます。
- AI の変換結果が読みと合わないとき (繰り返し続けた答え・直前の文節の混入など) は、その答えを使わず Mozc に任せるようにしました。Zenzai だけでなく、Gamma・Qwen・Shion・Jinen・kanakanji-edge と shuntelligence も同じ判定です。読みと表記が違う語 (きずく → 気づく) は、Mozc の文節ごとの候補で作れるときに Mozc の区切りで使います。
- 本家 v1.6.0 のうち、C# 版だけの変更 (Windows の設定画面の「適用」ボタン、再起動の案内、ゲームの中での IME の動作、Mac の最低 macOS 13.3、不具合報告フォームの項目、区切りの理由のログ、変換エンジンの設定の廃止) は、Flash の Rust 実装には入れていません。未移植の範囲は[上流1.6.0系の照合](https://github.com/appipinopi/Meltype-Flash/blob/rust/docs/UPSTREAM-1.6.0-AUDIT.md)に記録しています。

- Windows版にDiscordのステータス表示（Rich Presence）を追加しました。Discordが起動しているときだけ、今日・合計・1分あたりの打鍵数と起動からの経過を送ります。Discordのローカル接続だけを使い、外のサーバーは通りません。

- AI変換を有効にしているときは、状態の行の `{ai}` が「AI対応中」に変わります。
- iOS・macOS・Android・Windowsに利用状況の集計（Aptabase）を追加しました。送るのは起動・キーボード準備などの出来事の名前とOS・アプリの版だけで、入力内容・履歴・辞書・設定値は送りません。既定は無効で、入れた人だけが送り、切ると次の起動から送りません。
- 打鍵数を数えるのはTSF方式の入力です。ポータブル入力（キーボードモード）は数えません。Linux・ChromeOSは打鍵数と利用状況の集計の対象外です。
- 「ネットワーク権限は要求しません」と書いていたAndroidの説明が実際の権限と食い違っていたため、モデルのダウンロードに使うことを明記しました。

# Meltype-FLASH v1.0.8

- AI設定で系列だけでなく配布版・モデルサイズ・量子化を選べるようにしました。Zenzはv1/v2/v3/v3.1/v3.2、Jinenはv1/v1.1 beta/v2、kanakanji-edge 33m、shuntelligenceはv5/v6/v7の標準・軽量版、あわせて31種類から任意導入できます。

## 配布と導入

共通Rustエンジンを使うWindows・macOS・Linux・Android・ChromeOS・iOS向けプレビューです。元C#版と全機能・変換精度が同等の完成版ではありません。実機・実アプリでの受入確認が残っています。

| 環境 | 配布ファイル | 導入 |
|---|---|---|
| Windows 10/11 x64 | Meltype-flash-Windows-x64.zip | 全体を展開し、README-Windows.mdを参照。管理者PowerShellでManage-Windows.ps1を実行。32bitアプリ用TIP/workerも同梱 |
| Linux x64（Ubuntu 24.04でビルド） | Meltype-flash-Linux-x64.tar.gz | 展開後、Meltype-flash-linuxでbash install.sh。システムのIBus/GLibと設定画面のGUI実行環境が必要 |
| macOS 13以降・Apple Silicon | Meltype-flash-macOS-arm64.zip | ZIP全体を展開し、Install Meltype.commandを実行 |
| macOS 13以降・Intel | Meltype-flash-macOS-x64.zip | ZIP全体を展開し、Install Meltype.commandを実行 |
| Android 8.0以降・arm64/x86_64 | Meltype-flash-Android-debug.apk | 開発検証用APKをインストール後、システムのキーボード設定でMeltype-flash Previewを有効化 |
| ChromeOS | Meltype-flash-ChromeOS.zip | 展開後、chrome://extensionsで「パッケージ化されていない拡張機能を読み込む」。入力方法にMeltype-FLASHを追加 |
| iOS 15以降 | Meltype-flash-iOS-unsigned.ipa / Meltype-flash-iOS-source.zip | 自分の署名を設定して導入。Simulator用ZIPは実機に導入できません |

Windowsは元C#版と異なる専用COM登録IDを使います。配布ZIPを展開するだけではIME登録は行いません。導入済みのFlash版を更新する場合は、同梱の`Manage-Windows.ps1 -Action Update`を管理者PowerShellで実行してください。旧バージョンのファイルと個人データは保持します。設定画面にはOpenGL 2.0以上が必要です。CIではソフトウェアOpenGLで実トレイの終了試験を行い、実Windowsでも設定クリックと更新を確認しています。

LinuxはRust製IBus版です。Mozcヘルパーを同梱せず、変換は共通Coreの補助辞書に限られます。fcitx5用パッケージは含みません。IBusがアプリ名を渡さない入力経路（gnome-shellや一部のQt・XIMなど）ではアプリ別の自動切替を行いません。

macOSはSwift InputMethodKitとazooKeyを利用します。署名はアドホック署名で、Developer ID署名・Apple公証は行っていません。初回起動はmacOSの許可操作が必要になる場合があります。

Androidはエミュレーターで検証するdebug APKです。Play Store配布・正式な配布署名・物理端末での確認は未対応です。このAPKの署名鍵はCI実行ごとに変わるため、別のCI生成版からの上書き更新は保証できません。アンインストールするとアプリ内データを失うので、必要なデータは先にバックアップしてください。Mozcは同梱しません。

ChromeOSはManifest V3とchrome.input.imeを使用する試験版です。ChromeOS製品版・管理ポリシーによって導入できない場合があります。Windows/macOS/Linux上のChrome用IMEではありません。Chrome Web Store公開は行っていません。サイト別切替は初期状態では無効です。設定の「サイトごとの自動切替」を有効にし、タブ参照を許可して保存してください。周辺テキストを渡さないエディターではコメント・文字列内の日本語入力を自動判別できないため、そのサイトを通常入力へ変更してください。ChromeOS実機でのPre7の入力検証は未実施です。

RustとAndroidの内部バージョンは`0.1.0-pre.7`、AndroidのversionCodeは7です。iOSのビルド番号は12、マーケティング版番号は`0.1.0`です。ChromeOSは拡張機能の内部バージョン`0.1.6`、表示名`0.1.0 Pre7`を使います。

本家との比較には、入力途中の表示や追加診断で残る差があります。従来の`nihongoGitHub`分節差を含む過去の記録と、本家1.4.0に対する統合前の比較結果は区別してください。[本家1.4.0との比較・対応](UPGRADE-1.4.0.md)に測定範囲を記載しています。

各ファイルのSHA-256はSHA256SUMS.txtを参照してください。WindowsとChromeOSのZIPには内部ファイルのハッシュも含みます。ソースと各環境の詳細は同じリリースタグ内のrust/README.md、android/README.md、chromeos/README.mdを参照してください。
